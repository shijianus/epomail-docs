## 🧭 引言与核心承诺

欢迎阅读 **EpoMail 隐私权政策**。当您使用 EpoMail 服务时，即表明您信任我们对您个人信息的处理方式。我们深知这份责任重大，因此始终致力于全力保护您的信息，并让您拥有对这些信息的完全控制权。

本隐私权政策深度对照 **Google / Gmail 官方隐私政策体系（policies.google.com/privacy）** 制定，旨在帮助您清晰了解：
1. 我们收集哪些信息以及收集这些信息的原因；
2. 我们如何使用这些信息；
3. 我们在何种严格限制的条件下与第三方子处理方共享信息；
4. 您如何行使访问、更新、导出和彻底删除您个人信息的法定权利。

## 📥 1. 我们收集的信息 (Information We Collect)

为了向您提供高可用、安全且极速的现代电子邮件通信服务，我们在您使用 EpoMail 的过程中收集以下三类信息：

### 1.1 您主动创建或提供给我们的信息
- **账户基本信息**：在注册或由管理员创建账号时，您所设置的邮箱前缀（如 `alex@mybrand.com`）、显示昵称、单向加密后的密码哈希，以及用于安全验证的备用邮箱或手机号。
- **电子邮件通信内容**：您通过 EpoMail 发送、接收、起草或归档的所有邮件，包括发件人、收件人列表、抄送/密送、主题、发送时间戳、邮件 HTML 及纯文本正文。
- **附件与多媒体文件**：随邮件上传或接收的文件、PDF 报告、图片或压缩包等。
- **联系人与规则配置**：您在系统内创建的通讯录联系人、自建的邮件过滤规则、标签分类以及 Telegram 推送绑定凭据。

### 1.2 在您使用服务期间我们自动收集的信息
为了保障账户安全并防范网络攻击，系统底层自动记录必要的访问日志：
- **设备与浏览器信息**：访问 EpoMail Web 客户端时的浏览器类型、版本、操作系统平台（如 macOS/Windows/iOS/Android）以及语言首选项。
- **网络与安全审计日志**：登录及关键操作发生时的 IP 地址、大致地理位置（国家/城市级别，来自 Cloudflare 边缘节点网络分配）、访问时间戳，以及密码验证失败记录。

### 1.3 我们绝不收集的信息
:::important[隐私安全底线]
- **绝不收集侵入式商业画像**：我们绝不收集您的浏览历史、搜索习惯、购物偏好等商业追踪画像；
- **绝不使用第三方追踪 Cookies**：全站仅使用维持用户安全登录态所必需的本地会话令牌（JWT），绝不引入 Google Analytics、Facebook Pixel 等第三方跨站追踪脚本；
- **绝不上报设备私密相册或物理硬件序列号**。
:::

## 🎯 2. 我们为何处理您的信息 (Why We Process Your Data)

我们处理收集到的个人数据，严格限缩在以下合法、合理且最小必要的目的范围之内：

| 数据处理目的 | 涉及的数据类型 | 法律依据 (GDPR 标准) |
| :--- | :--- | :--- |
| **提供核心通信服务**<br/>处理邮件的入站清洗、正文解析、本地存储、检索与出站投递 | 邮件正文、收发件人、附件、别名 | 履行合同义务 (Performance of a Contract) |
| **安全保障与防欺诈**<br/>拦截暴力破解、防范自动化撞库、阻止恶意钓鱼邮件与垃圾邮件滥发 | 登录 IP、失败尝试、Turnstile 行为数据 | 正当合法利益 (Legitimate Interests) |
| **智能体验增强**<br/>利用边缘算力毫秒级提取验证码并在列表显著标注 | 邮件文本片段 (内存即时处理) | 履行合同义务与用户授权同意 |
| **遵守法律与合规义务**<br/>履行适格法院或监管机构依法出具的法定协助要求 | 审计日志、通信元数据 | 遵守法律责任 (Compliance with Legal Obligations) |

## 🤝 3. 数据共享与第三方子处理方 (Subprocessors)

**我们庄严承诺：永远不会将您的个人信息、邮件内容或通讯录出售给任何第三方！**

为了向您提供高可靠的边缘云计算基础设施，我们仅与以下经过严格安全审查的第三方云基础设施服务商（子处理方）协同处理数据：

| 子处理方名称 | 承担的职责与服务范围 | 数据驻留与合规标准 |
| :--- | :--- | :--- |
| **Cloudflare, Inc.** | 提供边缘计算 (Workers)、数据库存储 (D1)、对象存储 (R2)、缓存 (KV) 及入站邮件清洗 (Email Routing) | 遵循 ISO 27001、SOC 2 Type II，支持欧盟标准合同条款 (SCCs) |
| **Resend, Inc.** | 负责通过全球高信誉 IP 池向外部互联网投递出站 SMTP 邮件 | 遵循 SOC 2 Type II，实施端到端 TLS 传输加密 |

除此之外，除非存在以下极端法定情形，我们绝不向任何外部机构披露您的数据：
- 取得您的明确书面授权；
- 根据具有管辖权法院出具的有效传票、搜查令或强制性法律裁判（详见 [司法调证与合规协助指引](/legal/law-enforcement/)）。

## 🌐 4. 跨国数据传输与边缘网络安全

EpoMail 基于 Cloudflare 全球分布式边缘网络运行。当您在世界任何角落访问系统或发送邮件时，您的数据可能经由距离您最近的 Cloudflare 边缘数据中心（覆盖全球 300+ 城市）进行加速与安全清洗。

所有跨国数据传输均全面强制采用 **TLS 1.3 现代高强度加密通道**，确保数据在公网传输过程中免遭窃听与篡改。

## 🔒 5. 您的隐私控制与法定权利 (Your Privacy Rights)

无论您身处何地，EpoMail 均对标 **欧盟通用数据保护条例 (GDPR)** 与 **加州消费者隐私法案 (CCPA)** 等国际顶级隐私标准，赋予您对自身数据完整的控制权利：

```
┌────────────────────────────────────────────────────────┐
│             用户享有的五大核心法定隐私权利              │
└────────────────────────────────────────────────────────┘
  [1] 访问权 (Right of Access)：随时查看名下所有邮箱收发记录与账号元数据
  [2] 更正权 (Right to Rectification)：随时自主修改个人密码、昵称与偏好
  [3] 可携权 (Right to Data Portability)：一键无障碍导出标准 EML 格式归档
  [4] 限制处理权 (Right to Restriction)：随时开启/关闭验证码提取与消息推送
  [5] 被遗忘权 (Right to Erasure)：一键彻底永久物理删除邮件或注销账号
```

### 如何行使您的法定权利？
- **自主操作**：您可直接登录 EpoMail Web 客户端，在「个人中心」与「邮件箱」中随时执行导出、修改或删除操作；
- **联系管理员**：自托管实例用户可联系该站点的超级管理员处理深度数据诉求；管理团队承诺在法律规定的 **30 个自然日内** 审查并答复完毕。

## 📅 6. 数据保留与注销政策

- **活跃数据**：只要您的账号保持有效激活状态，您的邮件与附件将根据您的存储配额持续保存；
- **回收站清理**：移入「回收站」的邮件将在 **30 天后** 自动触发物理彻底清除；
- **账户注销**：当管理员或用户确认注销账户后，系统将在经过必要的 7 天防误触冷静期后，从 D1 数据库与 R2 对象存储桶中**彻底物理擦除**属于该用户的所有通信记录与附件文件。
