## 📨 1. 邮件收发与基础通信能力

### 零延迟邮件入站 (Inbound Processing)
- **依托 Cloudflare Email Routing**：所有进入绑定域名的邮件首先经过 Cloudflare 全球清洗中心，自动过滤大流量 DDoS 攻击与垃圾邮件探测。
- **MIME 复杂邮件解析**：Worker 进程原生解析 `multipart/mixed`、`multipart/alternative` 等标准协议，智能分离 HTML 富文本、纯文本与附件。
- **自动归档与未读同步**：入站邮件自动入库 D1，并实时更新用户未读计数，状态秒级同步。

### 高信誉邮件出站 (Outbound Delivery)
- **多发信渠道冗余保障**：原生深度集成 **Resend API** 与 **Cloudflare Send Email**，亦支持标准外部 SMTP 网关中继。
- **富文本撰写与内联图片**：集成现代化所见即所得编辑器，支持内联贴图、超链接、表格以及多文件附件一次性拖拽上传。
- **群发与抄送/密送 (CC/BCC)**：支持规范的抄送与密送机制，严密保护多收件人隐私。

## 📦 2. 对象存储与 R2 附件管理

传统邮件数据库常因为存储巨型附件（数十 MB 至上百 MB）导致数据库体积急剧膨胀，备份与查询极为缓慢。EpoMail 采用**元数据与实体文件彻底解耦**的架构：

- **分离式存储设计**：邮件元数据（发件人、主题、时间、大小、摘要）存储在轻量高效的 Cloudflare D1 数据库中；邮件原始 EML 归档与所有二进制附件直接进入 **Cloudflare R2 对象存储桶**。
- **极速预签名安全下载**：附件下载链接由后端 Worker 动态派发带有生命周期限制的加密预签名（Presigned URL），杜绝公开外链盗刷。
- **零出口流量费用 (Zero Egress Fee)**：Cloudflare R2 不收取任何数据流出（Egress）费用，即便团队频繁收发高频大附件，也无需担心流量账单爆炸。

## 🤖 3. Workers AI 智能提取与分析

EpoMail 原生集成了 Cloudflare 边缘大模型算力（默认基于 `@cf/meta/llama-3.1-8b-instruct`）：

- **邮件验证码精准提取**：当接收到来自 Google、GitHub、Apple、Telegram 或银行验证码邮件时，AI 引擎毫秒级识别验证码文本，直接在前端列表卡片与通知中高亮呈现，免去用户逐字阅读邮件正文的繁琐。
- **长邮件内容智能摘要**：对于大篇幅英文技术资讯或长篇报告，自动生成 1-2 句精要中文概述，提升阅读与分类效率。

## 🛡️ 4. 6 级 RBAC 细粒度权限控制

为了满足多成员团队、家庭组织与多租户协作需求，EpoMail 严格落实基于角色的访问控制（RBAC）体系，内置 6 大标准角色：

| 角色代码 | 角色名称 | 核心职责与权限边界 |
| :--- | :--- | :--- |
| **`ROLE_SUPER_ADMIN`** | **主站长 (超级管理员)** | 拥有系统至高无上权限。管理全站配置、查看所有域、创建/注销域管理员、执行数据库迁移与全局系统监控。 |
| **`ROLE_DOMAIN_ADMIN`** | **域管理员** | 管理所辖域名的所有邮箱账号分配、设置该域成员的发信配额、查看该域所有收发审计日志。 |
| **`ROLE_OPERATOR`** | **运营与合规审计员** | 负责全站反垃圾邮件监控、异常流量排查、合规性审计，拥有只读全局检索权限，无权篡改用户数据。 |
| **`ROLE_ADVANCED_USER`** | **高级用户** | 拥有独立域名邮箱，享有较高发信配额、支持配置自动化 Telegram 推送与规则引擎。 |
| **`ROLE_REGULAR_USER`** | **普通用户** | 拥有分配的标准邮箱账号，仅限进行常规邮件收发、联系人管理与个人偏好设置。 |
| **`ROLE_GUEST`** | **只读访客 / 临时账号** | 仅具备临时查看特定邮箱收件箱权限，禁止发信与修改账户凭据。 |

## 🔒 5. 企业级安全防护与认证体系

- **TOTP 两步验证 (2FA)**：支持 Google Authenticator、1Password、Bitwarden 等标准时间同步动态口令，密钥经系统级 AES 对称加密隔离存储，防止单密码泄漏。
- **Cloudflare Turnstile 人机防刷**：登录与公开注册接口强制接入无感 Turnstile 人机验证，彻底拦截自动化爬虫与黑客撞库机器人。
- **登录防爆破与 IP 锁定**：当连续输错密码达到阈值（如 5 次）时，系统自动锁定该账号与客户端 IP 访问窗口，有效阻断暴力破解尝试。
- **冷启动高密门禁**：通过独创的 `/api/init/<jwt_secret>` 初始化接口，仅持有生产密钥的运维人员可触发系统播种，杜绝恶意抢先注册主站长。

## 🔔 6. 规则引擎与自动化推送

- **Telegram 实时推送信令**：可在系统后台绑定 Telegram Bot Token 与 Chat ID。一旦入站邮件匹配特定规则，立即向指定 TG 频道或私聊窗口推送发件人、主题及智能提取的验证码。
- **邮件多条件过滤与打标**：支持按发件人后缀、主题关键词、包含附件等复合维度，自动将邮件归类至指定标签（如“工作”、“账单”、“验证码”），或自动转发至备用外部邮箱。

## 💻 7. 现代化响应式前端体验

- **自适应布局**：采用流动弹性栅格与响应式断点设计，无缝覆盖 **375px（移动端手机）**、**768px（平板电脑）**、**1024px（便携笔记本）** 到 **1440px+（宽屏台式显示器）**。
- **原生深浅色彩模式**：深度适配系统级深色模式（Dark Mode），高对比度且护眼舒适。
- **ECharts 数据可视化大屏**：后台提供交互式图表，直观呈现近 30 天邮件收发走势、入站拦截趋势、活跃邮箱排行与存储占用分布。
- **多语言（i18n）**：开箱即用支持包括中文简体、中文繁体、英语在内的多国语言无缝切换。
