本頁說明「設定 → 個資」與「設定 → 常規」兩個分區的每一項。安全與資料類設定分見[帳號安全設定指南](/zh-tw/mail/security/)與[資料匯出與儲存](/zh-tw/mail/data/)。

<details>
<summary>圖解：個資頁——個人資料被拆成的四個維度</summary>

個資頁的四張卡片：從身分形象到聯絡方式再到地址簿，個人資料的四個維度分卡管理。

1. **基本資訊卡**：頭像上傳、個人暱稱、性別與生日；暱稱與頭像是否對外顯示，受管理員「公開個人主頁」開關約束。
2. **聯絡資訊卡**：登入主信箱帶「主信箱」標記且不可移除；可新增多個額外電子信箱並隨時移除，另可登記含區碼的電話號碼。
3. **地址卡**：住家、公司與其他三組地址分別儲存，各自獨立增刪與編輯。它們是純粹的個資留存欄位：不參與郵件投遞、不影響計費與身分分組；是否需要填寫、以及是否對外顯示，取決於營運者是否開啟「公開個人主頁」。
4. **關聯設定與安全卡**：個資頁通往其他設定頁的跳板：帳號安全（使用者名稱與密碼、兩步驗證）與第三方授權（已授權應用程式）兩處最常用的入口集中在此，避免在個資頁與安全頁之間反覆翻找；點擊即跳至對應分區，而非另開新頁。

</details>

## 1. 個資（`#settings/profile`）

| 卡片 | 內容 |
| --- | --- |
| 基本資訊 | 頭像上傳、個人暱稱、性別、生日 |
| 聯絡資訊 | 登入主信箱（帶主信箱標記）、可新增多個額外電子信箱並隨時移除、含國碼的電話號碼 |
| 地址 | 住家、公司與其他三組地址卡 |

個資的對外展示受管理員「公開個人主頁」開關約束；開放時經 `/<使用者名稱>` 存取，見[介面與路由總覽](/zh-tw/mail/interface/)第 6 節。

## 2. 常規（`#settings/general`）

| 分組 | 內容 |
| --- | --- |
| 個人簡介 | 一段展示於公開個人主頁的簡介 |
| 個性裝扮 | 外觀色調（暗色／亮色／跟隨系統）、全域主題桌布（八種預設＋自訂桌布與 URL）、個人背景、介面密度 |
| 閱讀偏好 | 收件匣類型、閱讀窗格位置、會話群組開關 |
| 語言 | 介面語言六選一；預設翻譯目標語言獨立設定（16 選 1）；圖片文字辨識翻譯可單獨關閉 |
| 資料隱私 | 個人資訊與 AI 處理偏好的集中入口 |

## 3. 外觀的作用範圍

全域主題桌布對所有檢視生效，個人背景僅覆蓋信箱區；暗色／亮色亦可在頂欄快捷切換。系統郵件與歡迎郵件按收件人語言投遞，與介面語言設定獨立。

<details>
<summary>圖解：個資與常規的操作步驟</summary>

1. 「設定 → 個資」：上傳頭像，填寫暱稱、性別與生日。
2. 聯絡資訊卡可新增多個額外電子信箱與含國碼的電話號碼；地址卡分別保存住家、公司與其他地址。
3. 「設定 → 常規」：選擇外觀色調（暗色／亮色／跟隨系統）與全域主題桌布（八種預設或自訂）。
4. 設定閱讀偏好（收件匣類型、閱讀窗格、會話群組）與介面語言；預設翻譯目標語言 16 選 1。

</details>
