本頁說明託管實例（[mail.epocanvas.com](https://mail.epocanvas.com)）所提供服務的內容、邊界與支援管道。自行部署實例不在本頁所述「服務」範圍之內：軟體依 MIT 授權條款提供，上游專案不對任何實例的運行承擔責任，其法律地位見[開源與自行部署法律](/zh-tw/mail/open-source/)；兩種形態的資料控制者界定見[隱私權與條款總覽](/zh-tw/mail/overview/)第 2 節。

*圖：本服務的約定架構。本頁說明服務本身；契約條件與告知標準由其上的法律文件承載。*

## 1. 服務內容

| 項目 | 說明 |
| --- | --- |
| 帳號與註冊 | 依實例配置經註冊碼或開放註冊取得帳號，六種身分分組決定配額與權限 |
| 郵件收發 | 收信經 Cloudflare Email Routing 即收即解析；站內直投；站外經營運者配置的投遞通道 |
| 儲存 | 依身分分組的儲存配額；可接入個人物件儲存，接入後附件直接落其雲端 |
| 整理與自動化 | 八視圖收件箱、標籤與分類規則引擎、進階搜尋、驗證碼擷取 |
| AI 能力 | 全文翻譯與圖片文字辨識（依實例的 AI 引擎配置與模型授權） |
| 通知與轉寄 | Telegram 推送與郵件規則轉寄（依管理員的使用者資料控制開關） |
| 用戶端 | Web（可安裝 PWA）與 Android 應用（epomail） |
| 語言 | 六語言介面；系統郵件與歡迎郵件按收件人語言投遞 |

功能層面的逐項說明見[功能指南](/zh-tw/mail/features/)；各介面與路由的導覽見[介面與路由總覽](/zh-tw/mail/interface/)。

## 2. 服務邊界

| 事項 | 邊界 |
| --- | --- |
| 可用性 | 不承諾服務水準協議；運行可用性依 Cloudflare 平台 |
| 保存期限 | 垃圾桶郵件自收受之日起 7 日實體刪除；垃圾郵件隔離 7 日後轉入垃圾桶 |
| 配額 | 寄信、信箱數與儲存依身分分組出廠值，站長可於權限控制頁調整 |
| 費用 | 託管實例目前不設付費功能 |
| 功能變動 | 功能隨版本演進調整；重大變更經站內公告與公告郵件通知 |
| 附件限制 | 單一附件上限依實例設定，僅約束使用營運者公共儲存的使用者 |

保存期限的完整語義見[資料處理與安全維護](/zh-tw/mail/data-security/)；行為邊界見[可接受使用政策](/zh-tw/mail/acceptable-use/)。

## 3. 官方站點與應用內連結

應用內各處官方連結的預設指向如下；實例營運者可在系統設定中覆寫為自訂地址：

| 連結 | 預設指向 | 用途 |
| --- | --- | --- |
| 專案介紹 | 本站專案介紹頁 | 帳號選單頁尾 |
| 隱私權政策／服務條款 | 本站對應法律文件 | 帳號選單頁尾 |
| 使用文件 | 本站（按瀏覽器語言協商進入） | 系統設定「關於」卡 |
| 技術支援 | 本站服務範圍與支援頁 | 系統設定「關於」卡 |
| 版本發布 | GitHub Releases | 系統設定「關於」卡 |
| Telegram | `t.me/epomail` | 系統設定「關於」卡 |

## 4. 支援管道

| 管道 | 適用事項 |
| --- | --- |
| 產品內聯絡 | 站內訊息或 `admin@epocanvas.com` |
| 隱私與資料保護 | `privacy@epocanvas.com`（行使當事人權利、資料保護申訴） |
| GitHub Issues | 缺陷報告與功能建議（`github.com/shijianus/epomail`） |
| Telegram | `t.me/epomail` 社群交流 |

## 5. 申訴與恢復

- 忘記通關密語：登入頁「忘記通關密語」彈窗跳轉申訴門戶（攜帶申訴類型、介面語言與信箱參數），經核驗後恢復存取；
- 封禁與預警申訴：就處置結果提交的申訴以預警工單進入操作報告，由管理員研判放行或駁回，處置階梯見[可接受使用政策](/zh-tw/mail/acceptable-use/)第 6 節；
- 資料自助：全量資料匯出（JSON）、郵件歷史歸檔與單封 .eml 下載可隨時經「設定 → 資料」取得，見[設定指南](/zh-tw/mail/settings/)第 5 節。

## 6. 自部署實例的支援邊界

上游開源專案不對其程式碼的任何部署運行提供服務、支援或可用性承諾；部署者對其使用者的支援、告知與合規義務自負。本站文件（含法律文件）可作為自部署者面向其使用者的說明基礎，採用時其營運者即為該等文件的責任主體。
