**更新日期：2026 年 11 月 2 日｜版本：5.25**

本頁說明託管實例 [mail.epocanvas.com](https://mail.epocanvas.com) 的服務與支援。這是個人維護、非營利的學習與測試 side project；自行部署的條件由其實際營運者另行說明，角色及責任見[開源與自行部署法律](/zh-tw/mail/open-source/)與[總覽](/zh-tw/mail/overview/)。註冊前請閱讀服務條款，不接受者請勿建立帳號。

繁體中文（臺灣）版為本站正式版本，其餘語言為對照譯本；此安排不限制適用法律要求的清楚告知、對消費者有利的解釋或不得排除的權利。更新日期記錄文本修訂，不代表新條件自動生效。

## 1. 服務內容

| 項目 | 說明 |
| --- | --- |
| 帳號與註冊 | 依實例開放情況及配額註冊，供年滿 16 歲且具備必要締約能力者使用 |
| 郵件收發 | 經配置的收信路由、站內投遞及站外通道處理；收件結果亦受對方服務影響 |
| 儲存 | 按帳號配額儲存；選用個人物件儲存時，依配置傳送相關資料 |
| 整理與自動化 | 郵件檢視、標籤、規則、搜尋及可配置的驗證碼擷取 |
| AI 能力 | 翻譯、文字辨識及其他已啟用功能的資料範圍與觸發條件見隱私政策 |
| 通知與轉寄 | 可配置 Telegram 及郵件轉寄；涉及外部接收者與相應資料傳送 |
| 用戶端 | Web、可安裝 PWA 及 Android 應用，依已發布版本提供 |
| 語言 | 六語言介面與本地化通知，實際覆蓋依版本 |

功能操作見[功能指南](/zh-tw/mail/features/)與[介面與路由總覽](/zh-tw/mail/interface/)；個人資料處理應連同[隱私權政策](/zh-tw/mail/privacy-policy/)閱讀。

## 2. 服務邊界

| 事項 | 邊界 |
| --- | --- |
| 可用性 | 無 SLA、固定可用率、投遞時限或全年無休值班；上游中斷的責任仍依事實與法律判斷 |
| 保存期限 | 垃圾桶、排程、備份與合法保存各有範圍；刪除不等於所有副本立即清除，詳見隱私與安全文件 |
| 配額 | 發送、信箱數與儲存依實例公布設定及合理變更程序 |
| 費用 | 託管實例目前免費；非營利不排除資料保護與消費者義務 |
| 功能變動 | 不保證永久託管或特定功能持續；重大不利變更與可預見停運應在合理可行時預先通知並提供合理取回期間 |
| 附件限制 | 依實例、儲存及投遞提供者限制；BYOS 不使其他技術或法律限制失效 |

本專案以歐盟資料保護原則為參照，按實際風險盡合理努力維護與改善，並透過[隱私權政策](/zh-tw/mail/privacy-policy/)第 1 節說明已知風險及可採取的措施。此定位不包含全面合規認證、企業級可用性或無事故保證；法定權利及不可排除責任不因風險告知而改變。

服務適合能容忍中斷、內容遺失及功能調整的學習與一般通訊測試，不適合作為緊急通訊、法定保存、醫療決策、唯一帳號復原信箱或重要資料的唯一備份。請優先使用合成內容，另留必要副本，並按實際需要選擇功能。具體保存、匯出與加密界線見隱私權政策及[資料處理與安全維護](/zh-tw/mail/data-security/)；行為規則見[可接受使用政策](/zh-tw/mail/acceptable-use/)。

## 4. 支援管道

| 管道 | 適用事項 |
| --- | --- |
| 產品內聯絡 | 站內訊息或 `admin@epocanvas.com`，供一般支援與申訴 |
| 隱私與資料保護 | `privacy@epocanvas.com`，供權利行使與資料保護申訴 |
| GitHub Issues | 缺陷與功能建議：[原始碼儲存庫](https://github.com/shijianus/epomail/issues) |
| Telegram | `t.me/epomail` 社群交流，不適合提交私人資料或憑證 |

一般支援非即時，未承諾答覆或修復期限。GDPR 適用時，資料保護請求應無不當遲延並於收到後 1 個月內答覆；符合法律規定的複雜度或數量條件時，可延長最多 2 個月，並在首月內通知原因；其他適用法律要求更短期間者從其規定。詳見隱私權政策；一般支援排程不能延後法定期限。

## 5. 申訴與恢復

- 無法登入時，可用登入頁提供的恢復或申訴入口，或聯絡 `admin@epocanvas.com`；僅要求比例相當的核驗，恢復依實際驗證及技術可行性決定。
- 對警告、停用或終止可提出申訴；緊急隔離不剝奪事後複核與外部救濟。處置依[可接受使用政策](/zh-tw/mail/acceptable-use/)第 6、7 節。
- 可使用介面目前提供的匯出及單封郵件下載；自助匯出不代表涵蓋全部個人資料、附件或外部副本。需要補充存取、可攜或刪除者，請依[隱私權政策](/zh-tw/mail/privacy-policy/)及[資料處理與安全維護](/zh-tw/mail/data-security/)提出請求。

## 6. 自部署實例的支援邊界

單純發布原始碼不產生對所有部署的託管、支援或可用性承諾。實際營運者應依其服務關係與適用法律向使用者提供告知及救濟；作者若另行營運，同樣承擔相應義務。

本站文件可作撰寫參考，不能取代實際角色、配置及法律適用的評估，也不構成認證。需要組織委託處理者，須先確認是否受理，並另訂必要的資料處理協議。
