本文檔說明官方系統郵件之簽發方式與識別標準，以及本站法律文檔之防竄改校驗機制，供您核驗官方通訊與文檔之真偽。本文檔依[隱私權與條款總覽](/zh-tw/mail/overview/)與[資料處理與安全維護](/zh-tw/mail/data-security/)訂定。

本站法律文件以繁體中文（臺灣）版本為正式版本，其餘語言版本為對照譯本，文義有疑義時以正式版本為準。本站法律與技術文檔以本服務開源實作為準，旨在建立透明、嚴謹之非商業社區通訊規範。

## 1. 官方發信身分與認證標記

官方系統通訊與一般使用者郵件以下列方式區分：

1. **唯一官方發信地址**：歡迎郵件與全域公告由系統經官方地址 `announcement@epocanvas.com` 簽發。該地址為程式內建，官方郵件僅經系統特權管道產生；
2. **官方認證標記（isOfficial）**：寄件人為 `announcement@epocanvas.com`、`admin@epocanvas.com`，或帶「官方」標籤之郵件，系統注入官方標記；前端閱讀窗格為其顯示官方標識與橫幅提示，便於與普通郵件區分；
3. **生命週期**：歡迎郵件與全域公告自投遞之日起按設定天數過期（預設 7 日），到期由系統排程任務清理。

## 2. 官方郵件目錄

本服務之官方系統郵件限於下列類型，均由系統模板渲染產生：

| 類型 | 觸發時機 | 說明 |
| --- | --- | --- |
| 歡迎郵件 | 新信箱開通 | 內建六語言官方模板；按設定天數過期（預設 7 日） |
| 全域公告 | 管理員發布系統公告 | 內建六語言官方模板；時效同歡迎郵件 |

除上表外，系統不以任何地址向使用者發送「帳戶異常」「中獎」「驗證逾期」等性質之郵件。收到自稱官方而寄件地址不符者，可依第 6 節窗口舉報。

## 3. 不可變投遞與預置翻譯

1. **不可變快照投遞**：官方郵件於發送時完成變數替換並固化內容快照，不隨收件人日後切換介面語言而重新產生，維護官方通訊內容之客觀唯一性；
2. **預置翻譯回退**：您對未修改之官方郵件使用「翻譯」時，系統直接採用預置之對應語言官方模板於本地渲染，不向任何 AI 服務傳輸郵件內容；經管理員修改正文之郵件，方經 AI 全文翻譯（見[隱私權政策](/zh-tw/mail/privacy-policy/)第 6 節）。

## 4. 用戶端渲染隔離

郵件內容（含官方郵件與外部來信）於瀏覽器中之渲染採取下列隔離措施：

1. **Shadow DOM 隔離**：正文渲染於獨立之 Shadow DOM 內，頁面全域樣式與腳本不影響郵件內容，郵件內樣式亦不外溢至頁面；
2. **內容白名單消毒**：正文經 DOMPurify 清洗，`<script>`、`<iframe>`、`<object>`、`<embed>`、`<form>`、`<style>` 標籤與內聯事件處理器一律移除，阻斷腳本注入與介面偽造。

## 5. 文檔防竄改校驗

本站法律文檔於發布時產生密碼學存證，任何人均可核驗所讀文檔與開源儲存庫發布版本一致：

| 核驗途徑 | 機制 | 說明 |
| --- | --- | --- |
| 存證清單 | `tamper-proof.json` | 建置流水線自 git 儲存庫產生，記錄每篇文檔之 SHA-256 雜湊、位元組大小與固化提交號 |
| 頁面內嵌面板 | 每頁底部「官方防竄改與完整性校驗」 | 顯示本文檔之官方雜湊與固化提交；點擊「即時驗證」重新擷取清單，比對頁面所載雜湊是否一致 |
| 離線核驗 | `sha256sum`／OpenSSL | 對開源儲存庫中之 Markdown 原文計算雜湊，與清單逐項比對 |
| 權威源站 | `docs.epocanvas.com/epomail` | 經 HTTPS 存取；自其他網域或鏡像存取者，應以清單雜湊核驗內容 |

:::tip[線上驗真操作指引]
於任意文檔頁底部點擊「即時驗證本文完整性」，面板將重新擷取官方清單並與頁面所載雜湊比對；亦可於終端機執行 `curl -sSL https://docs.epocanvas.com/epomail/tamper-proof.json` 取得清單原文，對源儲存庫 Markdown 執行 `sha256sum` 逐項核對。
:::

## 6. 責任邊界與通報窗口

1. **託管實例**：官方郵件之簽發、發信身分與文檔存證由官方營運團隊維護；
2. **自建實例**：自建部署者應自行設定投遞通道與密鑰，並依[資料處理與安全維護](/zh-tw/mail/data-security/)保護其實例；自建實例之官方通訊以該實例營運者為責任主體；
3. **通報窗口**：發現冒用官方名義之郵件、存證校驗異常或安全漏洞，請聯絡：
   - 官方發信與安全窗口：`announcement@epocanvas.com`
   - 隱私與資料保護窗口：`privacy@epocanvas.com`
