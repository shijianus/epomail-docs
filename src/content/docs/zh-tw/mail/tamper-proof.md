## 1. 系統發信身分與顯示標記

識別系統通訊時，應區分應用程式顯示規則與身分認證：

1. 歡迎郵件與全域公告通常由系統使用內建位址 `announcement@epocanvas.com` 產生；這不表示其他安全或管理通知不存在，也不表示顯示該位址的郵件必定真實。
2. `isOfficial` 為應用程式顯示標記：寄件人為 `announcement@epocanvas.com`、`admin@epocanvas.com`，或帶「官方」標籤時，可顯示標識與橫幅。該標記不是數位簽章，也不是對寄件人身分的獨立認證。
3. 部分系統郵件於讀取列表時，按設定的過期天數（預設 7 日）延後標記刪除，再由每日排程任務清理；並非到期立即徹底刪除。實際期限與清理限制見[資料處理與安全維護](/zh-tw/mail/data-security/)第 1.5 節。

## 2. 系統郵件與通知目錄

系統通訊包括下列類型；具體是否發送與發送方式取決於實作、設定及事件，不限於歡迎郵件與公告：

| 類型 | 觸發時機 | 說明 |
| --- | --- | --- |
| 歡迎郵件 | 新信箱開通 | 可使用內建六語言模板；保存與清理依第 1 節 |
| 全域公告 | 管理員發布系統公告 | 可使用內建六語言模板或經修改的內容；保存與清理依第 1 節 |
| 安全通知 | 登入或安全事件、依法須通知的事故 | 可因事件與適用規則發出，不因其涉及帳戶安全而當然屬於偽造郵件 |
| 管理裁決與申訴通知 | 管理處置、裁決或申訴複核 | 可告知處置與複核結果；有關紀錄的保存規則見資料安全文件 |

不能僅憑寄件位址、顯示標記或郵件中的連結判斷真偽。請從已知可信的服務入口核對通知；有疑義時使用第 6 節窗口，不在可疑連結中提交憑證。

## 3. 投遞快照與模板翻譯

1. 模板郵件在發送時替換變數並保存正文快照，切換介面語言本身不會重寫已保存的正文。該行為不等於儲存不可改寫，也不提供數位簽章或身分認證。
2. 使用「翻譯」時，命中可用的目標語言模板可在本機呈現；無法識別模板、模板缺失或正文改動等未命中情形進入一般翻譯流程，可能按設定經模型、Workers AI 或公共翻譯備援處理。不能概括承諾官方郵件絕不外傳；接收者、處理鏈及所需保障見[隱私權政策](/zh-tw/mail/privacy-policy/)第 6、7 節。

## 4. 用戶端渲染限制

郵件正文的渲染採用樣式封裝與內容清洗，兩者都不是獨立的身分或安全認證：

1. Shadow DOM 提供 DOM 與樣式作用域封裝，減少郵件與頁面樣式互相干擾；它不是腳本安全邊界，不能阻止頁面腳本存取或操作內容，也不是獨立來源的沙箱。
2. DOMPurify 按設定移除危險標籤與行內事件處理器，降低內容注入風險。清洗效果依版本、設定與後續處理決定，不能保證阻斷所有腳本注入、介面偽造或遠端資源請求。

## 5. 發布清單一致性檢查

`tamper-proof.json` 是發布清單的既有檔名，不表示清單已簽章或不可竄改。線上面板只比較目前網站兩次傳回的本頁清單項目，不對頁面正文計算雜湊。

| 檢查途徑 | 機制 | 範圍與限制 |
| --- | --- | --- |
| 發布清單 | `tamper-proof.json` | 建置時記錄工作樹原始檔經 CRLF 轉 LF 後的 SHA-256、位元組數及當時的 Git HEAD；提交號不證明工作樹沒有未提交修改 |
| 本頁面板 | 「發布清單一致性檢查」 | 僅在本頁概述與圖示後、第 1 節前顯示；比較初次與再次讀取的本頁項目 SHA-256 及完整 `gitCommit` |
| 手動原始檔核對 | Node／`sha256sum`／OpenSSL | 另行核對清單與原始檔的來源及版本，按相同換行規則計算本機 Markdown 雜湊；面板不執行此項操作 |
| 請求來源 | 目前網站的同源清單位址 | 只讀取該站清單，不請求 GitHub 作獨立核驗；HTTPS 本身不證明發布者身分或文件法律效力 |

成功僅表示兩次清單中本頁項目雜湊與 `gitCommit` 相同，不驗證頁面正文、發布者身分、數位簽章或法律合規。清單與腳本同由該站提供，若兩者一起被替換仍可能顯示一致，不能作為獨立信任依據。

:::tip[如何檢查清單一致性]
在本頁面板點擊「檢查清單一致性」。初次有效讀取只建立比對基準，不顯示成功；再次讀取後雜湊或提交號不同顯示「驗證失敗」，發布更新也可能造成差異。網路或 HTTP 錯誤、無效 JSON／結構、缺少本頁項目、不合法的 64 位十六進位 SHA-256 或完整 Git 提交號均顯示「無法驗證」，不會按成功處理。初取失敗後重新讀取成功也只建立基準，須再次檢查；手動原始檔核對說明可在面板內另行展開。
:::
