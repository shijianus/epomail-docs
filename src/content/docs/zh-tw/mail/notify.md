**生效日期：2026 年 10 月 5 日｜版本：5.16**

本頁逐步說明「設定 → 資料」頁「郵件與訊息轉寄」區的兩項能力：Telegram 訊息推送與自動轉寄。兩項功能是否對帳號開放由管理員「使用者資料控制」卡決定；關閉時對應區塊不顯示。資料匯出與儲存亦在同一頁，見[設定指南](/zh-tw/mail/settings/)第 5 節。

*圖：郵件與訊息轉寄區。Telegram 推送帶啟停狀態與設定入口，自動轉寄含目的地與進階選項。*

## 1. Telegram 訊息推送

推送使用您自備的私有 Telegram 機器人，新郵件即時直達您的會話：

1. 向 @BotFather 申請一個私有機器人，取得 Bot Token（形如 `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`）；
2. 取得您與該機器人的 Chat ID（向機器人發送任意訊息後經 getUpdates 查詢，群組為負數、頻道形如 `-100123456789`）；
3. 在「Telegram 訊息推送」項點設定，填入 Bot Token 與 Chat ID；在群組話題內接收時可另填 Topic ID；
4. 選擇推送類型偏好：全部郵件，或僅重要與驗證碼郵件；
5. 點「發送測試訊息」驗證連通，成功後開啟推送。

推送內容的欄位顯示偏好（寄件人、收件人、郵件正文）由管理員在系統設定的郵件推送卡全域配置；官方機器人的全站推送與個人私有機器人互不衝突。

## 2. 自動轉寄

| 配置項 | 說明 |
| --- | --- |
| 啟用自動轉寄 | 總開關；開啟後出現下方配置 |
| 轉寄目的地信箱 | 一個或多個目標地址，多個以英文逗號分隔 |
| 觸發類型 | 全部郵件直接副本轉寄；或僅當收件信箱命中指定前綴／字母別名（如 `billing`、`dev-*`）時轉寄 |
| 主題標頭 | 可選在轉寄郵件主題新增 `[Fwd]` 標頭，便於在目標信箱中識別 |

:::note
介面另提供「智慧規則過濾轉寄」與「保留郵件原件」選項；目前版本的轉寄引擎將智慧規則檔按全部郵件處理、尚未套用保留原件選項，依賴這兩項行為前請先實測。
:::

## 3. 投遞路徑與防回圈

轉寄優先經平台原生轉寄通道投遞，失敗時自動改經系統投遞通道並按開關附加 `[Fwd]` 前綴；目的地與收件人或原寄件人相同時自動跳過，避免轉寄回圈。觸發類型與進階選項的規則語義亦見[搜尋與規則參考](/zh-tw/mail/search/)第 7 節。
