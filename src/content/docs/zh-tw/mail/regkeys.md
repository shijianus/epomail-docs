**生效日期：2026 年 10 月 6 日｜版本：5.17**

註冊密鑰是管理區的邀請碼介面（`#manage/admin/reg-keys`，權限鍵 `reg-key:query`），控制誰能註冊本實例。註冊碼的三種全站模式（必填／關閉／選填）由[系統設定](/zh-tw/mail/system/)的網站設定卡決定。

*圖：註冊密鑰*

<details>
<summary>圖解：註冊金鑰空白頁——簽發入口與檢索框</summary>

註冊密鑰頁在尚未簽發任何邀請碼時的空狀態：一個簽發按鈕與一個檢索框構成本頁全部分區。

1. **新增註冊碼按鈕**：簽發入口：彈窗內一次產生一組 8 位隨機碼（可點擊重新整理重新產生），並綁定註冊後進入的身分分組、有效期與可用次數（1–99999，每成功註冊一次扣減一次）。
2. **註冊碼檢索框**：簽發後按註冊碼篩選定位，查看剩餘次數、綁定分組與有效期；訪客視角的敏感欄位自動脫敏。
3. **空狀態卡**：實例尚未簽發任何註冊碼時的引導佔位；簽發後此區變為註冊碼清單，附一鍵複製、使用紀錄查驗、單筆刪除與「清理未用」批次作廢。

</details>

## 1. 簽發

「新增」彈窗一次簽發一條註冊碼，可配置：

| 欄位 | 說明 |
| --- | --- |
| 註冊碼 | 8 位隨機碼，可點擊重新整理重新產生 |
| 綁定分組 | 經此碼註冊的帳號進入指定身分分組（分組見[權限控制](/zh-tw/mail/roles/)） |
| 有效期 | 到期日後不可再用 |
| 可用次數 | 1–99999；每成功註冊一次扣減一次 |

## 2. 管理與查驗

| 操作 | 說明 |
| --- | --- |
| 清單 | 顯示剩餘次數、綁定分組、有效期；訪客檢視時敏感段脫敏 |
| 複製 | 一鍵複製註冊碼文字，便於傳送給受邀者 |
| 使用記錄 | 檢視該碼已被哪些帳號使用 |
| 刪除 | 立即作廢該碼 |
| 清理未用 | 一鍵清除所有尚未使用的碼 |

URL 攜帶邀請碼參數（`?code=`／`?regKey=`／`?invite=`）可直接預填註冊表單，見[介面與路由總覽](/zh-tw/mail/interface/)第 5 節。

<details>
<summary>圖解：註冊密鑰的操作步驟</summary>

1. 進入管理區「註冊密鑰」（需 `reg-key:query` 權限）。
2. 點「新增」產生 8 位隨機碼（可點擊重新整理重新產生）。
3. 綁定註冊後進入的身分分組，設定有效期與可用次數（1–99999）。
4. 複製註冊碼傳送給受邀者；「使用記錄」查驗消耗情況；「清理未用」一鍵作廢全部未用碼。

</details>
