## 1. 違法與危害內容

不得利用服務從事下列行為。處置應考量可靠資訊、實際危害與合法使用的可能性；緊急隔離及法定通報依第 6、7 節辦理。

| 禁止行為 | 營運者之處置 |
| --- | --- |
| 兒童及少年性虐待、性剝削內容的製作、持有或散布，以及引誘兒少受侵害 | 立即限制接取、阻止傳播；依法保存必要證據及通報，並審查帳號終止 |
| 向兒少散布依法禁止向其提供的暴力、性或賭博內容 | 先限制有害接觸，依法律與危害程度移除或限制帳號 |
| 未經同意製作或散布性影像，包括有害的合成性影像 | 迅速限制接取或移除；保存與申訴依第 2 節 |
| 依法禁止散布、販售或公開展示的猥褻內容 | 核實通知與適用法律後採必要措施 |
| 詐欺、釣魚、冒用身分或偽造寄件人以欺騙他人 | 隔離內容、限制涉事功能並依法處理 |
| 惡意軟體散布、憑證竊取、未經授權入侵或破壞系統 | 立即隔離危害並複核；第 4 節的合法隔離測試另依授權範圍判斷 |
| 侵害著作權、商標權、隱私或違法揭露他人資料 | 核實權利及合法使用理由，按第 8 節或適用程序處理 |

## 2. 非自願性性影像

禁止以本服務製作、傳輸或散布未經同意的性影像。接獲足以定位內容的可信通知時，營運者應迅速限制接取或移除，降低再次散布的危害。

1. 依實際適用法律判斷移除、證據保存與通報義務，不以單一法域規則推定全球相同。
2. 僅在適用法律明確要求時，按其適用對象、起算點與範圍保存至少 180 日；其他情形以合法且必要的最短期間保存。證據應隔離，限獲授權且有必要的人員接觸，期滿且無其他合法保存事由時清除。
3. 向主管或執法機關提供資料，須具法律依據、核實對象並限於必要範圍。緊急移除不剝奪事後申訴；法律禁止揭露或有妨害調查風險時，理由通知得依法限制或延後。

## 3. 垃圾郵件與濫用行為

不得從事下列行為：

1. 發送未經請求的大量郵件、向未同意的收件人行銷，或進行信箱暖機與位址驗證轟炸。除本政策外，仍須遵守依法適用的寄件地、收件地及其他反垃圾郵件規範；行銷遭拒絕時應停止。
2. 未經授權批次註冊，繞過 Turnstile、註冊金鑰或配額限制。
3. 建立濫發轉寄跳板、短期濫用帳號池，或反覆註冊以規避處置。

## 4. 攻擊與干擾

可在您控制且與真實服務隔離的部署，以合成或合法去識別的資料學習、除錯及安全測試，並確保第三方不受影響。測試不授權取得真實郵件、個人資料或他人憑證。

1. 對公開託管實例、真實使用者系統或第三方系統進行掃描、壓力測試、社交工程、暴力破解或存取測試前，須取得該系統負責人的明確授權，遵守範圍、時間與停止條件；公開可訪問不等於授權。
2. 不得故意耗盡 AI、附件、API 等共用資源，或干擾他人使用；獲授權的容量測試應遵守事先約定的限制。
3. 善意批評、漏洞回報、隱私申訴、主管機關檢舉及依法維權不屬濫用。禁止威脅、定向騷擾或以公開私人資料造成危害。
4. 第三方條款僅在實際選用服務及相關契約關係範圍內適用，不轉嫁營運者本應承擔的義務。

## 5. 資源使用之一般義務

1. 請遵守實例公布的儲存與發送配額；變更依服務條款通知。
2. 不得出租、轉售帳號或將憑證交予未授權者。合法整合應使用受限授權並妥善保管金鑰。
3. 選用 BYOS 或外部資料庫前，應確認存取權限及資料處理條件；使用者與營運者各依實際角色履行義務，使用者選擇服務不免除營運者的資料保護與國際傳輸責任。

## 6. 執行措施

處置依違規性質、可信程度、危害與重複情形採比例原則。兒少侵害、非自願性影像或進行中攻擊可先隔離或停用，無須逐級等待；之後仍應複核。

法定內容通報依適用法律辦理，僅提供必要資料予有權接收者，不自動向所有第三方、上游服務商或檢舉人提供內容。使用者僅就依法可歸責的行為負責，沒有概括賠償營運者或開發者全部費用、罰款或第三方索賠的義務。

## 7. 申訴與檢舉

1. 認為處置有誤者，可經 `admin@epocanvas.com` 或服務條款第 13 節管道申訴；無法登入仍可聯絡。一般情形應在重大處置前提供理由與說明機會，並於合理期間複核答覆。
2. 檢舉請提供必要的內容位置、時間與理由，避免重新散布受害影像、密碼或無關個資。營運者按可信程度及危害分流處理；隱私請求的法定期限另依隱私政策。
3. 緊急措施得先執行再通知，但不取消事後申訴或向法院、主管機關求助的權利。複核發現錯誤時，應在合法且技術可行範圍更正限制與結果；不得承諾已刪除資料必可恢復。

## 8. 著作權與智慧財產權之通知與反通知

權利人可提供權利及侵害的具體說明、足以定位內容的資訊、聯絡方式與依法必要的聲明。營運者應核實通知、授權及適用的例外或限制，再決定限制接取、移除或要求補充資料；不因單方主張即認定侵權。

受影響者可提出反通知及合法使用理由。通知、反通知或身分資料僅在適用程序要求且具法律依據的必要範圍轉交，並依法告知，不自動完整轉送給檢舉人。反覆侵權或故意虛假通知依事實、比例原則及法律處理；內部程序不取代法定救濟。
