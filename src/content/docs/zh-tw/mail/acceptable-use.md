# 可接受使用政策

**生效日期：2026 年 9 月 30 日｜版本：5.2**

本政策是[服務條款](/zh-tw/mail/terms-of-service/)第 7 節「可接受使用」之具體化，規定您使用 EpoCanvas Mail 服務（下稱「本服務」）時之行為邊界。違反本政策者，營運者得依「執行措施」節處置；涉有犯罪嫌疑者，並依法處理。

本政策所列行為，除違反本政策外，亦可能構成您或營運者所在地法律下之違法行為；具體定性以有權限機關之認定為準，本文件不構成法律意見。

本站法律文件以本繁體中文（臺灣）版本為正式版本，其他語言版本僅供參考；內容如有歧異，以繁體中文版本為準。

## 1. 違法與危害內容

您不得利用本服務傳輸、儲存或散布下列內容：

| 禁止行為 | 營運者之處置 |
| --- | --- |
| 兒童及少年性剝削內容，包括拍攝、製造、重製、持有、散布、播送、交付、公然陳列、販賣兒少性影像或與性相關之圖畫、語音、物品 | 零容忍：一經發現即刪除內容並終止帳號，保存證據並移交有權限機關；不適用申訴緩衝程序 |
| 對兒童及少年散布或播送有害其身心健康之暴力、血腥、色情、猥褻、賭博內容 | 零容忍程序：限制接取或先行移除 |
| 非自願性性影像之攝錄、重製、散布，或以電腦合成等方法製作之不實性影像（詳第 2 節） | 先行限制瀏覽或移除，證據至少保存 180 日，並配合調查 |
| 猥褻之文字、圖畫、聲音、影像或其他物品之散布、播送、販賣或公然陳列 | 依檢舉查處；屬違法內容者移除並依情節處置 |
| 詐欺、釣魚、冒用身分（含偽造寄件人或冒用政府機關與公務員名義）之郵件與內容 | 隔離或刪除涉詐內容；涉嫌犯罪者移交有權限機關 |
| 惡意軟體、病毒、勒索軟體之散布，以竊取憑證為目的之郵件，無故入侵、取得刪除變更電磁紀錄或干擾電腦系統 | 立即隔離並終止帳號；涉嫌犯罪者移交有權限機關 |
| 侵害他人著作權、商標權、隱私或名譽之內容 | 經權利人有效通知後移除，並依相關法律處理 |

## 2. 非自願性性影像

利用本服務上傳、傳輸或儲存非自願性性影像者，一經查獲，營運者即予限制瀏覽或移除，並依下列規定處理：

1. **刑事禁止**：未經同意攝錄、重製、散布他人之性影像，或以電腦合成等科技方法製作並散布不實性影像，於多數法域構成刑事犯罪。
2. **平臺移除義務**：營運者知有性侵害犯罪嫌疑情事，即先行限制瀏覽或移除與犯罪有關之資料；該等資料與嫌疑人之個人資料及網路使用紀錄，至少保留 180 日，以提供司法及警察機關調查。
3. **處置方式**：營運者接獲通知或檢舉後，先行限制瀏覽或移除該等內容，保存證據並配合司法警察機關之調查。本節之處置不適用第 7 節之申訴緩衝程序。

## 3. 垃圾郵件與濫用行為

您不得為下列行為：

1. 傳送未經請求之大量商業郵件（UBE／UCE）、向未經同意之收件人行銷，或以本服務進行信箱暖機（warm-up）與位址驗證轟炸。上開行為可能違反收件地之法律（如美國 CAN-SPAM Act、歐盟 ePrivacy 指令、加拿大 CASL）；跨國傳輸以收件地法律為準。以個人資料行銷者，當事人表示拒絕接受行銷時，應即停止利用其個人資料行銷。
2. 以程式化手段批次註冊帳號、繞過人機驗證（Turnstile）、繞過註冊金鑰或配額限制。
3. 將本服務用作匿名轉發跳板或短期一次性濫發池，或以規避處置為目的反覆註冊。

## 4. 攻擊與干擾

您不得：

1. 對本服務或第三方系統進行掃描、探測、暴力破解；嘗試越權存取他人信箱、管理介面或其他使用者之資料。前揭行為可能構成犯罪，營運者並得依民事及行政途徑求償與處置。
2. 以無正當理由之方式使用 AI 翻譯、附件、API 等共用資源，致妨礙其他使用者之正常使用。
3. 對 Cloudflare、上游開放原始碼社群或營運者為騷擾、誹謗或權利濫用之行為。
4. 違反第三方服務（Cloudflare、Resend、Mailjet、Telegram 等）之使用條款。

## 5. 資源使用之一般義務

1. 您應依您帳號之儲存配額使用資源；配額由營運者依角色設定。
2. 帳號與 API 權杖不得出借、出租或轉讓予第三人使用。
3. 您以自備外部儲存（BYOS）與外部資料庫者，應自行確保該等服務符合其所在地法律對國際傳輸之要求。

## 6. 執行措施

營運者依違規之性質與情節輕重，採取比例相當之處置；兒少性剝削內容不適用階梯緩衝，逕依零容忍程序辦理。

## 7. 申訴與檢舉

1. **申訴**：您認為處置有誤者，得透過[服務條款](/zh-tw/mail/terms-of-service/)第 13 節所列管道申訴；營運者應於合理期限內複核並答覆。除情事緊急外，第 4 級以上之重大處置前，應給予說明之機會。
2. **檢舉**：任何人發現違反本政策之行為或安全隱患（垃圾郵件來源、釣魚郵件、越權存取嘗試等），得透過前述管道檢舉；善意檢舉一律獲核實處理。
3. **例外**：涉兒少性剝削內容或第 2 節之非自願性性影像者，營運者不適用申訴緩衝程序，逕行刪除、終止帳號，保存證據，並移交有權限機關處理。
