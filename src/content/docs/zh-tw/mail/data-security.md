# 資料處理與安全維護

**生效日期：2026 年 9 月 29 日｜版本：4.1**

本文件依[隱私權政策](/zh-tw/mail/privacy-policy/)第 10 節，說明本服務個人資料之生命週期、各類資料之處理矩陣，以及營運者依《個人資料保護法》第 20-1 條（非公務機關應辦理安全維護事項，防止個人資料被竊取、竄改、毀損、滅失或洩漏）及《個人資料保護法施行細則》第 12 條所建立之安全維護措施。本文件同時作為接受主管機關依《個人資料保護法》第 22 條實施檢查及當事人查閱之基礎文件。

## 3. 安全維護措施（對應施行細則第 12 條）

《個人資料保護法施行細則》第 12 條列舉「適當安全維護措施」得包括之事項。營運者依該條建立下列措施，全部十一項均已涵蓋：

| 施行細則第 12 條事項 | 本服務之落實 |
| --- | --- |
| 一、配置管理人員及相當資源 | 實例營運者指定管理員，依 RBAC 多級角色劃分權限 |
| 二、界定個人資料之範圍 | 本文件第 2 節之處理矩陣，明確界定各類資料 |
| 三、個人資料之風險評估及管理機制 | 三種郵件模式之加密選擇、失敗鎖定、限流與配額機制；開放原始碼公開受社群檢視 |
| 四、事故之預防、通報及應變機制 | 見本文件第 4 節 |
| 五、蒐集、處理及利用之內部管理程序 | [隱私權政策](/zh-tw/mail/privacy-policy/)第 5 節之處理活動對應表 |
| 六、資料安全管理及人員管理 | 密碼學雜湊路由（防越權存取）、預設拒絕（fail-closed）之權限檢查、非白名單參數於閘道剝離 |
| 七、認知宣導及教育訓練 | 自行部署營運者應自行辦理；本站文件可作為訓練素材 |
| 八、設備安全管理 | Cloudflare 邊緣設施承擔實體與虛擬設備安全（SOC 2 Type II、ISO/IEC 27001）；金鑰以環境變數注入，不入程式碼庫 |
| 九、資料安全稽核機制 | 安全日誌（登入 IP、裝置、失敗紀錄）留存並限稽核存取；工作階段得即時撤銷 |
| 十、使用紀錄、軌跡資料及證據保存 | 登入與安全日誌保存至帳號實體刪除；濫用事件之證據依[可接受使用政策](/zh-tw/mail/acceptable-use/)保存 |
| 十一、安全維護之整體持續改善 | 開放原始碼專案持續演進；重大安全修復隨版本發布並公告 |

技術措施要點：全站 HTTPS/TLS；HTML 郵件經 DOMPurify 於隔離之 Shadow DOM 淨化後呈現（阻斷腳本、內嵌事件與外部匯入）；附件下載強制 `Content-Disposition: attachment` 與 `X-Content-Type-Options: nosniff`；對 Webhook 與外部儲存端點實施 SSRF 防護（阻斷私有網段與雲端 metadata 位址）；郵件 ID 以 HMAC 混淆路由，防止越權列舉。

:::caution[加密之範圍與限制]
本服務「全部／隱私／加密」三種郵件模式之加密，係伺服器端靜態加密：金鑰由實例伺服器之環境變數與使用者識別衍生。此機制防護資料庫檔案遭竊取或快照洩漏之風險，並非端對端加密；掌握伺服器與金鑰之營運者在技術上具備解密能力。需要營運者亦無法讀取之保密強度者，應自行以 GPG 等端對端加密工具先加密郵件內文再行發送。
:::

## 4. 事件應變與通知

營運者知悉個人資料被竊取、竄改、毀損、滅失或洩漏時，採取下列措施：

1. 即時阻斷侵害來源（撤銷工作階段、封鎖來源、輪替金鑰）；
2. 評估影響範圍並留存紀錄（《施行細則》第 12 條第十款之軌跡資料與證據保存）；
3. 依《個人資料保護法》第 20-1 條第二項授權訂定之安全維護辦法及主管機關之規定，通知受影響之當事人並向主管機關通報；通知內容包括侵害事實、可能之危害、已採取之應變措施及當事人得採取之自保措施；
4. 就事件原因檢討並補強對應之安全措施（《施行細則》第 12 條第十一款之持續改善）。

## 5. 受檢之配合

依《個人資料保護法》第 1-1 條，本法之主管機關為個人資料保護委員會。依同法第 22 條，主管機關認非公務機關有違反本法之虞，或為檢視其落實本法情形而認有必要時，得通知陳述意見、要求提供必要之文書、資料、物品，或自行或會同中央目的事業主管機關、直轄市及縣（市）政府派員攜帶執行職務證明文件進入檢查。本服務營運者接受主管機關之檢查與稽核，無正當理由不得規避、妨礙或拒絕；本文件與[隱私權政策](/zh-tw/mail/privacy-policy/)即作為受檢之基礎文件。

依《個人資料保護法》第 25 條，主管機關就違法情事，除裁處罰鍰外，並得為禁止蒐集處理利用、命令刪除個人資料檔案、沒入或令銷毀違法蒐集之個人資料、公布違法情形之處分；營運者將依處分內容配合辦理。

自行部署之營運者，應就其實例獨立履行本節所列全部義務，並自行面對其所在地主管機關之稽核；本文件可作為其建立安全維護計畫之範本。
