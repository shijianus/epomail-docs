**生效日期：2026 年 10 月 5 日｜版本：5.17**

本頁逐一導覽 EpoCanvas Mail 的每一處介面及其路由。介面路徑由兩部分組成：路徑前綴 `/mail/u/N/`（N 為多帳號工作階段序號，單一帳號恆為 0）與 `#` 後的視圖路由（如 `#inbox`）；舊式直達路徑（如 `/inbox`）會自動正規化為完整形態。登入面獨立部署於 `/login/`。各路由之存取能力由身分分組權限決定，見[運行模式](/zh-tw/mail/modes/)；逐項設定之作用見[設定指南](/zh-tw/mail/settings/)。

![EpoCanvas Mail 收件箱全景：左側寫信入口與資料夾樹，右側郵件列表帶驗證碼徽標與官方認證標記](/images/mail/zh-tw/ui/views-guide.png)

*圖：收件箱（`#inbox`）。八視圖共用同一列表骨架，計數與標籤即時同步。*

<details>
<summary>圖解：收件箱全景——四個最先用到的入口</summary>

這張收件匣全景圖的四個標註分區，對應日常使用頻率最高的四個入口：寫一封新信、翻重要郵件、查延後事項與核對已傳送。

1. **寫信（側欄頂端主按鈕）**：全域唯一的新建郵件入口，點擊即彈出寫信彈層（非獨立路由）；行動裝置為右下懸浮按鈕，亦支援 `?composeTo=<地址>` 深鏈預填收件人。任何檢視下都能一鍵開始寫信。
2. **星標郵件（側欄資料夾）**：所有加星郵件跨資料夾匯聚於此：在列表列點擊星形圖示即入此檢視，用於收藏需要長期保留或快速再訪的郵件；側欄計數即時反映數量。
3. **稍後處理（側欄資料夾）**：延後跟進的暫存區，分「緊急」與「等待」兩檔：在詳情頁選「延後」並指定時間，到期自動回到收件匣頂端，重要事項不再沉底。
4. **已傳送（側欄資料夾）**：本帳號寄出的全部郵件存底，可在此核對哪些信已實際寄出；對外寄送量受帳號身分分組的每日寄件配額約束，站內信箱直投、站外經投遞通道。

</details>

## 1. 郵箱主介面

登入後進入的主介面按視圖路由區分，九個路由如下：

| 視圖路由 | 介面 | 主要內容 |
| --- | --- | --- |
| `#inbox` | 收件箱 | 預設視圖；時間正／倒序切換、新郵件輪詢增量插入、虛擬捲動列表、未讀紅點、會話彙聚 |
| `#all` | 全部郵件 | 跨資料夾彙總視圖；點擊側欄標籤即跳轉本視圖並按該標籤過濾 |
| `#message` | 郵件詳情 | 回覆／回覆全部／轉寄、星標、已讀未讀、移動到、舉報垃圾、延後處理、加標籤、表情回應、AI 全文翻譯、列印單封或會話、下載 .eml、檢視原始信頭、封鎖寄件人、由此建立篩選器 |
| `#sent` | 已送出 | 本帳號寄出的郵件 |
| `#drafts` | 草稿匣 | 本機草稿；未填收件人時顯示佔位標記 |
| `#starred` | 星標郵件 | 星標集合視圖 |
| `#snoozed` | 延後處理 | 分緊急與等待兩檔；到期自動回到收件箱 |
| `#spam` | 垃圾郵件 | 被系統或使用者判定為垃圾的郵件 |
| `#trash` | 垃圾桶 | 已刪除郵件；自收受之日起 7 日實體刪除 |

寫信為彈層而非獨立路由，觸發點有三：側欄「寫信」按鈕、行動裝置懸浮按鈕（需寄信權限）與深鏈 `?composeTo=<地址>`（開啟寫信窗並預填收件人）。

![EpoCanvas Mail 寫信視窗：寄件人鎖定目前信箱，富文字工具列與附件、傳送按鈕](/images/mail/ui/ui-compose.png)

*圖：寫信彈層。站內信箱直投，站外經營運者配置之通道投遞。*

<details>
<summary>圖解：寫信彈層自上而下的分區構成</summary>

寫信彈層自上而下的分區：寄件人鎖定、收件人與主旨、格式化文字工具列、正文編輯區與底部動作列。

- **寄件人列**：寄件人鎖定為目前登入信箱，寫信時不可手動改寫，因此本平台寄出的郵件不存在 From 偽造。多信箱帳號可在此下拉切換寄件身分，寄出後收件人看到的是所選信箱；寄件人地址亦決定寄出郵件走哪條投遞通道。
- **收件人與主旨列**：收件人支援聯絡人挑選與 `?composeTo=` 深鏈預填；主旨進入清單顯示並可被 `subject:` 檢索。
- **工具列與正文區**：17 項排版工具：段落、字號、字樣式、顏色、對齊、清單、引用、連結、圖片、表格、表情、翻譯與原始碼模式。
- **底部動作列**：附件按鈕（能力依身分分組開啟，單一附件上限依實例設定）與寄送按鈕；站內直投、站外經營運者配置通道投遞。

</details>

## 2. 介面骨架

主介面由四個區域構成：

| 區域 | 元素 |
| --- | --- |
| 頂欄 | 搜尋框（郵件頁搜郵件、設定頁搜設定項，見[搜尋與規則參考](/zh-tw/mail/search/)）、明暗切換、說明、公告鈴鐺（有未讀公告時顯示）、帳號選單（頭像、儲存用量條、帳號詳情、設定、登出；選單頁尾附專案介紹、隱私權政策與服務條款外連；多帳號模式另附切換、新增與全部登出） |
| 側欄 | 寫信按鈕、八個資料夾導覽與未讀計數、標籤區（至多 7 個）與新增標籤入口 |
| 狀態列 | 連線狀態、最近同步時間、未讀數、郵件模式徽標（加密模式下提示）與版本號 |
| 主區 | 目前視圖的列表或詳情 |

寬度低於 1025 像素時側欄收合為抽屜並以遮罩喚出，路由切換自動收起。

## 3. 設定區

進入設定後主區切換為設定面板，郵件側欄隨之隱藏。五個分區路由：

| 分區路由 | 分區 | 內容 |
| --- | --- | --- |
| `#settings/profile` | 個資 | 頭像、暱稱、性別、生日、信箱、電話與地址 |
| `#settings/general` | 一般 | 簡介、外觀色調、主題桌布、閱讀偏好、語言與資料隱私 |
| `#settings/security` | 安全 | 使用者名稱與通關密語、兩步驗證中心、通行金鑰、註銷帳號 |
| `#settings/data` | 資料 | 資料匯出、通知與轉寄、第三方應用授權、儲存空間 |
| `#settings/labels` | 標籤 | 標籤管理與分類規則建構器 |

![EpoCanvas Mail 一般設定頁：個性化區、主題桌布與外觀色調](/images/mail/ui/ui-settings-general.png)

*圖：一般分區。五個設定分區共用同一骨架，左欄為分區導覽。*

<details>
<summary>圖解：設定區的外殼——左欄導覽與右區內容</summary>

一般設定分區的外觀樣貌：左欄為五個設定分區的導覽，右區為一般項目（外觀色調、主題桌布等）。

- **左欄分區導覽**：個資／一般／安全／資料／標籤五分區切換；進入設定後郵件側欄隱藏，由「返回郵件」回主介面。
- **個性裝扮區**：外觀色調三態（暗色／亮色／跟隨系統）與全域主題桌布（八種預設 + 自訂圖片或 URL）。範圍是全站所有檢視，與僅涵蓋信箱區的「個人背景」不同；頂欄另有色調快捷切換，不必回到本頁。
- **其餘分組**：本頁剩餘三組設定：閱讀偏好（收件匣類型、閱讀窗格位置、會話檢視）、語言（介面語言六選一、AI 翻譯目標語言 16 選一）與資料隱私（個人資料處理與 AI 處理偏好的集中入口）。此圖僅示左欄與面貌，逐項含義見設定指南第 3 節。

</details>

## 4. 管理區

管理區路由為 `#manage/admin/<分區>`；路徑中的角色組段須與帳號身分相符（站長為 `admin`、協管者為 `moderator`），不符時自動歸位到可用分區。每個分區綁定獨立權限鍵，逐分組授權於權限控制頁：

| 分區路由 | 分區 | 權限鍵 | 職責 |
| --- | --- | --- | --- |
| `#manage/admin/analysis` | 分析頁 | `analysis:query` | 收發量、攔截率、來源分布、成長曲線與 AI 用量儀表 |
| `#manage/admin/users` | 使用者列表 | `user:query` | 帳號查詢、重設通關密語、調整分組、封禁與恢復 |
| `#manage/admin/mail` | 全部郵件 | `all-email:query` | 全庫郵件審查、`$` 進階檢索、詳情抽屜與實體刪除 |
| `#manage/admin/roles` | 權限控制 | `role:query` | 身分分組、配額範本與 AI 模型授權 |
| `#manage/admin/reg-keys` | 註冊密鑰 | `reg-key:query` | 邀請註冊碼的簽發與查驗 |
| `#manage/admin/system` | 系統設定 | `setting:query` | 實例級配置，配置卡清單見[設定指南](/zh-tw/mail/settings/) |
| `#manage/admin/apps` | 應用管理 | `setting:query` | OAuth 2.0／OIDC 第三方應用憑證 |
| `#manage/admin/rules` | 分類管理 | `setting:query` | 收發開關、AI 識別、黑白名單與硬攔截 |
| `#manage/admin/audit` | 操作報告 | `setting:query` | 四類預警的研判、處置與申訴裁決 |

![EpoCanvas Mail 操作報告頁：四類預警工單與處置按鈕](/images/mail/ui/ui-audit-report.png)

*圖：操作報告（`#manage/admin/audit`）。列表研判，處置按鈕按預警類別分流。*

<details>
<summary>圖解：操作報告在管理端的表格化樣貌</summary>

操作報告頁的管理端樣貌：預警工單表格化研判，處置按鈕依預警類別分流。

- **工單表格**：每列一條預警工單，欄含類別（稽核／風控／封鎖／申訴）、優先級（P0／P1）、目前狀態，以及活躍環境池的純文字資訊——IP、地理、裝置與指紋。環境池依請求行為聚合，同一帳號在多 IP 並行登入時才會累積出可見的異常特徵。
- **處置按鈕**：按鈕隨工單類別分流：申訴警告把「研判放行」提到最顯眼處（放行即復原帳號），封鎖警告突出「解除預警」，其餘類別走標準操作選單。按鈕只提交研判結論，真正的封鎖與復原仍由使用者清單頁落地，兩頁狀態同步。
- **模式連動**：同一張表在三種郵件模式下形態不同：全部郵件模式（L1）資訊最全；隱私模式（L2）下本頁即圖中樣貌；加密模式（L3）記錄時間戳記被剝離、時間欄隱藏，管理員只能憑類別與環境池研判，無法還原事件發生次序。

</details>

## 5. 登入面

`/login/` 為獨立的登入應用，與主介面分離部署。同一登入卡承載全部流程：

| 流程 | 行為 |
| --- | --- |
| 通關密語登入 | 帳號（信箱）與通關密語提交；連續失敗觸發防暴力破解鎖定 |
| 兩步驗證 | 驗證器應用程式（TOTP 六位碼）、備用復原碼與通行金鑰三選一或多重依次驗證；勾選「以後此裝置登入不再驗證」發放 30 天信任 |
| 第三方登入 | 管理員啟用並配置密鑰的提供者顯示為按鈕；開啟而未配置密鑰的灰顯「即將上線」 |
| 註冊 | 信箱（可選預設網域後綴）、通關密語與註冊碼；註冊碼模式分為必填、關閉與選填三檔，URL 可攜帶邀請碼參數 |
| 忘記通關密語 | 彈窗跳轉外部申訴門戶，攜帶申訴類型、介面語言與信箱參數 |
| 新增帳號 | 多帳號模式下經 `?action=addAccount&u=N` 進入，登入後落入對應工作階段位 |

![EpoCanvas Mail 登入頁：信箱與通關密語輸入框、保持軌道連線勾選框與第三方快捷登入按鈕](/images/mail/ui/ui-login-oauth.png)

*圖：登入頁。第三方按鈕的三態顯示規則見[運行模式](/zh-tw/mail/modes/)第 4 節。*

<details>
<summary>圖解：登入頁承載的全部流程</summary>

登入面的整體樣貌：同一張登入卡承載密碼登入、兩步驗證、第三方快捷登入、註冊與忘記密碼全部流程。

- **輸入區**：本頁最常走的路徑：信箱即帳號，密碼經加鹽雜湊儲存、伺服器端不接觸明文。連續失敗會觸發防暴力破解鎖定，鎖定粒度與時長由後端策略決定；勾選「保持軌道連線」後本裝置 30 天內免重複驗證。
- **第三方按鈕區**：管理員已啟用並配置密鑰的提供者顯示為按鈕；已開啟而未配置密鑰的灰顯「即將上線」，未啟用的不顯示。
- **其餘流程**：同一張卡還承載另外三條路徑：已開啟兩步驗證的帳號提交後進入第二驗證（TOTP、備用碼或通行密鑰）；註冊碼模式下可攜帶 code 參數直接預填註冊表單；「忘記密碼」跳轉外部申訴入口並帶上申訴類型、介面語言與信箱。逐條規則見運行模式第 4 節。

</details>

## 6. 獨立頁面與全域能力

| 介面 | 路由 | 說明 |
| --- | --- | --- |
| OAuth 授權頁 | `#/oauth/authorize` | 第三方應用申請授權時顯示：應用資訊、官方認證徽章、存取範圍清單與授權／取消 |
| 公開個人主頁 | `/<使用者名稱>` | 未登入可存取；展示頭像、時區、身分分組、加入時間、個人資料看板與「郵件聯絡我」；是否開放由管理員「公開個人主頁」開關決定 |
| 404 頁 | 其餘路徑 | 未知路徑的空狀態頁與回首頁入口 |
| PWA | — | Web 端可安裝為應用；另提供 Android 應用（epomail） |

郵件模式亦改變管理介面：加密模式（Level 3）下全庫郵件審查入口隱藏、操作報告剥离時間戳記，見[運行模式](/zh-tw/mail/modes/)第 2 節。
