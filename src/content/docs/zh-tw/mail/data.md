**生效日期：2026 年 10 月 6 日｜版本：5.15**

本頁說明「設定 → 資料」頁的匯出與儲存兩部分。同頁的通知與轉寄見[通知與轉寄指南](/zh-tw/mail/notify/)；匯出資料的法定地位見[資料處理與安全維護](/zh-tw/mail/data-security/)。

![EpoCanvas Mail 資料頁：三類匯出卡與儲存用量儀表、個人物件儲存接入](/images/mail/ui/ui-settings-data.png)

*圖：資料頁。匯出與儲存管理同頁呈現，附件用量以身分分組配額計算。*

## 1. 三類匯出

| 匯出項 | 格式 | 範圍 |
| --- | --- | --- |
| 匯出全量資料 | JSON | 完整備份：帳號個資、歷史郵件、通訊錄、分類與標籤規則及安全設定 |
| 郵件歷史歸檔 | MBOX（通用）、JSON 或 CSV | 僅收發郵件，可限定時間範圍 |
| 通訊錄與配置 | JSON | 聯絡人名錄、自訂別名規則與系統個人化偏好 |

單封郵件可在閱讀頁直接下載為 .eml。垃圾桶郵件 7 日實體刪除且不可復原，需要留存請先匯出（見[服務條款](/zh-tw/mail/terms-of-service/)第 8 節）。

## 2. 儲存空間

- 附件儲存用量儀表即時顯示用量與配額，配額以身分分組（出廠值見[運行模式](/zh-tw/mail/modes/)第 3 節）；
- 可接入個人物件儲存（自備 Backblaze B2 或 S3 儲存桶）：接入後新附件直接保存於您的雲端，不再佔用實例配額；平台對 B2 的推薦基於其免費額度與 0 對外流量費；
- 接入狀態隨時可解除，解除後新附件回落至實例儲存。
