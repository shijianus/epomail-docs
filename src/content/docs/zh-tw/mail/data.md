<summary>圖解：資料頁——個人資料自主的四個分區</summary>

資料頁的四張卡片：資料帶走的三種格式、一個轉寄區、一個儲存區與一個第三方授權區，個人資料自主的完整介面。

1. **使用者資料與資料匯出卡**：三類匯出並列：全量 JSON 備份、郵件歷史歸檔（MBOX／JSON／CSV + 時間範圍）與通訊錄配置；單封郵件另可在閱讀頁下載 .eml。
2. **郵件與訊息轉寄卡**：Telegram 訊息推送與自動轉寄的逐項配置；兩項功能是否對帳號開放由管理員「使用者資料控制」開關決定。
3. **儲存空間卡**：附件儲存用量儀表即時對照配額；可接入自備 Backblaze B2／S3 儲存桶，接入後新附件直存個人雲端、不受實例配額約束，解除接入即回落。
4. **第三方應用和服務卡**：使用者名下全部 OAuth 授權的應用清單：逐應用移除存取權限，或經詳情彈窗一鍵撤銷全部；撤銷即時生效，應用現有權杖立即失效。

</details>

## 1. 三類匯出

| 匯出項 | 格式 | 範圍 |
| --- | --- | --- |
| 匯出全量資料 | JSON | 完整備份：帳號個資、歷史郵件、通訊錄、分類與標籤規則及安全設定 |
| 郵件歷史歸檔 | MBOX（通用）、JSON 或 CSV | 僅收發郵件，可限定時間範圍 |
| 通訊錄與配置 | JSON | 聯絡人名錄、自訂別名規則與系統個人化偏好 |

單封郵件可在閱讀頁直接下載為 .eml。垃圾桶郵件 7 日實體刪除且不可復原，需要留存請先匯出（見[服務條款](/zh-tw/mail/terms-of-service/)第 8 節）。

## 2. 儲存空間

- 附件儲存用量儀表即時顯示用量與配額，配額以身分分組（出廠值見[運行模式](/zh-tw/mail/modes/)第 3 節）；
- 可接入個人物件儲存（自備 Backblaze B2 或 S3 儲存桶）：接入後新附件直接保存於您的雲端，不再佔用實例配額；平台對 B2 的推薦基於其免費額度與 0 對外流量費；
- 接入狀態隨時可解除，解除後新附件回落至實例儲存。

<details>
<summary>圖解：匯出與儲存的操作步驟</summary>

![匯出與儲存的操作步驟](/images/mail/zh-tw/ui/data.png)

1. 進入「設定 → 資料」。
2. 「匯出全量資料」打包下載 JSON 完整備份（含個資、歷史郵件、通訊錄、規則與安全設定）。
3. 「郵件歷史歸檔」選擇 MBOX／JSON／CSV 格式與時間範圍後下載。
4. 「通訊錄與配置」匯出聯絡人名錄與個人化偏好。
5. 儲存卡查看附件用量；點「接入儲存桶」綁定自備 Backblaze B2／S3，之後附件直存個人雲端。

</details>
