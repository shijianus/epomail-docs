資料頁的四張卡片：資料帶走的三種格式、一個轉寄區、一個儲存區與一個第三方授權區，個人資料自主的完整介面。

1. **使用者資料與資料匯出卡**：提供 JSON 資料匯出、郵件歸檔（MBOX／JSON／CSV）與個人資料及標籤匯出；三者均來自同一後端回應，時間範圍參數未生效，單封 .eml 亦由現有欄位重新組成。
2. **郵件與訊息轉寄卡**：Telegram 訊息推送與自動轉寄的逐項配置；兩項功能是否對帳號開放由管理員「使用者資料控制」開關決定。
3. **儲存空間卡**：顯示郵件與附件的計量用量及有效配額；自備 Backblaze B2／S3 可承接新附件並繞過附件保存路徑的系統配額檢查，其他郵件限制仍適用；解除接入不會遷移舊物件。
4. **第三方應用和服務卡**：顯示 OAuth 授權並提供撤銷操作。後端刪除對應授權並記錄撤銷狀態，userinfo 請求據此拒絕存取；不能保證第三方會話、已取得資料及全部現有權杖同步回收。

## 1. 三類匯出

| 匯出項 | 格式 | 範圍 |
| --- | --- | --- |
| 匯出全量資料 | JSON | 部分帳號與個人資料、`is_del=0` 郵件的選定欄位及 `customLabels`；不含附件檔案、原始 MIME、完整聯絡人／別名資料、安全設定或稽核記錄 |
| 郵件歷史歸檔 | MBOX、JSON 或 CSV | 瀏覽器將同一回應的郵件欄位轉換成所選格式；後端忽略 `type/format/range`，未依所選時間範圍篩選，垃圾桶郵件被排除 |
| 通訊錄與配置 | JSON | 僅後端回傳的 profile 子集、customLabels 與匯出時間；不是完整通訊錄、別名規則或全部偏好的備份 |

單封 .eml 與批次 MBOX 均由已有欄位重新組成，不包含完整原始 MIME 或附件檔案。垃圾桶依郵件建立時間超過 7 天清理，不保證移入後再保存 7 天；請在刪除前另存附件並核對匯出內容，範圍與權利見[隱私權政策](/zh-tw/mail/privacy-policy/)。

本輪本機實作另將完整原始 MIME 以伺服器端 AES-256-GCM 加密後暫存在物件儲存，用於投遞恢復。應用設定 7 天清理期限，失敗重試可延長期限，成功入庫亦不立即刪除；排程分批清理，清理失敗的物件保留待重試，因此不是儲存層 TTL 到期即刪除的保證。此暫存不納入自助匯出，單封 .eml 與 MBOX 仍由欄位重建，亦不證明線上實例已全部部署。

目前本機實作會在一般登出時清除目前工作階段、目前郵件快取與收件人歷史，保留其他帳號工作階段及本機草稿；刪除草稿清單項目時，草稿與 `att` 附件在同一 IndexedDB 交易內刪除。這些本機內容不在伺服器匯出中。

共用或轉讓裝置前，先另存所需草稿，再於「設定 → 資料 → 隱私與本機資料」選擇「清除本機全部本站資料」。確認範圍包括此瀏覽器內本站所有帳號的登入、裝置信任、快取、設定、草稿及附件，並會登出；阻擋或部分失敗須依提示重試，或透過瀏覽器清除本站資料，不能視為已全部清除。此操作不撤銷所有伺服器憑證，亦不刪除其他網站資料、聊天副本、伺服器靜態頭像、稽核記錄或備份。同卡的自動驗證碼辨識預設關閉，須個人選用、服務已設定且提供資料去向說明才可開啟。以上為本輪本機實作，不證明所有線上實例已部署；同源儲存邊界見隱私權政策第 4.3 節。

## 2. 儲存空間

- 附件儲存用量儀表即時顯示用量與配額，配額以身分分組（出廠值見[運行模式](/zh-tw/mail/modes/)第 3 節）；
- 可接入個人 Backblaze B2／S3 儲存桶；啟用後新附件依個人設定保存，附件保存路徑可繞過系統配額檢查，但統計與其他郵件限制仍存在。服務商費用及外部保存規則須另行確認，見[第三方處理者清單](/zh-tw/mail/sub-processors/)；
- 解除接入不遷移或刪除原桶物件。舊附件的 BYO 來源定位保留，待物件清理佇列確認後才結束相關處理，不能把解除接入當成清理完成；舊附件可讀性及刪除限制見[資料處理與安全維護](/zh-tw/mail/data-security/)。

<details>
<summary>圖解：匯出與儲存的操作步驟</summary>

![匯出與儲存的操作步驟](/images/mail/zh-tw/ui/data.png)

1. 進入「設定 → 資料」。
2. 「匯出全量資料」下載選定個人資料、未刪郵件欄位與 customLabels 的 JSON；附件、完整通訊錄及安全設定須另行處理。
3. 「郵件歷史歸檔」選擇 MBOX／JSON／CSV 後下載；格式由瀏覽器轉換，後端不套用時間範圍。
4. 「通訊錄與配置」匯出回傳的 profile 子集與 customLabels；請核對所需聯絡人和偏好是否包含。
5. 儲存卡查看附件用量；點「接入儲存桶」綁定自備 Backblaze B2／S3，之後附件直存個人雲端。

</details>
