<summary>圖解：收件箱全景——四個最先用到的入口</summary>

這張收件匣全景圖的四個標註分區，對應日常使用頻率最高的四個入口：寫一封新信、翻重要郵件、查延後事項與核對已傳送。

1. **寫信（側欄頂端主按鈕）**：全域唯一的新建郵件入口，點擊即彈出寫信彈層（非獨立路由）；行動裝置為右下懸浮按鈕，亦支援 `?composeTo=<地址>` 深鏈預填收件人。任何檢視下都能一鍵開始寫信。
2. **星標郵件（側欄資料夾）**：所有加星郵件跨資料夾匯聚於此：在列表列點擊星形圖示即入此檢視，用於收藏需要長期保留或快速再訪的郵件；側欄計數即時反映數量。
3. **稍後處理（側欄資料夾）**：延後跟進的暫存區，分「緊急」與「等待」兩檔：在詳情頁選「延後」並指定時間，到期自動回到收件匣頂端，重要事項不再沉底。
4. **已傳送（側欄資料夾）**：本帳號寄出的全部郵件存底，可在此核對哪些信已實際寄出；對外寄送量受帳號身分分組的每日寄件配額約束，站內信箱直投、站外經投遞通道。

</details>

## 1. 八個檢視

| 檢視 | 行為要點 |
| --- | --- |
| 收件匣 | 預設檢視；時間正／倒序切換、新郵件輪詢增量插入、虛擬捲動列表、未讀紅點、會話彙聚 |
| 全部郵件 | 跨資料夾彙總；點擊側欄標籤即按該標籤過濾 |
| 已傳送 | 本帳號寄出之郵件 |
| 草稿匣 | 本機 IndexedDB 的 `draft` 與 `att` 附件；一般登出保留草稿，刪除清單項目時兩表在同一交易內一併刪除 |
| 星標郵件 | 星標集合 |
| 延後處理 | 分緊急與等待兩檔；到期自動回入收件匣 |
| 垃圾郵件 | 排程以郵件建立時間判斷，預設超過 7 日轉入垃圾桶；不是移入垃圾郵件後保證再存 7 日 |
| 垃圾桶 | 固定 7 日門檻亦按建立時間計算，可能與垃圾轉入發生於同輪；超過配額 90% 時執行刪除也可能直接實體清除 |

## 2. 郵件詳情頁動作

| 分組 | 動作 |
| --- | --- |
| 回覆類 | 回覆、回覆全部、轉寄；內嵌回覆與表情回應 |
| 整理類 | 星標、已讀／未讀、移動到（收件匣／垃圾／垃圾桶）、歸檔、延後（預設時間或自選）、加標籤、檢舉垃圾／非垃圾 |
| AI 類 | 全文翻譯逐次告知資料去向並確認，OCR 預設關閉；驗證碼自動辨識預設關閉，須個人選用且服務已設定 |
| 輸出類 | 列印單封或會話、由現有欄位重建並下載 .eml、檢視程式提供的信頭欄位；自助匯出不含投遞恢復所暫存的完整原始 MIME |
| 治理類 | 封鎖寄件人、由此建立篩選器（打標籤／標已讀／進垃圾／進垃圾桶） |

## 3. 寫信彈層

寫信為彈層（非獨立路由），入口：側欄「寫信」按鈕、行動裝置懸浮按鈕（需寄信權限）、深鏈 `?composeTo=<地址>`（預填收件人）。

- 收件人支援聯絡人選擇；站內信箱直投，站外經營運者配置之通道投遞；
- 格式化文字工具列 17 項：段落、字號、粗體、斜體、底線、刪除線、顏色、對齊、有序與無序清單、引用、分隔線、連結、圖片、表格、表情、翻譯與原始碼模式；
- 附件能力依帳號角色開啟，單一附件上限依實例設定。

## 4. 會話與排版

郵件詳情支援會話彙聚、排版分層與懸浮快捷回覆；介面信頭與下載的 .eml 仍由欄位重建，不能當作完整原始 MIME 的下載；用於投遞恢復的加密暫存與清理期限見[資料匯出與儲存](/zh-tw/mail/data/)。本輪本機實作預設阻擋郵件中的遠端圖片、網路樣式與主動內容；一般閱讀可在知悉 IP 位址及開啟紀錄可能外傳後，僅為目前郵件允許圖片。列印預設仍阻擋遠端內容，Telegram 分享閱讀不提供遠端內容載入；安全的內嵌圖片與已確認的本站附件不等同第三方追蹤資源。

一般登出清除目前工作階段、目前郵件快取與收件人歷史，保留其他帳號工作階段及本機草稿；全部本站本機資料須透過[資料頁清理操作](/zh-tw/mail/data/)另行確認刪除。這些行為是目前本機程式碼狀態，不證明所有線上部署均已更新。儲存邊界見[隱私權政策](/zh-tw/mail/privacy-policy/)第 4.3 節；官方郵件的標記與說明見[防竄改與官方規範](/zh-tw/mail/tamper-proof/)。

<details>
<summary>圖解：信箱檢視與詳情的操作步驟</summary>

![信箱檢視與詳情的操作步驟](/images/mail/zh-tw/ui/views.png)

1. 登入後預設進入收件匣（`/mail/u/0/#inbox`）；頂欄按鈕切換時間正／倒序。
2. 新郵件由輪詢自動插入清單頂部，未讀以紅點標示；側欄資料夾樹在八個檢視間切換。
3. 點擊側欄標籤，清單即切到「全部郵件」並按該標籤過濾。
4. 點擊任一郵件進入詳情檢視（`#message/<hash>`）：回覆、星標、延後、加標籤、翻譯、下載 .eml 等動作見頁內動作欄。

</details>
