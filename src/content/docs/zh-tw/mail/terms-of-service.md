# 服務條款

**生效日期：2026 年 9 月 29 日｜版本：4.1**

本條款是您與您所用實例之營運者之間，關於使用 EpoCanvas Mail 服務（下稱「本服務」）之約定。您完成註冊、登入或以其他方式使用本服務，即表示您已閱讀並同意本條款之全部內容；不同意者，請勿註冊或使用本服務。

本條款為定型化契約條款。依《消費者保護法》第 11-1 條，企業經營者與消費者訂立定型化契約前，應有三十日以內之合理期間供消費者審閱全部條款內容；本條款全文於註冊頁公開可閱，歷史版本隨開放原始碼儲存庫存檔。本條款之解釋並受《民法》第 247-1 條之規制：依照當事人一方預定用於同類契約之條款所為之約定，按其情形顯失公平者，該部分約定無效。依《電子簽章法》第 4 條，您以電子方式所作之同意，在功能上等同於實體文件及簽章，不得僅因其電子形式而否認其法律效力。

本站法律文件以本繁體中文（臺灣）版本為正式版本，其他語言版本僅供參考；內容如有歧異，以繁體中文版本為準。

## 1. 定義

1. **本服務**：運作於某一 EpoCanvas Mail 實例上之全部功能，包括網頁端、行動應用程式（epomail）、開放 API 及相關元件。
2. **營運者**：部署並運作您所用實例之個人或團隊。就託管實例 `mail.epocanvas.com` 而言，指 EpoCanvas 營運團隊；就自行部署實例而言，指其部署者。
3. **您（當事人）**：註冊、登入或以其他方式使用本服務之自然人或組織。
4. **契約成立**：您於哪一個實例註冊，即與該實例之營運者成立契約。本條款為通用範本：託管實例直接適用；自行部署營運者得修改後作為其站點條款，並應依《個人資料保護法》第 8 條向其使用者履行告知義務。

## 2. 服務之說明

本服務提供多信箱管理、站內外郵件收發、附件收發、標籤與星號、垃圾郵件隔離、延後提醒、搜尋、AI 翻譯（選用）、驗證碼自動提取（選用）、Telegram 推播（選用）、兩步驟驗證（TOTP／通行金鑰）、OAuth 開放平台及資料匯出等功能；實際可用功能以實例所開啟者為準。

本服務基於 MIT 授權條款之開放原始碼專案建置並延續開源：原始碼公開可稽核，您得自行部署取得同等能力。軟體本身依「現狀」提供，其授權條款與本條款之責任約定相一致（見第 10 節）。

## 3. 帳號之申請與安全

1. **註冊資訊**：註冊須提供有效之收件信箱地址與密碼。您不得冒用他人名義，亦不得使用您無權使用之網域。
2. **資格**：您應確認年滿 14 歲；未滿 14 歲者不得使用本服務。您並應確保註冊與使用行為於您所在地法律允許之範圍內為之。
3. **憑證保管**：您對密碼、兩步驟驗證憑證及 API 權杖負保管責任。經由您憑證所為之操作，推定為您本人之行為。
4. **兩步驟驗證**：建議啟用 TOTP 或通行金鑰。採「加密郵件模式」之實例，營運者得依安全政策要求強制啟用。
5. **登入保護**：連續 5 次密碼錯誤將鎖定登入 12 小時；同一帳號最多維持 10 個活躍工作階段，您得於任一裝置登出以即時撤銷權杖。
6. **註冊限制**：`admin` 等識別字為系統保留；營運者得將實例設定為憑註冊金鑰註冊或關閉註冊，此屬實例管理權限。

## 4. 服務之提供與變更

1. **可用性**：本服務運作於 Cloudflare 邊緣設施，營運者盡合理努力維持可用性，但不承諾特定之可用率、投遞時效或故障復原時限，亦不提供服務水準協議（SLA）。
2. **功能變更**：開放原始碼專案持續演進，功能可能新增、調整或移除；涉及資料刪除能力之重大變更將預先公告。
3. **實驗性功能**：標示「實驗」或處於測試期之功能（如圖片文字辨識翻譯）依現狀提供，可能不穩定，並得隨時調整或下線。
4. **維護與中斷**：營運者得因升級、修復或濫用處置暫停部分或全部服務；因 Cloudflare 或上游 AI、投遞服務商故障所致之不可用，非屬營運者違約。

## 5. 您的內容

1. **所有權**：您收發之郵件及其附件之所有權與責任歸屬您本人。營運者不為廣告、模型訓練或讓與之目的利用您的內容。
2. **處理授權**：為提供儲存、投遞、搜尋、推播及（選用之）翻譯功能，您授權營運者僅於營運本服務所必需之範圍內進行技術處理；您停止使用且資料經刪除後，授權終止。
3. **傳送責任**：您對您傳送之每一封郵件負責；因傳送內容所生之爭議與法律責任，由您承擔。
4. **內容可及性之告知**：營運者原則上不主動審查您之正常郵件。惟「全部郵件模式」下管理員技術上得讀取全部郵件（隱私模式下僅限垃圾、已刪除與無主郵件），並於接獲檢舉或依法令要求時處置。您選擇實例前，應了解其運作模式；對保密強度有要求者，見[隱私權政策](/zh-tw/mail/privacy-policy/)第 10 節加密範圍之說明。

## 6. 外寄投遞與第三方服務

1. **外寄投遞**：寄往站外之郵件經營運者配置之通道（Cloudflare Email Workers、Resend 或 Mailjet）投遞。第三方投遞可能延遲、退信或為收件方服務商攔截，營運者對投遞結果不為保證。
2. **第三方條款**：您使用 Telegram 推播、AI 翻譯、Linux DO 登入、外部 S3 儲存等功能時，並受該第三方服務條款拘束。
3. **OAuth 開放平台**：您經 OAuth 授權第三方應用者，其授權範圍（openid / profile / email）與撤銷方式見[隱私權政策](/zh-tw/mail/privacy-policy/)第 9 節；第三方應用對資料之使用依其自身條款。

## 7. 可接受使用

您使用本服務，應遵守[可接受使用政策](/zh-tw/mail/acceptable-use/)之全部規定，包括禁止傳輸違法內容、濫發垃圾郵件、攻擊系統或干擾他人使用。違反者，營運者得依該政策所定程序處置，直至刪除帳號及全部資料，並依法保存證據配合有權機關之調查。

## 8. 資料之保存、移除與帳號終止

1. **您終止**：您得隨時於設定中自助註銷帳號，或請求營運者刪除。註銷後工作階段即時失效；郵件進入軟刪除狀態，至管理員執行實體刪除為止。
2. **系統例行清理**：垃圾郵件隔離 7 日後轉入垃圾桶；垃圾桶郵件自收受之日起 7 日後由系統實體刪除（含附件）。刪除不可復原；請先以「資料匯出」取得 JSON 副本。
3. **營運者終止**：您違反[可接受使用政策](/zh-tw/mail/acceptable-use/)時，營運者得依該政策暫停或終止您之使用權。
4. **法定保存**：因法令要求或司法程序所必要之保存，營運者得於必要範圍內延後刪除，並依法定程序處理。

## 9. 處置之通知與救濟

營運者依「可接受使用」或前節暫停、終止您之使用權前，除情事緊急（如進行中之攻擊、違法內容之傳輸）外，應通知您並給予說明或補正之機會。您認為處置有誤者，得依[可接受使用政策](/zh-tw/mail/acceptable-use/)「申訴與檢舉」節之程序申訴，營運者應於合理期限內複核並答覆。

本條款所定之通知以電子文件為之者，其發文及收文時間依《電子簽章法》第 9 條認定：收文者已指定收受電子文件之資訊系統者，以文件進入該系統之時間為收文時間；未指定者，以文件進入收文者資訊系統之時間為收文時間。您註冊時所留電子郵件地址即為電子通知之送達處所，您應維持該地址可正常收信。
