## 4. 儲存與存取的實際範圍

### 4.1 帳號與安全資料

新寫入的密碼驗證採用加鹽 PBKDF2-HMAC-SHA256，預設 210,000 次迭代且可配置；歷史 SHA-256 或較低參數記錄可在驗證時升級，不能保證所有存量已完成遷移。TOTP 密鑰加密保存；復原碼有驗證用雜湊，另保存以密鑰加密、可於重新驗證後顯示的原碼副本；通行金鑰保存公開憑證資料。這些措施降低風險，並非保證密碼永不可被猜解。TOTP 設定流程可在 KV 暫存未加密設定密鑰 600 秒；歷史密碼升級遇到多因素驗證時，可在待完成的 KV 流程暫存輸入密碼 300 秒並可能續期，故不能聲稱任何路徑都不保存明文憑證。個人欄位、登入來源、操作紀錄與權限設定亦可能存於實例資料庫或 KV。

### 4.2 郵件與附件

郵件資料主要由 Cloudflare D1 與配置的物件儲存處理；附件可依使用者或營運者配置存於 S3 相容儲存、R2，或在未配置時使用 KV。已核對的入站路徑讀取並解析原始 MIME，未另持久保存完整原始郵件；下載 .eml 並不證明保留了原始檔。外部備援、資料庫與自行修改的保存行為須另行確認，實際資料位置不能僅由原始碼推定。

服務不提供端對端加密。「加密」與「隱私」模式依程式及設定對部分正文、主旨作伺服器端靜態加密；附件與路由中繼資料不自動納入該保護，掌握伺服器及密鑰者在技術上可能解密。

### 4.3 瀏覽器、日誌與外部請求

瀏覽器可在 localStorage 保存登入權杖、語言與介面偏好；登出與伺服器撤銷、憑證有效期是不同機制。在共用裝置使用後應登出並清除不需保留的本機資料。

登入安全機制亦處理 IP 衍生的國家／城市、網路 ASN 及裝置資訊。已知環境清單最多保留最近 15 筆並使用 180 日滑動 TTL，持續使用可能使期限續延；IP 多帳號關聯項目使用 7,200 秒 TTL。可信裝置憑證可保存 60 日，前 30 日可能用於免除部分多因素驗證。這些與帳號欄位或稽核日誌的保存並非同一週期。

Cookie 規則亦可能涵蓋 localStorage 等終端儲存或讀取。適用 ePrivacy 終端存取規範時，僅為傳送通訊或提供您明確要求的服務所嚴格必要的存取，才可依相應例外免事先同意；登入或安全標籤本身不表示符合例外。其他終端存取須在啟動前清楚告知並取得有效同意，同意前不得啟動。拒絕不應使無關的基本功能失效，撤回須與給予同意同樣容易，撤回後停止相應存取。不能以未使用 Cookie 免除上述要求。

字型、Turnstile、外部圖片及其他配置的資源可能收到 IP、User-Agent、時間及請求資料；閱讀遠端郵件圖片也可能向寄件方暴露開啟情況。沒有廣告或分析 SDK 不等於沒有第三方網路請求。完整資料流見[第三方處理者清單](/zh-tw/mail/sub-processors/)。

### 4.4 管理與除錯存取

管理介面依郵件模式、角色及權限限制可見範圍；這不是營運者在技術上絕對不能接觸資料的保證。人工存取限處理具體支援、安全事故、濫用檢舉、合法請求或其他有依據且必要的事項，採最小權限並保留適當紀錄。禁止以學習、測試或好奇為由隨意閱讀真實郵件，亦不得將其貼入公開 Issue 或除錯服務。

公開個人頁面預設關閉；開啟後，匿名訪客可取得主信箱、個人欄位、角色、加入時間及郵件活動／來源統計。部分「隱藏統計」設定僅控制畫面，不能當作 API 存取限制；帳號軟刪除也未證實會關閉該公開路徑。需要撤回公開時應同時關閉頁面並請營運者核對匿名存取，在修正前勿用該功能公開不必要的真實資料。

### 4.5 敏感與第三人的資料

郵件可能包含健康、種族、宗教、政治意見、工會、基因、生物辨識、性生活或性傾向等特殊類別資料；犯罪紀錄另受特別限制。僅稱「被動儲存」或取得帳號使用者的一般同意，不會自動滿足相關額外法律要件。測試應使用合成或已依法去識別的內容；目前不以承接受監管的敏感資料處理為服務目的，未確認合法依據及保障前，不應上傳此類真實資料。

## 6. AI 與選用內容處理

已核對的程式包含收件時的驗證碼提取，以及您操作後的翻譯、圖片文字辨識。實際資料可能包括主旨、正文片段、圖片及其中的身分或敏感內容，不能保證文本中沒有個人資料。OpenAI 相容協定只描述介面，不表示接收者必然為 OpenAI。

驗證碼提取的全站開關在本次核對版本預設關閉；啟用後，新信抵達時可自動向 Workers AI 傳送完整主旨及最多 6,000 個 JavaScript 字元的正文文字，主旨不計入此上限。這並非每次均由您按鈕觸發，亦未見逐使用者退出判斷。全站開關不等同每位使用者的有效同意。部署者在缺少有效依據、所需選擇或可履行的撤回機制時，應停用相應外傳；請求使用者搬到另一實例，不能代替自由撤回或證明先前已取得同意。

文字翻譯可能使用配置的模型或 Workers AI，部分流程會向 MyMemory 或 Google 翻譯公共介面傳送文本片段，包含經 URL 查詢參數傳送的情形；缺漏片段的備援不僅發生於整體端點失效時。OCR 可將內嵌圖片位元組傳至 Workers AI，或將遠端圖片 URL 傳至配置的外部視覺端點；辨識出的文字再進入翻譯流程。用戶端 OCR 預設關閉，但省略參數的 API 呼叫可能採不同預設，不能以介面開關推論所有路徑都沒有圖片處理。

對具有個人或機密資料的郵件，未確定接收者、受託契約、保存與跨境保障前，應停用該路徑。一次按下翻譯，不是對未披露接收者或後續模型訓練的概括同意；某些圖片可能在翻譯工作流程中被提取，不僅限於您另外上傳的圖片。

營運者不將郵件作為自行訓練模型的資料集；第三方的保存、訓練與再利用限制須以實際契約及配置確認，不憑本政策代其作保。AI 結果可能有誤，驗證碼、翻譯與辨識輸出應由您核對；本服務不以此提供具法律效果的專業判斷。在適用範圍內應清楚標示 AI 功能及輸出，依實際角色與用途履行必要透明告知；一般翻譯或辨識不因使用 AI 就當然屬高風險系統，亦不因此取得合規認證。

## 7. 接收者與國際傳輸

依實際配置，接收者包括 Cloudflare、外寄投遞服務、您或營運者指定的儲存與資料庫、身分源、AI／翻譯服務、通知平臺、經授權應用及收件人的郵件服務商。各方是否為受託處理者或獨立控管者依其實際用途及契約判斷，不能全數列為僅按指示處理。

Cloudflare 全球網路或非歐盟供應者的使用不保證資料僅在歐洲經濟區內處理。GDPR 限制的跨境傳輸，須先確認實際地區與合法機制，例如對應範圍的充分性決定，或已有效訂立的標準契約條款、傳輸影響評估及必要補充措施。SOC 2、ISO 認證、TLS 或服務商宣稱提供 SCC，都不單獨構成該次傳輸已合法的證明。例外或明示同意不應用作反覆、結構性傳輸的通常替代方案。

可向第 14 節窗口索取與您資料相關的接收者、地區及保障摘要，並在依法可提供且經必要遮蔽後取得保障文件。對有權機關的請求，營運者核實權限與法律依據、限制揭露範圍，並於法律允許且不損及合法目的時通知受影響者。

## 8. 保存、停用與刪除

| 資料類別 | 實際機制及保存標準 |
| --- | --- |
| 帳號、個人設定與正常郵件 | 為提供服務而保存至刪除、帳號清理或合法必要性消失；停用不等同實體清除 |

| 帳號註銷／停用 | 自助操作限制存取並改變資料狀態；未證實有註銷後 90 日自動清除所有資料的機制，刪除請求須另行追蹤完成 |
| 安全、登入、稽核及權利請求紀錄 | 僅保存特定目的所必要的期間；沒有通用自動到期的項目，營運者須另訂並落實最短必要保存與定期複核 |
| 附件、原始郵件、備份及外部副本 | 各儲存與備援的刪除須分別確認；不得將介面刪除當作所有副本已同時清除，具體週期由實例補充告知 |
| 法定保存或具體爭議 | 有實際法律依據時僅保留所需資料、限制其他使用並記錄理由及期限，期滿清除 |
| 計畫性停運 | 在合理可行時先通知並提供資料取回期間，再終止資源及處理殘留副本；突發中斷可能限制取回能力 |

沒有一項固定的 90 日寬限可排除法定「不再必要即刪除」或第 9 節的請求期限。若備份只能按週期覆寫，應隔離不再使用、告知週期，並於復原時重新套用刪除；未確認的備份週期不能描述為即時或徹底不可復原。寄件人、收件人或獨立服務商已持有的副本，通常無法由本服務單方面刪除；依法應通知接收者更正、刪除或限制時仍須辦理。

## 9. 當事人權利與處理期限

依適用法律及其要件，您可請求知情、查閱及複本、更正、刪除、限制處理、反對基於合法利益的處理、撤回同意，以及在符合條件時取得機器可讀資料或請求可攜。撤回不影響撤回前合法的處理；反對直接行銷時應停止該用途。您亦可就具有重大影響的自動決定請求適用的保障與人工介入。

GDPR 適用時，對於您提供且與您有關、以同意或履行契約為依據並以自動化方式處理的個人資料，您可要求以結構化、常用且機器可讀格式取得，並不受阻礙地移轉至另一控管者；技術上可行時亦可要求直接傳送。此權利不得不利影響他人的權利與自由，亦不限制查閱或刪除權。

自助匯出是其中一個途徑，匯出檔不等於所有資料的完整副本：個人欄位為選定子集，不包含附件檔案、垃圾桶郵件、完整路由欄位、原始 MIME、所有別名及安全／管理稽核紀錄。取得未包含且依法可請求的資料，可聯絡 `privacy@epocanvas.com`；營運者亦須保護通訊對象及其他人的權利，必要時遮蔽而非一概拒絕。

:::note[對合法利益處理提出異議]
GDPR 適用時，您可隨時基於個別情況，反對以合法利益為依據的處理，包括剖析。除非營運者證明有優先於您利益、權利與自由的重大且正當事由，或為提出、行使或防禦法律請求所必要，否則不得繼續。反對直接行銷無須提出個別理由，提出後須停止該用途。請聯絡 `privacy@epocanvas.com`；營運者最遲須於首次聯絡時，清楚、單獨提示此權利。
:::

GDPR 適用時，應無不當遲延並於收到請求後一個月內回覆。因複雜程度或請求數量而有必要時，可依法再延長最多兩個月，但須在第一個月內說明延長及理由；不採取行動時亦應告知理由、申訴與司法救濟途徑。其他適用法律定有較短期限者，依其規定。

一般請求免費。僅在適用法律允許且能證明請求明顯無根據或過度時，始得收合理費用或拒絕並說明。身分有合理疑義時僅要求必要的補充核驗，不一律索取證件，也不以未註冊或無法登入排除權利。

您可直接向有管轄權的資料保護機關申訴及尋求司法救濟；GDPR 適用時，包括您慣常居所、工作地或涉嫌侵害地的主管機關。毋須先取得營運者同意或先用完內部申訴。歐盟機關聯絡資料可見 [EDPB 成員清單](https://www.edpb.europa.eu/about-edpb/about-edpb/members_en)。

## 10. 安全與事故應變

營運者應依資料性質、風險、技術現況及合理實施成本採取適當的存取控制、憑證保護、加密、更新與事故處理措施；安全功能的存在不構成零風險或特定認證的保證。個人維護模式不要求本政策以外的 24 小時支援，但不延長法定通報期限。

事故須立即評估、控制並留存紀錄。GDPR 適用時，除不太可能對個人權利自由造成風險外，控管者應無不當遲延且在可行情況下於知悉後 72 小時內向有管轄權的監管機關通報；遲報須說明，資訊可依法分階段提供。對當事人可能造成高度風險時，除符合法定例外，應無不當遲延直接告知，不一律以公開事故細節代替通知。受託處理者應無不當遲延通知控管者。其他適用通訊法另有通報對象、門檻或較短期限者，從其規定。

## 11. 年齡與兒童資料

託管測試服務供年滿 16 歲且依法具備締約能力者使用；所在地法律要求更高年齡或監護人許可時，依其規定。此服務門檻不表示已完成年齡驗證，也不取代 GDPR 對兒童同意與其他兒少保護規範的判斷。得知未符合門檻者註冊時，應限制不必要處理並依法核實、回應與刪除。自行部署者須另行評估對象、年齡與可行的保障。

## 12. 法律適用與比例原則

託管實例的營運所在地為臺灣，應遵守適用的個人資料保護及通訊法律，並按官方資料庫所載已生效規定與施行注記判斷義務。法規修正公布不等於已施行。

營運地不是唯一判斷依據。在歐盟設立機構相關活動中處理資料，或在境外向身在歐盟的人提供服務、監測其境內行為而符合法定條件時，GDPR 亦可能適用；單純網站可從歐盟連線，不當然構成向當地提供服務。免費、公益、個人作者或「測試中」不會自動排除適用；對外開放信箱亦不能一概援用純粹個人或家庭活動例外。

歐盟代表、資料保護長、影響評估與處理紀錄依各自法定條件決定，不因小型專案便一律免除，也不因可從歐盟瀏覽便一律必須任命。持續營運的信箱通常不屬偶發處理，應審慎評估相關例外。措施可以配合規模與風險，無須僅為發表原始碼取得 ISO 認證或承諾企業服務。
