**生效日期：2026 年 10 月 5 日｜版本：5.11**

EpoCanvas Mail 的設定分為兩個區域：側欄「設定」區為每個帳號可自行調整的個人設定，含個資、一般、安全、資料與標籤五個分區；「管理」區僅對具備管理權限的身分分組顯示，承載實例級配置。本頁逐區說明各項設定的作用與相互關係。多重帳號、郵件模式與登入方式等運行層面的行為見[運行模式](/zh-tw/mail/modes/)。

## 1. 個人設定分區

| 分區 | 內容 |
| --- | --- |
| 個資 | 頭像、暱稱、性別、生日等基本資料與聯絡資訊 |
| 一般 | 個人簡介、外觀色調、主題桌布、閱讀偏好、介面語言與翻譯目標語言 |
| 安全 | 使用者名稱與密碼、兩步驗證中心、註銷帳號 |
| 資料 | 資料匯出、通知與轉寄、儲存空間與個人雲端儲存 |
| 標籤 | 自訂標籤與分類規則管理 |

## 2. 個資：個人資料

![EpoCanvas Mail 個資頁：基本資訊卡含頭像上傳、個人暱稱、性別與生日；聯絡資訊卡顯示帶主信箱標記的電子郵件與新增電子信箱按鈕、電話號碼；下方為住家、公司與其他地址卡（介面為簡體中文）](/images/mail/ui/ui-settings-profile.png)

*圖：個資頁。主信箱帶「主信箱」標記，額外電子信箱可新增多個並隨時移除。*

基本資訊卡管理頭像、暱稱、性別與生日；聯絡資訊卡列出登入主信箱與自行新增的額外電子信箱，另可登記含國碼的電話號碼；地址卡分別保存住家、公司與其他地址。資料的公開範圍受管理員「公開個人主頁」開關約束。

## 3. 一般：外觀與語言

![EpoCanvas Mail 一般頁：個人簡介文字框，個性裝扮區提供暗色調、亮色調與跟隨系統三種外觀色調，全域主題桌布提供八種預設與自訂桌布，下方繼續個人背景等設定（介面為簡體中文）](/images/mail/ui/ui-settings-general.png)

*圖：一般頁的外觀色調與主題桌布選擇，目前為跟隨系統與預設純淨桌布。*

- 外觀：暗色、亮色、跟隨系統三種色調；全域主題桌布預設八種，支援自訂桌布；另可單獨設定個人背景與介面密度；
- 閱讀偏好：收件匣類型、閱讀窗格位置與會話群組開關；
- 語言：系統語言六選一；翻譯目標語言獨立設定，共 17 種，決定 AI 全文翻譯的目標語言；圖片文字辨識翻譯可單獨關閉；
- 資料隱私區集中於個人資訊與 AI 處理偏好入口。

## 4. 安全：密碼與兩步驗證

安全頁可修改使用者名稱與密碼（顯示上次變更時間）。兩步驗證中心提供總開關與三種第二驗證方式的獨立配置：驗證器應用程式（TOTP）、備用復原碼（10 組一次性代碼）與通行金鑰（Passkey）。兩步驗證的登入行為與信任裝置規則見[運行模式](/zh-tw/mail/modes/)第 4 節。頁面底部提供註銷帳號入口，註銷後帳號資料依[隱私權政策](/zh-tw/mail/privacy-policy/)的刪除條款處理。

## 5. 資料：匯出、通知與儲存

![EpoCanvas Mail 資料頁：使用者資料與資料匯出卡含全量資料 JSON、郵件歷史歸檔（MBOX、JSON、CSV 與時間範圍）與通訊錄配置三類匯出；下方儲存空間卡顯示附件儲存用量儀表與個人物件儲存接入入口（介面為簡體中文）](/images/mail/ui/ui-settings-data.png)

*圖：資料頁。資料匯出與儲存管理同頁呈現，附件儲存用量依身分分組配額計算。*

| 匯出項 | 格式 | 範圍 |
| --- | --- | --- |
| 匯出全量資料 | JSON | 完整備份：帳號個資、歷史郵件、通訊錄、分類與標籤規則及安全設定 |
| 郵件歷史歸檔 | MBOX（通用）、JSON 或 CSV | 僅收發郵件，可限定時間範圍 |
| 通訊錄與配置 | JSON | 聯絡人名錄、自訂別名規則與系統個人化偏好 |

單封郵件可於閱讀頁直接下載為 .eml。通知與轉寄區提供 Telegram 推送（綁定機器人與對話 ID）與郵件規則轉寄（自選目的地地址，觸發類型分全部郵件、別名前綴與智慧規則，可選保留副本與主旨加前綴）；兩項功能是否對使用者開放由管理員的使用者資料管控開關決定。儲存區顯示附件儲存用量儀表，並可接入個人物件儲存（Backblaze B2 或 S3 自備儲存桶），接入後附件直接保存於個人雲端，不受實例配額約束。

## 6. 標籤管理

標籤分區管理自訂標籤的顏色與圖示，並配置分類規則的條件、例外與優先級；出廠預置社群、訂閱、推銷與工作四個標籤。規則引擎的行為與搜尋語法見[功能指南](/zh-tw/mail/features/)第 3、4 節。

## 7. 管理控制台

管理區依身分分組的權限逐項顯示，介面路徑與身分分組綁定以防越權存取。九個管理分區如下：

| 分區 | 職責 |
| --- | --- |
| 分析頁 | 郵件量、分類與標籤的統計儀表板 |
| 使用者清單 | 帳號查詢、重設密碼、調整身分分組、重設兩步驗證、封禁與復原、清空使用者郵件 |
| 垃圾郵件／全部郵件 | 全站郵件審查分區；名稱與範圍隨郵件模式變化（Level 1 顯示全部郵件，Level 2 顯示垃圾郵件分區，Level 3 隱藏入口） |
| 權限控制 | 六種身分分組的配額與權限模板、預設分組與 AI 模型授權；參觀者與站長分組受保護不可刪除 |
| 註冊密鑰 | 邀請註冊碼的簽發與查驗 |
| 系統設定 | 實例級配置，見下方配置卡清單 |
| 應用管理 | OAuth 2.0／OIDC 第三方應用程式的接入憑證簽發與管理 |
| 分類管理 | 收信與寄信功能開關、AI 識別配置、黑白名單與硬攔截規則 |
| 操作報告 | 四類預警的研判、處置與申訴裁決 |

系統設定頁以配置卡組織實例級配置：

| 配置卡 | 內容 |
| --- | --- |
| 網站設定 | 開放註冊、公開個人主頁、郵件模式、兩步驗證、隱藏登入網域、註冊碼、新增信箱、多帳號快速切換、信箱前綴規則 |
| 介面客製化 | 網站標題、彈窗提示與動態／靜態介面 |
| 第三方認證與單一登入 | 第三方快捷登入總開關與各 Provider 密鑰配置（經特性開關控制顯示） |
| 儲存與核心資料庫 | 物件儲存（B2／S3，預設回退 R2／KV）、核心與第三方資料庫架構、單一附件上限與級聯刪除、KV 快取體檢 |
| 郵件推送 | Telegram 機器人、全域轉寄與規則轉寄（加密模式下鎖定關閉） |
| AI Hub | AI 提供者（自訂 OpenAI 相容端點或 Cloudflare Workers AI）、啟用開關、每日配額與速率限制、模型授權 |
| 使用者資料管控 | 使用者的 Telegram 推送、郵件轉寄、API 與自備儲存開關及預設儲存配額 |
| Turnstile | 人機驗證的站點密鑰與開關 |
| 站內公告與歡迎郵件 | 公告彈窗、公告郵件群發與歡迎郵件模板（多語言） |
| 稽核報告策略 | 預警觸發的營運閾值 |
| 關於 | 版本資訊與更新檢查 |

操作報告頁以預警工單呈現全站風險事件，每條記錄帶類別、優先級、狀態與完整環境資訊（IP、地理、裝置與指紋）：

| 預警類別 | 觸發情形 | 常見處置 |
| --- | --- | --- |
| 稽核警告 | 被其他使用者檢舉或違規檢舉成立 | 核驗後研判放行或執行管控 |
| 風控警告 | 觸碰安全紅線或異常登入環境（如多地多 IP 併發登入） | 重點關注、約談或封禁 |
| 封禁警告 | 帳號已被系統自動封禁或管理員手動封禁 | 解除預警或維持 |
| 申訴警告 | 使用者就處置結果提交申訴 | 研判放行或駁回 |

![EpoCanvas Mail 操作報告頁：表格列出申訴警告、封禁警告、稽核警告與風控警告四類預警工單，各帶優先級、狀態標籤、活躍環境池資訊與研判放行、解除預警等處置按鈕（介面為簡體中文）](/images/mail/ui/ui-audit-report.png)

*圖：操作報告。四類預警統一清單研判，處置按鈕按預警類別分流；加密模式下記錄時間戳記被剝離。*
