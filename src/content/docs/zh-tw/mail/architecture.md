本頁說明 EpoCanvas Mail 的技術實作：部署拓撲、資料加密、儲存鏈路、權限模型與郵件生命週期。全部技術事實以開源程式碼之實際實作為準，可自行審計核對；對個人之隱私影響與法定告知見[資料處理與安全維護](/zh-tw/mail/data-security/)與[隱私權政策](/zh-tw/mail/privacy-policy/)。

本站法律文件以繁體中文（臺灣）版本為正式版本，其餘語言版本為對照譯本，文義有疑義時以正式版本為準。

## 1. 部署拓撲

| 元件 | 實作 |
| --- | --- |
| 運算 | Cloudflare Workers（V8 Isolate 沙箱）：業務邏輯無狀態，明文僅存於請求記憶體，請求結束即釋放 |
| 入站 | Cloudflare Email Routing 接收郵件，postal-mime 解析正文、標頭與附件 |
| 出站 | 三通道依序解析：Cloudflare Email Workers 綁定、Resend API、Mailjet；站內互發直接寫入資料庫 |
| 結構化儲存 | Cloudflare D1（雙庫物理隔離：使用者庫承載帳號、角色與設定；郵件庫承載郵件、星標與附件中繼資料；單庫部署 100% 向後相容，託管實例當前即以單庫運行） |
| 鍵值儲存 | Workers KV：會話權杖、登入風控計數、TOTP 中間態、使用者資料與物件儲存兜底 |
| 邊緣推論 | Workers AI（驗證碼提取等，預設 llama-3.1-8b-instruct） |
| 定時任務 | Cron 觸發器執行：每 30 分鐘重新整理資料分析快取；每日執行風控計數歸零、發信計數重置、回收站與垃圾郵件清理、無綁定 OAuth 帳號清除 |
| 人機驗證 | Cloudflare Turnstile（HTTP API 校驗，註冊與新增信箱） |

## 2. 技術棧

| 層 | 技術 |
| --- | --- |
| 用戶端 | Vue 3.5、Element Plus、Pinia、vue-i18n、ECharts、Dexie（本地草稿，不上傳伺服器）、Vite 7、vite-plugin-pwa |

## 3. 資料加密體系

- **三模式靜態加密**：全部模式（不加密）、隱私模式（除垃圾與回收站外均加密）、加密模式（全部加密）；模式語義與管理員可及範圍見[資料處理與安全維護](/zh-tw/mail/data-security/)第 1.3 節；
- **郵件加密**：主旨與正文以 AES-256-GCM（含認證標籤）加密，每筆記錄使用隨機初始化向量；密鑰自實例級主密鑰環境變數經 HKDF-SHA256 衍生並按使用者加鹽，主密鑰不入庫、不隨程式碼提交；
- **憑證保護**：密碼經 PBKDF2-HMAC-SHA256 100,000 次迭代加鹽雜湊；TOTP 密鑰以 AES-256-GCM 靜態加密，備用復原碼僅存 SHA-256 雜湊；通行金鑰僅存公鑰；
- **邊界**：以上為伺服器端靜態加密，非端對端加密；附件不在加密範圍內。

## 4. 附件儲存鏈

附件二進位按序解析儲存：自備 S3 相容儲存（BYOS，支援 AWS S3、Backblaze B2、MinIO 等）→ 營運者設定之 S3 相容儲存 → Cloudflare R2 綁定 → 缺省 Cloudflare KV。中繼資料（檔案名稱、MIME、體積）存於 D1；下載附帶防禦性標頭與 MIME 允許清單；刪除郵件時附件經引用計數級聯清理。

## 5. 會話與角色權限

會話為 30 天有效期之 JWT（HS256），落於 KV 並經深度脫敏；同帳號上限 10 個活躍會話，登出與註銷即時吊銷。權限採用 RBAC，播種六個標準角色：

| 角色 | 每日發信 | 儲存配額 | 附件 | 附加能力 |
| --- | --- | --- | --- | --- |
| 參觀者 | 禁止 | 0 | 否 | 唯讀沙箱 |
| 普通使用者 | 5 封 | 5 MB | 否 | 基礎收發 |
| 普通使用者 LV.0 | 8 封 | 10 MB | 否 | 部落格等級連動升級 |
| 普通使用者 LV.1 | 10 封 | 25 MB | 是 | 基礎收發與附件 |
| 管理員 | 100 封 | 500 MB | 是 | 使用者管理、全郵件管理（受郵件模式約束） |
| 站長 | 不限 | 1024 MB | 是 | 全部權限 |

全部管理與業務路由統一經鑑權閘道校驗；公開端點（登入、註冊、OAuth、初始化）除外；帳號刪除即時吊銷其會話。

## 6. 郵件生命週期

| 環節 | 行為 |
| --- | --- |
| 刪除 | 郵件先入回收站（軟刪除），自收受之日起 7 日後由定時任務實體刪除（含附件與索引） |
| 垃圾隔離 | 垃圾郵件保留 7 日後轉入回收站；隔離期可設定 |
| 配額清理 | 信箱用量逾配額 90% 時，已標記刪除之郵件逕行實體刪除 |
| 官方郵件 | 歡迎郵件與全域公告預設 7 日過期（可設定） |
| 級聯刪除 | 實體刪除按分塊執行（規避 D1 單語句繫結參數上限），附件與星標隨郵件級聯移除 |
| 帳號註銷 | 會話即時失效，資料進入軟刪除狀態，至管理員執行實體刪除為止（時限承諾見[隱私權政策](/zh-tw/mail/privacy-policy/)第 8 節） |

## 7. 應用安全設計

- **防越權路由**：郵件 URL 一律使用 HMAC-SHA256 簽名的 20 位隨機 Hash，綁定使用者與租戶，不暴露自增 ID，杜絕枚舉與 BOLA／IDOR；
- **XSS 三重防禦**：DOMPurify 允許清單消毒、body style 注入過濾、附件輸出 MIME 允許清單加嚴格 CSP 與 `nosniff`；
- **SSRF 阻斷**：出站請求經公共位址校驗，回環、RFC 1918 與雲中繼資料位址一律拒絕；
- **登入防護**：連續 5 次失敗鎖定 12 小時；Turnstile 人機驗證；TOTP／通行金鑰兩步驟驗證；
- **官方郵件完整性**：官方發信身分鎖定、不可變快照投遞與文件防竄改校驗，見[防竄改與官方規範](/zh-tw/mail/tamper-proof/)。

## 8. 可觀測與品質保障

- 執行日誌經 Cloudflare Workers Logs 收集（應用不落 IP 日誌之外的自建日誌）；資料分析頁僅呈現統計彙總，無內容級資料；
- 自動化測試、稽核與巡檢腳本逾百個：Playwright 全真棧瀏覽器迴歸、公網端對端斷言、全倉靜態掃描與六語言 i18n 三件套（詳見[專案介紹](/zh-tw/mail/project/)第 7 節）。
