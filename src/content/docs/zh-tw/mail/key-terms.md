# 用語定義

**生效日期：2026 年 10 月 2 日｜版本：5.7**

本頁定義本站各法律文件所用之名詞。法律名詞採資料保護法制之通用定義；技術名詞之解釋，以本服務開放原始碼之實際實作為準。

本站法律文件以繁體中文（臺灣）版本為正式版本，其餘語言版本為對照譯本，文義有疑義時以正式版本為準。本站法律與技術文件以本服務開放原始碼實作為準，旨在建立透明、嚴謹之非商業社群通訊規範。

## 1. 法律名詞

| 名詞 | 定義 |
| --- | --- |
| 個人資料 | 指自然人之姓名、出生年月日、聯絡方式、社會活動及其他得以直接或間接方式識別該個人之資料。本服務所涉者以電子郵件地址、帳號憑證、網路活動紀錄為主 |
| 高敏感個人資料 | 病歷、醫療、基因、性生活、健康檢查及犯罪前科等高敏感類別之個人資料，其處理於多數法域受嚴格限制 |
| 蒐集／處理／利用 | 蒐集指以任何方式取得個人資料；處理指為建立或利用個人資料檔案所為資料之記錄、輸入、儲存、編輯、更正、複製、檢索、刪除、輸出、連結或內部傳送；利用指將蒐集之個人資料為處理以外之使用 |
| 資料控管者 | 決定個人資料蒐集、處理、利用之目的與方式之主體；託管實例之營運者、自行部署實例之部署者均屬之 |
| 受託處理者 | 依控管者之指示，為其處理個人資料之主體（如 Cloudflare、Resend） |
| 當事人 | 個人資料所識別之自然人，即本站文件所稱之「您」 |
| 國際傳輸 | 指將個人資料作跨國（境）之處理或利用；遵循適用法律之要求及標準契約條款等保障機制 |
| 告知義務 | 向當事人蒐集個人資料時，告知蒐集者名稱、蒐集目的、資料類別、利用之期間地區對象方式、當事人得行使之權利及不提供之影響等事項之義務；蒐集非由當事人提供之資料者，於處理或利用前告知來源 |
| 特定目的 | 蒐集或處理個人資料所應有之特定目的；利用並應於該特定目的之必要範圍內為之 |
| 行銷拒絕權 | 當事人表示拒絕接受行銷時，即停止利用其個人資料行銷；首次行銷時並提供表示拒絕之方式 |
| 主管機關 | 依適用法律主管個人資料保護事務之機關；託管實例所在地臺灣之主管機關為個人資料保護委員會 |
| 非自願性性影像 | 未經同意而被攝錄、重製、散布之他人性影像，及以電腦合成等方法製作之不實性影像；未經同意攝錄、重製或散布該等影像於多數法域構成犯罪，平臺接獲通知應先限制瀏覽或移除 |
| 兒少性剝削 | 對兒童或少年之性剝削行為，包括拍攝、製造、重製、持有、散布、播送、交付、公然陳列、販賣或支付對價觀覽兒童或少年之性影像 |
| 準據法 | 契約所適用之法律，依營運者所在地確定；[服務條款](/zh-tw/mail/terms-of-service/)第 11 節載明各實例之準據法 |
| 定型化契約 | 以概括條款就多數不特定人所為之契約約定；顯失公平之部分依適用法律得不受拘束 |

## 2. 技術名詞

| 名詞 | 定義 |
| --- | --- |
| 實例（站點） | 運作於特定個人或組織之 Cloudflare 帳號內之一份 EpoCanvas Mail 部署，如 `mail.epocanvas.com` |
| 營運者 | 部署並管理實例之個人或團隊；即各文件所稱之「我們」 |
| PBKDF2 | 一種密碼雜湊演算法。本服務以 HMAC-SHA256 執行 100,000 次疊代並附加每使用者獨立隨機鹽，使原始密碼無法自雜湊值反推 |
| TOTP | 依 RFC 6238 之時間性一次性密碼；其金鑰於資料庫中以 AES-256-GCM 加密儲存 |
| Passkey（通行金鑰） | 依 FIDO2/WebAuthn 標準之公開金鑰憑證；本服務僅儲存公鑰，私鑰留存於當事人裝置 |
| JWT（工作階段權杖） | 登入後簽發之數位簽章憑證，有效期 30 日；同帳號上限 10 個並行工作階段；登出即由伺服器端撤銷 |
| localStorage | 瀏覽器提供之網頁儲存機制，資料留存於當事人裝置並可跨工作階段；本服務之工作階段權杖存於此處，不使用 Cookie |
| 靜態加密（encryption at rest） | 資料寫入儲存媒體時之加密。本服務之金鑰由實例伺服器環境變數衍生，屬伺服器端加密，非端對端加密 |
| 端對端加密（E2EE） | 僅收發雙方得解密之加密型態。本服務不提供；有此需求者應自行以 GPG 等工具預先加密 |
| HMAC 混淆路由 | 以雜湊訊息認證碼將郵件識別碼與使用者身分綁定編碼之機制，防止越權存取（IDOR）與資源列舉 |
| RBAC | 角色存取控制。本服務採預設拒絕（fail-closed）之多級權限模型，非白名單參數於閘道剝離 |
| D1／KV／R2 | Cloudflare 之邊緣 SQLite 資料庫、全球複製鍵值儲存與 S3 相容物件儲存，分別承載結構化資料、工作階段快取與附件 Blob |
| 遙測（telemetry） | 軟體自動向開發者回傳使用資料之行為。本服務之原始碼零遙測，不向上游回傳任何實例資料 |
| 軟刪除／實體刪除 | 軟刪除指標記刪除，管理員得復原；實體刪除指連同附件與索引自儲存體中移除，不可復原 |
| BYOS（自備儲存） | Bring Your Own Storage——將附件存於營運者或當事人自有之 S3 相容物件儲存（如 Backblaze B2、Wasabi）之機制；儲存憑證由配置者自行保管 |
| Workers AI | Cloudflare 邊緣推論服務；用於驗證碼提取等 AI 處理，觸發條件與資料範圍見[隱私權政策](/zh-tw/mail/privacy-policy/)第 6 節 |
| Turnstile | Cloudflare 之人機驗證機制；於註冊與新增信箱時評估瀏覽器可信度，不以廣告 Cookie 或跨站追蹤為之 |
| SSRF 防護 | 伺服器端請求偽造（Server-Side Request Forgery）之阻斷機制；對外部端點之請求一律經公共位址校驗，回環、私有網段與雲端中繼資料位址一律拒絕 |

## 3. 其他

本頁未定義之名詞，依[隱私權政策](/zh-tw/mail/privacy-policy/)與[服務條款](/zh-tw/mail/terms-of-service/)之文脈及一般法律與技術慣例解釋。對定義有疑義者，請透過[隱私權政策](/zh-tw/mail/privacy-policy/)第 14 節所列管道詢問。
