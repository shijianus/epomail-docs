## 1. 法律名詞

| 名詞 | 定義 |
| --- | --- |
| 個人資料 | 與已識別或可識別自然人有關的資料，包括帳號、網路紀錄，以及郵件內容、附件或中繼資料中的個人資訊；不限於註冊欄位 |
| 高敏感個人資料 | 健康、基因、性生活等依法受特別保護的資料；犯罪紀錄可能受獨立規則規範，各法域的分類與要件不完全相同 |
| 蒐集／處理／利用 | 包括取得、記錄、儲存、檢索、傳送、使用及刪除等操作；臺灣法律區分蒐集、處理與利用，GDPR 的處理概念涵蓋較廣，不宜機械套用 |
| 資料控管者 | 單獨或共同決定特定處理目的與方式的主體；依事實判斷，不因自建而當然唯一排他，也不將每位個人使用者一律視為控管者 |
| 受託處理者 | 代表控管者並依其合法指示處理資料的主體；同一提供者就自行決定目的的其他活動可能是獨立控管者 |
| 當事人 | 資料所涉及的自然人，包括使用者、寄件人、收件人及郵件提及的人，不必已建立帳號 |
| 國際傳輸 | 依法構成跨境提供或使境外接收者可存取資料的活動；須按實際路徑評估適法機制，供應商認證不自動滿足傳輸要求 |
| 告知義務 | 依法說明處理者身分、目的、依據、來源、接收者、保存及權利等資訊；間接來源包括寄件人、身分提供者、檢舉人或整合服務，時點與例外依適用法律 |
| 特定目的 | 處理前明確界定的目的，資料處理應限於合法、必要且相容的範圍；學習或測試不等於可任意使用真實郵件 |
| 行銷拒絕權 | 當事人可依適用法律拒絕直接行銷；收到拒絕後應停止相應使用，並提供易用的拒絕方式 |
| 主管機關 | 依處理活動與現行法律有管轄權的機關；不僅限營運者所在地。歐盟機關可查閱 [EDPB 成員名單](https://www.edpb.europa.eu/about-edpb/about-edpb/members_en) |
| 非自願性性影像 | 未經同意製作或散布的性影像，包括有害合成影像；限制接取、必要保存及救濟見[可接受使用政策](/zh-tw/mail/acceptable-use/) |
| 兒少性剝削 | 對兒童及少年進行性虐待、剝削、引誘，或製作、持有、散布相關違法內容；保護、通報與證據保存依適用法律 |
| 準據法 | 契約有效選定或依法確定的法律；不得排除強制的消費者、資料保護或司法救濟權，見[服務條款](/zh-tw/mail/terms-of-service/)第 11 節 |
| 定型化契約 | 為多數使用者預先擬定的契約條款；不公平或依法不得排除權利的內容，不因點擊接受即當然有效 |
| 資料處理協議（DPA） | 對實際受託處理的事項、指示、安全、協助與終止等作成的必要協議；組織用途須另行確認及訂立，名稱不能改變實際角色 |
| 資料保護長（DPO） | 符合法定條件時須指定的獨立資料保護職務；一般隱私聯絡信箱不等於已任命 DPO |
| 歐盟代表 | 在適用 GDPR 的特定境外處理情形下依法指定的歐盟境內聯絡代表；不同於 DPO，不因提供歐語介面就宣稱已任命 |

## 2. 技術名詞

| 名詞 | 定義 |
| --- | --- |
| 實例（站點） | 特定營運者管理的一份 EpoCanvas Mail 部署，如 `mail.epocanvas.com`；資料流依其基礎設施與功能設定而異 |
| 營運者 | 實際決定並管理實例服務的自然人或組織；作者同時營運時，也依其行為承擔義務 |
| PBKDF2 | 由密碼與鹽值衍生驗證值的機制，用於提高猜測成本；不是保證弱密碼不會被破解，實際參數見安全文件 |
| TOTP | 以共享秘密及時間產生一次性驗證碼的機制；伺服器須保護所持秘密，並非僅儲存公開金鑰 |
| Passkey（通行金鑰） | WebAuthn 憑證；伺服器保存公鑰、憑證識別及必要的驗證中繼資料，私鑰由驗證器或所選同步服務管理，不傳給本服務驗證伺服器 |
| JWT（工作階段權杖） | 用於登入工作階段的簽章權杖；簽章不等於加密，效期、撤銷與工作階段限制依部署實作 |
| localStorage | 瀏覽器中可跨工作階段保存資料的機制；可能保存登入狀態及偏好，並不證明所有頁面或第三方元件均無 Cookie |
| 靜態加密（encryption at rest） | 儲存資料的加密；郵件主旨與正文依模式處理，附件及中繼資料不自動受同一應用層加密保護。持有伺服器與金鑰者仍可能解密 |
| 端對端加密（E2EE） | 僅通訊端點掌握解密能力的設計；本服務未提供此保證，自行使用 OpenPGP 亦不必然隱藏信封資訊或其他中繼資料 |
| HMAC 混淆路由 | 將資源識別與使用者資訊綁定的機制，可降低列舉與未授權存取風險；仍須伺服器授權檢查，不能保證無越權 |
| RBAC | 按角色限制操作與資料存取的機制；有效性依權限設定、檢查與維護，不構成絕對安全保證 |
| D1／KV／R2 | Cloudflare 的資料庫、鍵值與物件儲存服務；實際資料位置、複本及保存依配置與提供者安排 |
| 遙測（telemetry） | 自動回報使用或診斷資料的行為；未設上游使用分析不代表無第三方流量，字型、驗證、投遞及選用服務仍可能發出請求 |
| 軟刪除／實體刪除 | 前者標記或限制資料使用，後者從指定儲存移除；不表示備份、外部副本與合法保存資料同步消失，也不保證必可恢復或必不可恢復 |
| BYOS（自備儲存） | 使用所配置的 S3 相容物件儲存；端點、憑證與檔案可能由實例為完成存取而處理，非僅留在使用者裝置 |
| Workers AI | Cloudflare 推論服務；啟用的自動處理與使用者觸發功能可能傳送郵件內容，範圍及依據見[隱私權政策](/zh-tw/mail/privacy-policy/) |
| Turnstile | Cloudflare 的人機驗證服務；驗證請求與必要技術資料涉及第三方處理，詳見[第三方處理者清單](/zh-tw/mail/sub-processors/) |
| SSRF 防護 | 限制伺服器被誘導存取不適當目的地的檢查；覆蓋範圍與效果依實際路徑及部署，不代表所有外部請求均已消除風險 |
