**生效日期：2026 年 10 月 6 日｜版本：5.15**

標籤與分類規則在「設定 → 標籤」（`#settings/labels`）管理。規則條件的完整欄位表見[搜尋與規則參考](/zh-tw/mail/search/)第 7 節；本頁說明標籤本身的操作與統計。

## 1. 標籤的建立與外觀

| 操作 | 說明 |
| --- | --- |
| 新增標籤 | 側欄標籤區（至多 7 個）或標籤頁內新增並命名 |
| 圖示 | 內建圖示庫任選，亦支援自訂 SVG |
| 顏色 | 標籤色板自訂，清單與側欄同步呈現 |
| 刪除 | 刪除標籤同時解除其在規則中的引用 |

## 2. 出廠四標籤

| 標籤 | 維護方式 |
| --- | --- |
| 社群 | 預設規則按常見公共信箱網域自動歸類 |
| 訂閱 | 內建啟發式：無回覆前綴的寄件人、郵件行銷平台網域與退訂訊號 |
| 推銷 | 內建啟發式：折扣、限時等主題詞與行銷詞密度 |
| 工作 | 手動或自建規則維護 |

四個出廠標籤可編輯可刪除；啟發式歸類僅對未手動處理的新郵件生效。

## 3. 分類規則建構器

- 規則由「條件 + 例外」兩步構成：條件全部命中且例外無一命中時執行動作；
- 條件欄位（寄件人、收件人、主題、正文、地址包含等）與多值語法見[搜尋與規則參考](/zh-tw/mail/search/)第 7 節；取值輸入帶後端聯想補全；
- `priority` 數值決定執行順序（小者優先），`stopProcessing` 命中即截斷後續規則；
- 規則於收信時自動執行，亦可在標籤頁對既存郵件手動執行。

## 4. 統計與複核

- 側欄標籤區即時顯示各標籤的總數與未讀數；
- 分類結果可在管理區[分析頁](/zh-tw/mail/analysis/)複核來源分布；站點級黑白名單與硬攔截由管理員在[分類管理](/zh-tw/mail/category/)配置。

<details>
<summary>圖解：標籤與規則建構器的操作步驟</summary>

![標籤與規則建構器的操作步驟](/images/mail/zh-tw/ui/labels.png)

1. 進入「設定 → 標籤」；在側欄標籤區或標籤頁新增標籤（側欄至多顯示 7 個）。
2. 為標籤挑選內建圖示或上傳自訂 SVG，並選取標籤顏色。
3. 在規則區以「條件 + 例外」兩步新增規則；取值輸入自帶聯想補全。
4. 設定 priority（小者優先）與 stopProcessing（命中截斷）；規則於收信時自動執行，也可手動執行。

</details>
