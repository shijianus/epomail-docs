**生效日期：2026 年 10 月 6 日｜版本：5.16**

分类管理是管理区的站点级治理界面（`#manage/admin/rules`，权限键 `setting:query`），在用户个人规则之上叠加全站收信治理。个人标签规则见[标签与分类管理](/mail/labels/)；条件字段语义见[搜索与规则参考](/mail/search/)第 7 节。

![图：分类管理界面](/images/mail/ui/category-guide.png)

*图：分类管理界面*
*标注：1. 邮件设置　2. AI 模型与 API 密钥集成　3. 基础名单规则　4. 硬拦截规则*


## 1. 收发与刷新开关

收信功能、发信功能与自动刷新的总开关，以及无收件人邮件的处理开关；关闭收信后入站邮件直接拒收。

## 2. AI 识别

Workers AI 验证码提取及其规则配置、AI API Key／URL／模型——与[系统设置](/mail/system/)的 AI Hub 同源，此处控制的是入站识别行为（验证码徽标等）。

## 3. 名单与拦截

| 机制 | 说明 |
| --- | --- |
| 发件人黑名单 | 命中即拦截，可配置为标签模式或直接拦截 |
| 白名单模式 | 仅白名单内发件人可送达，其余按策略处理 |
| 硬拦截发件人 | 直接拒收并累计拦截计数 |
| 主题与内容关键词 | 命中黑名单关键词的邮件拦截 |
| 空发件人拦截 | 无发件人名的邮件拒收 |
| 非收件人拦截 | 收件人不含本实例地址的邮件拒收 |
| 可执行附件拦截 | 携带可执行附件的邮件拒收 |

## 4. 与用户侧的分层

站点级名单由管理员维护、作用于全实例；用户侧规则仅作用于本人信箱，两者命中均会自动打上对应标签。名单与关键词的行为细节见[搜索与规则参考](/mail/search/)第 9 节，滥用处置见[可接受使用政策](/mail/acceptable-use/)。

<details>
<summary>图解：站点级治理的操作步骤</summary>

1. 进入管理区「分类管理」（需 `setting:query` 权限）。
2. 配置收信／发信功能开关与自动刷新、无收件人处理。
3. 配置 Workers AI 验证码识别及其 API 参数。
4. 按需启用：发件人黑名单、白名单模式、硬拦截发件人、主题与内容关键词、空发件人拦截、非收件人拦截、可执行附件拦截。
5. 名单命中自动打标，硬拦截直接拒收并计数；拦截效果可回分析页复核。

</details>
