**生效日期：2026 年 10 月 6 日｜版本：5.17**

用户列表是管理区的帐号管理界面（`#manage/admin/users`，权限键 `user:query`），供管理员检索与处置站内全部帐号。

![图：用户列表](/images/mail/ui/users-guide.png)

*图：用户列表*

<details>
<summary>图解：用户列表——从定位帐号到行内处置</summary>

用户列表的四个标注分区：从检索定位到行内处置，管理员的帐号管理动线一屏完成。

1. **邮箱检索框**：顶部按邮箱检索定位帐号，分页与排序即查即得；配合列表中的收发量、存储占用与垃圾/被举报计数快速锁定异常帐号。
2. **用户邮箱列**：帐号的唯一标识：邮箱即帐号名，登录、收信与一切授权都以它为准。行内操作（重置密码、调整分组、封禁）作用于本列所指的帐号；同页另有收发量、存储占用与垃圾／被举报计数三列，用于判断某帐号是否异常。
3. **存储空间列**：该帐号附件存储的实时用量，对照其身份分组配额（见权限控制页）判断是否需要扩容或清理。
4. **设置（操作）列**：行内管理操作：重置密码（签发一次性密码）、调整身份分组、重置两步验证、封禁与恢复，以及清空用户邮件（不可逆，慎用）。

</details>

## 1. 列表与检索

列表按帐号逐行展示邮箱、收发量、存储占用、垃圾与被举报计数等维度，顶部支持按邮箱检索；分页与排序即查即得。

## 2. 帐号操作

| 操作 | 说明 |
| --- | --- |
| 重置密码 | 为帐号签发新的一次性密码，通知其重新登录 |
| 调整身份分组 | 变更帐号所属分组，配额与权限随即切换（分组定义见[权限控制](/mail/roles/)） |
| 重置两步验证 | 帐号无法通过二验时的应急通道，清除其 TOTP／通行密钥配置 |
| 封禁与恢复 | 封禁后帐号立即失去会话，恢复后重新可登录 |
| 清空用户邮件 | 清除该帐号名下邮件（不可逆，慎用） |

## 3. 处置与申诉的衔接

封禁会以预警工单进入[操作报告](/mail/audit/)；被处置用户可经申诉门户或站内渠道申诉，由管理员研判。处置阶梯与比例原则见[可接受使用政策](/mail/acceptable-use/)第 6 节。

<details>
<summary>图解：用户列表的操作步骤</summary>

1. 进入管理区「用户列表」（需 `user:query` 权限）。
2. 顶部搜索框按邮箱定位帐号。
3. 在行内操作菜单选择：重置密码、调整身份分组、重置两步验证、封禁与恢复或清空用户邮件。
4. 封禁与处置会以预警工单进入操作报告，供后续申诉裁决。

</details>
