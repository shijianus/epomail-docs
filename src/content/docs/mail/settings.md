**生效日期：2026 年 10 月 5 日｜版本：5.13**

EpoCanvas Mail 的设置分为两个区域：侧栏「设置」区为每个帐号可自行调整的个人设置，含个资、常规、安全、资料与标签五个分区；「管理」区仅对具备管理权限的身份分组显示，承载实例级配置。本页逐区说明各项设置的作用与相互关系。多账户、邮件模式与登录方式等运行层面的行为见[运行模式](/mail/modes/)。

## 1. 个人设置分区

| 分区 | 内容 |
| --- | --- |
| 个资 | 头像、昵称、性别、生日等基本资料与联系信息 |
| 常规 | 个人简介、外观色调、主题壁纸、阅读偏好、界面语言与翻译目标语言 |
| 安全 | 用户名与密码、两步验证中心、注销帐号 |
| 资料 | 数据导出、通知与转发、存储空间与个人云存储 |
| 标签 | 自定义标签与分类规则管理 |

## 2. 个资：个人资料

![EpoCanvas Mail 个资页：基本信息卡含头像上传、个人昵称、性别与生日；联系信息卡显示带主邮箱标记的电子邮件与添加电子邮箱按钮、电话号码；下方为住家、公司与其他地址卡](/images/mail/ui/ui-settings-profile.png)

*图：个资页。主邮箱带「主邮箱」标记，额外电子邮箱可添加多个并随时移除。*

基本信息卡管理头像、昵称、性别与生日；联系信息卡列出登录主邮箱与自行添加的额外电子邮箱，另可登记含区号的电话号码；地址卡分别保存住家、公司与其他地址。资料的公开范围受管理员「公开个人主页」开关约束。

## 3. 常规：外观与语言

![EpoCanvas Mail 常规页：个人简介文本框，个性装扮区提供暗色调、亮色调与跟随系统三种外观色调，全局主题壁纸提供八种预设与自定义壁纸，下方继续个人背景等设置](/images/mail/ui/ui-settings-general.png)

*图：常规页的外观色调与主题壁纸选择，当前为跟随系统与默认纯净壁纸。*

- 外观：暗色、亮色、跟随系统三种色调；全局主题壁纸预设八种，支持自定义壁纸；另可单独设置个人背景与界面密度；
- 阅读偏好：收件箱类型、阅读窗格位置与会话视图开关；
- 语言：系统语言六选一；翻译目标语言独立设置，共 16 种，决定 AI 全文翻译的目标语言；图片文字识别翻译可单独关闭；
- 数据隐私区集中于个人信息与 AI 处理偏好入口。

## 4. 安全：密码与两步验证

安全页可修改用户名与密码（显示上次变更时间）。两步验证中心提供总开关与三种第二验证方式的独立配置：身份验证器应用（TOTP）、备用恢复码（10 组一次性代码）与通行密钥（Passkey）。两步验证的登录行为与信任设备规则见[运行模式](/mail/modes/)第 4 节。页面底部提供注销帐号入口，注销后帐号资料依[隐私政策](/mail/privacy-policy/)的删除条款处理。

## 5. 资料：导出、通知与存储

![EpoCanvas Mail 资料页：用户资料与数据汇出卡含全量数据 JSON、邮件历史归档（MBOX、JSON、CSV 与时间范围）与通讯录配置三类导出；下方存储空间卡显示附件存储用量仪表与个人对象存储接入入口](/images/mail/ui/ui-settings-data.png)

*图：资料页。数据导出与存储管理同页呈现，附件存储用量按身份分组配额计算。*

| 导出项 | 格式 | 范围 |
| --- | --- | --- |
| 汇出全量数据 | JSON | 完整备份：帐号个资、历史邮件、通讯录、分类与标签规则及安全设置 |
| 邮件历史归档 | MBOX（通用）、JSON 或 CSV | 仅收发邮件，可限定时间范围 |
| 通讯录与配置 | JSON | 联系人名录、自定义别名规则与系统个性化偏好 |

单封邮件可于阅读页直接下载为 .eml。通知与转发区提供 Telegram 推送（绑定机器人与会话 ID）与邮件规则转发（自选目的地地址，触发类型分全部邮件、别名前缀与智能规则，可选保留副本与主题加前缀）；两项功能是否对用户开放由管理员的用户数据管控开关决定。存储区显示附件存储用量仪表，并可接入个人对象存储（Backblaze B2 或 S3 自备存储桶），接入后附件直接保存于个人云端，不受实例配额约束。

## 6. 标签管理

标签分区管理自定义标签的颜色与图标，并配置分类规则的条件、例外与优先级；出厂预置社群、订阅、推销与工作四个标签。规则引擎的行为与搜索语法见[功能指南](/mail/features/)第 3、4 节。

## 7. 管理控制台

管理区按身份分组的权限逐项显示，界面路径与身份分组绑定以防越权访问。九个管理分区如下：

| 分区 | 职责 |
| --- | --- |
| 分析页 | 邮件量、分类与标签的统计仪表盘 |
| 用户列表 | 帐号查询、重置密码、调整身份分组、重置两步验证、封禁与恢复、清空用户邮件 |
| 垃圾邮件／全部邮件 | 全站邮件审查分区；名称与范围随邮件模式变化（Level 1 显示全部邮件，Level 2 显示垃圾邮件分区，Level 3 隐藏入口） |
| 权限控制 | 六种身份分组的配额与权限模板、默认分组与 AI 模型授权；参观者与站长分组受保护不可删除 |
| 注册密钥 | 邀请注册码的签发与查验 |
| 系统设置 | 实例级配置，见下方配置卡清单 |
| 应用管理 | OAuth 2.0／OIDC 第三方应用的接入凭证签发与管理 |
| 分类管理 | 收信与发信功能开关、AI 识别配置、黑白名单与硬拦截规则 |
| 操作报告 | 四类预警的研判、处置与申诉裁决 |

系统设置页以配置卡组织实例级配置：

| 配置卡 | 内容 |
| --- | --- |
| 网站设置 | 开放注册、公开个人主页、邮件模式、两步验证、隐藏登录域名、注册码、添加邮箱、多账户快速切换、邮箱前缀规则 |
| 个性化设置 | 网站标题、弹窗提示与动态／静态界面 |
| 第三方认证与单点登录 | 第三方快捷登录总开关与各 Provider 密钥配置（经特性开关控制显示） |
| 存储与核心数据库 | 对象存储（B2／S3，缺省回退 R2／KV）、核心与第三方数据库架构、单附件上限与级联删除、KV 缓存体检 |
| 邮件推送 | Telegram 机器人、全局转发与规则转发（加密模式下锁定关闭） |
| AI 智能引擎与大模型接入 | AI 提供商（自定义 OpenAI 兼容端点或 Cloudflare Workers AI）、启用开关、每日配额与速率限制、模型授权 |
| 用户资料控制 | 用户的 Telegram 推送、邮件转发、API 与自带存储开关及默认存储配额 |
| Turnstile 人机验证 | 人机验证的站点密钥与开关 |
| 网站公告 | 公告弹窗、公告邮件群发与欢迎邮件模板（多语言） |
| 操作报告 | 预警触发的运营阈值 |
| 关于 | 版本信息与更新检查 |

操作报告页以预警工单呈现全站风险事件，每条记录带类别、优先级、状态与完整环境信息（IP、地理、设备与指纹）：

| 预警类别 | 触发情形 | 常见处置 |
| --- | --- | --- |
| 审计警告 | 被其他用户检举或违规举报成立 | 核验后研判放行或执行管控 |
| 风控警告 | 触碰安全红线或异常登录环境（如多地多 IP 并发登录） | 重点关注、约谈或封禁 |
| 封禁警告 | 帐号已被系统自动封禁或管理员手动封禁 | 解除预警或维持 |
| 申诉警告 | 用户就处置结果提交申诉 | 研判放行或驳回 |

![EpoCanvas Mail 操作报告页：表格列出申诉警告、封禁警告、审计警告与风控警告四类预警工单，各带优先级、状态标签、活跃环境池信息与研判放行、解除预警等处置按钮](/images/mail/ui/ui-audit-report.png)

*图：操作报告。四类预警统一列表研判，处置按钮按预警类别分流；加密模式下记录时间戳被剥离。*
