## 1. 我们在服务中内置了安全功能，以保护您的数据

所有由官方托管平台（mail.epocanvas.com）处理的数据，均受到系统内置多重深度防御工程的持续保护。我们公开说明数据处理的全过程，确保数据流转透明可信。

### 1.1 传输中加密与通道防护

我们使用现代传输层安全协议（TLS 1.3）对用户与服务之间的全部网络连接实施强制通道加密，并配置 HTTP 严格传输安全（HSTS）预加载策略。无论是通过浏览器网页端访问信箱、调用后台 API 接口，还是进行邮件跨节点中继，数据在公共互联网传输过程中始终保持高强度密文状态，有效防御中间人窃听、数据包篡改与降级劫持。

### 1.2 边缘无状态执行与内存隔离

当您收发邮件或发起管理操作时，业务逻辑直接在离您地理距离最近的 Cloudflare Workers 全球边缘计算节点（V8 Isolate 沙箱）中瞬时执行。邮件解密明文仅暂存于易失性内存中处理，处理完毕后沙箱纳秒级物理销毁，宿主机物理磁盘零留存。这种底层无状态架构彻底根除了传统持久化服务器中因常驻进程残留、内存泄漏或多租户侧信道导致的潜在安全隐患。

### 1.3 工业级静态存储加密（AES-256-GCM）

所有邮件正文与敏感元数据在持久化写入 Cloudflare D1 关系型数据库之前，均强制经由加密主密钥派生生成独立密文，并采用带有密码学认证标签（Auth Tag）的 AES-256-GCM 算法进行封包。静态加密密钥由 Cloudflare Workers 运行时加密环境变量注入，不落盘、不入库、不提交代码仓。即使数据库底层文件或备份介质遭遇物理窃取，攻击者亦无法解密还原出任何明文内容。

### 1.4 凭证脱敏与硬件级认证保障

用户账号凭证绝不以明文或简单哈希形式存储。系统强制采用高强度密码学随机盐（Salt），结合 PBKDF2 算法进行 100,000 次密钥迭代拉伸，能够有效抵御离线彩虹表与专用 GPU 暴力碰撞。双重验证（TOTP）密钥入库前由主密钥实施对称加密；系统全面支持 WebAuthn / FIDO2 通行密钥（Passkey），私钥永久固化于用户本地安全芯片（Secure Enclave），根本杜绝网络钓鱼与伪造攻击。

### 1.5 全生命周期数据处理矩阵

本服务所涉全部数据类别、具体收集字段、处理目的、底层存储介质及留存周期如下表所列：

| 资料类别 | 具体收集字段 | 核心处理目的 | 存储介质与技术防护 | 保存与销毁周期 |
| --- | --- | --- | --- | --- |
| **帐号凭证** | 电子邮件地址、用户名、密码哈希与随机盐、TOTP 密钥、备用码哈希、Passkey 公钥 | 身份注册、登录验证、两步验证凭证找回 | Cloudflare D1；PBKDF2（100k 次迭代）、TOTP 静态 AES 加密 | 保存至帐号终止；账号注销时物理覆写清除 |

:::caution[加密之范围、技术说明与用户自主风险知情]
本服务在官方托管云端平台所提供之「加密存储」，系指**服务器端静态加密（Server-side Encryption at Rest）**。解密密钥由实例运行时的安全环境变量在处理收发逻辑时载入内存。该机制旨在防范数据库勒索、底层存储介质失窃或离线快照外泄等基础设施级风险，而非传统端对端加密（E2EE）。

在技术原理上，持有底层运维最高权限之系统运营者具备解密能力。我们没有阻挠任何人使用本服务，但用户必须充分知晓自身风险：若您的通讯涉及极高机密、国家安全或要求任何第三方（包括服务提供方）均绝对无法查阅之极度隐私场景，**当事人应当自主使用 GPG / OpenPGP 等客户端密码学工具在本地离线完成正文加解密后再行投递**。
:::

## 2. 双轨架构治理：官方托管服务与开源专案源码

官方托管站点 `mail.epocanvas.com` 由核心团队作为独立运营者提供。我们承诺全力维护托管节点的可用性、零商业广告注入及密码学防篡改标准，保障普通用户免费享用纯净、现代、高安全性的通讯服务。

托管服务属于非商业公益性质，不提供企业级商业 SLA（服务水准协议）保证，亦不对因不可抗力、上游云基础设施故障（如全球主干网中断）或用户自身保管不慎导致的凭证丢失承担间接赔偿责任。用户对其数据资产负有最终保管义务，应养成定期导出备份重要通信的良好习惯。

### 2.2 我们对用户的期望与反滥用红线

我们希望为所有用户营造安全、可靠的通讯环境。访问或使用我们的托管服务，您必须遵守以下基本行为准则：

*   **遵守适用的法律法规**：不得利用本服务违反出口管制、经济制裁或侵犯他人的法定权益；
*   **严禁发送垃圾邮件（Spamming）**：严禁利用本服务发送未经请求的大宗商业广告邮件、营销轰炸信件或高频恶意骚扰信息；
*   **严禁网络钓鱼与恶意攻击**：严禁散布恶意软件、木马病毒，严禁伪造发件人身份或冒充金融机构实施欺诈，严禁对系统进行对抗性破解注入；

### 3.1 欧盟通用数据保护条例（GDPR）权利全面赋能

对于位于欧洲经济区（EEA）的用户，系统全面落实 GDPR 第 15 至 22 条所赋予的数据主体法定权利：

*   **知情权与访问权（Articles 15）**：您可以随时在信箱界面中查阅系统收集的全部个人信息、登录历史与通讯记录；
*   **数据便携权与一键导出（Article 20）**：您可以随时导出属于自己的全部邮件数据副本，系统支持通用的标准 `.eml` 原始邮件格式与结构化 JSON 元数据包，便于您轻松迁移至其他服务商；
*   **删除权与被遗忘权（Article 17）**：当您主动申请注销账号时，系统不仅会立即切断所有会话并清空数据库关联记录，更会在物理存储层销毁加密主密钥，从密码学数学底层实现永久且不可逆的彻底物理覆写灭失；
*   **跨境数据传输标准（SCCs）**：系统跨境中继与边缘分发严格依托 Cloudflare 全球网络所具备的欧盟标准合同条款（Standard Contractual Clauses, SCCs）与 GDPR 附录协议保障流转合法性。

### 3.2 加利福尼亚州消费者隐私法案（CCPA / CPRA）刚性承诺

对于美国及加利福尼亚州居民，我们依据 CCPA / CPRA 做出以下明确披露与不可撤销之承诺：

*   **绝不销售或共享个人信息承诺（Do Not Sell or Share My Personal Information）**：我们在过去 12 个月内未曾、且未来亦绝不向任何数据经纪商、广告公司或商业第三方销售、出租、交易或共享任何用户的个人信息、通讯内容或使用习惯；
*   **限制使用敏感个人信息**：我们收集的信息仅用于向您提供电子邮件通讯服务，绝不用于跨上下文行为广告（Cross-context Behavioral Advertising）分析或训练未经许可的商业 AI 模型；
*   **非歧视待遇原则**：您行使任何法定的隐私权利（包括要求删除数据或限制处理），系统均绝不在功能完整性、服务质量或传输速率上对您施加任何歧视性差别对待。

### 3.3 亚太地区法规调适与跨境网络路由认知

官方托管团队位于台湾，严格遵守当地个人资料保护法制（PDPA）。在面对全球化互联网时，当事人应对底层技术机制保持理性认知：

电子邮件本质上是基于国际公网 SMTP 协议流转的分布式协议。当您与全球不同国家或地区的收件人互相通信时，数据包在跨国骨干网中继过程中可能穿越不同国家和地区的网络交换节点，并受沿途电信网络法例管辖。用户应切实保管好自身终端设备安全（防范本地键盘记录木马、定期更新操作系统），并优先启用 FIDO2 通行密钥增强账户抗风险能力。

### 3.4 72 小时安全事件应急响应与官方联络渠道

我们建立了标准化的安全应急响应标准作业程序（SOP）：

*   **快速阻断与威胁隔离**：一旦监测到安全威胁，边缘网关将于数分钟内阻断异常来源 IP、强制吊销涉事会话 JWT 令牌，并视险情立即轮换实例加解密主密钥；

*   **开源代码协同修复**：查明漏洞根因后立即合并上游修复补丁并发布安全公告（Security Advisory），协助全网自建节点同步修补。
