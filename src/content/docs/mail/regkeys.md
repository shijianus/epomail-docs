**生效日期：2026 年 10 月 6 日｜版本：5.17**

注册密钥是管理区的邀请码界面（`#manage/admin/reg-keys`，权限键 `reg-key:query`），控制谁能注册本实例。注册码的三种全站模式（必填／关闭／选填）由[系统设置](/mail/system/)的网站设置卡决定。

*图：注册密钥*

<details>
<summary>图解：注册密钥空白页——签发入口与检索框</summary>

注册密钥页在尚未签发任何邀请码时的空状态：一个签发按钮与一个搜索框构成本页全部分区。

1. **添加注册码按钮**：签发入口：弹窗内一次生成一条 8 位随机码（可点击刷新重新生成），并绑定注册后进入的身份分组、有效期与可用次数（1–99999，每成功注册一次扣减一次）。
2. **注册码搜索框**：签发后按注册码筛选定位，查看剩余次数、绑定分组与有效期；访客视角的敏感字段自动脱敏。
3. **空状态卡片**：实例尚未签发任何注册码时的引导占位；签发后此区变为码列表，附一键复制、使用记录查验、单条删除与「清理未用」批量作废。

</details>

## 1. 签发

「添加」弹窗一次签发一条注册码，可配置：

| 字段 | 说明 |
| --- | --- |
| 注册码 | 8 位随机码，可点击刷新重新生成 |
| 绑定分组 | 经此码注册的帐号进入指定身份分组（分组见[权限控制](/mail/roles/)） |
| 有效期 | 到期日后不可再用 |
| 可用次数 | 1–99999；每成功注册一次扣减一次 |

## 2. 管理与查验

| 操作 | 说明 |
| --- | --- |
| 列表 | 显示剩余次数、绑定分组、有效期；访客视角敏感段脱敏 |
| 复制 | 一键复制注册码文本，便于分发给受邀者 |
| 使用记录 | 查看该码已被哪些帐号使用 |
| 删除 | 立即作废该码 |
| 清理未用 | 一键清除所有尚未使用的码 |

URL 携带邀请码参数（`?code=`／`?regKey=`／`?invite=`）可直接预填注册表单，见[界面与路由总览](/mail/interface/)第 5 节。

<details>
<summary>图解：注册密钥的操作步骤</summary>

1. 进入管理区「注册密钥」（需 `reg-key:query` 权限）。
2. 点「添加」生成 8 位随机码（可点击刷新重新生成）。
3. 绑定注册后进入的身份分组，设置有效期与可用次数（1–99999）。
4. 复制注册码发给受邀者；「使用记录」查验消耗情况；「清理未用」一键作废全部未用码。

</details>
