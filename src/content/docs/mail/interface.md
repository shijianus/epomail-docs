**生效日期：2026 年 10 月 5 日｜版本：5.17**

本页逐一导览 EpoCanvas Mail 的每一处界面及其路由。界面路径由两部分组成：路径前缀 `/mail/u/N/`（N 为多账户会话序号，单帐号恒为 0）与 `#` 后的视图路由（如 `#inbox`）；旧式直达路径（如 `/inbox`）会自动归一化为完整形态。登录面独立部署于 `/login/`。各路由之访问能力由身份分组权限决定，见[运行模式](/mail/modes/)；逐项设置之作用见[设置指南](/mail/settings/)。

![EpoCanvas Mail 收件箱全景：左侧写信入口与文件夹树，右侧邮件列表带验证码徽标与官方认证标记](/images/mail/ui/views-guide.png)

*图：收件箱（`#inbox`）。八视图共用同一列表骨架，计数与标签即时同步。*

<details>
<summary>图解：收件箱全景——四个最先用到的入口</summary>

这张收件箱全景图的四个标注分区，对应日常使用频率最高的四个入口：写一封新信、翻重要邮件、查延后事项与核对已寄出。

1. **写信（侧栏顶部主按钮）**：全局唯一的新建邮件入口，点击弹出写信弹层（非独立路由）；移动端为右下悬浮按钮，亦支持 `?composeTo=<地址>` 深链预填收件人。任何视图下都可一键开始写信。
2. **星标邮件（侧栏文件夹）**：所有加星邮件跨文件夹聚合于此：在列表行点击星形图标即入此视图，用于收藏需要长期保留或快速再访的邮件；侧栏计数实时反映数量。
3. **稍后处理（侧栏文件夹）**：延后跟进的暂存区，分「紧急」与「等待」两档：在详情页选「延后」并指定时间，到期自动回到收件箱顶部，重要事项不再沉底。
4. **已发送（侧栏文件夹）**：本帐号发出的全部邮件存底，可在此核对哪些信已实际寄出；出站量受帐号角色的每日发信配额约束，站内信直投、站外经投递通道。

</details>

## 1. 邮箱主界面

登录后进入的主界面按视图路由区分，九个路由如下：

| 视图路由 | 界面 | 主要内容 |
| --- | --- | --- |
| `#inbox` | 收件箱 | 默认视图；时间正／倒序切换、新邮件轮询增量插入、虚拟滚动列表、未读红点、会话聚合 |
| `#all` | 全部邮件 | 跨文件夹汇总视图；点击侧栏标签即跳转本视图并按该标签过滤 |
| `#message` | 邮件详情 | 回复／回复全部／转发、星标、已读未读、移动到、举报垃圾、延后处理、加标签、表情回应、AI 全文翻译、打印单封或会话、下载 .eml、查看原始信头、屏蔽发件人、由此创建过滤器 |
| `#sent` | 已发送 | 本帐号发出的邮件 |
| `#drafts` | 草稿箱 | 本地草稿；未填收件人时显示占位标记 |
| `#starred` | 星标邮件 | 星标集合视图 |
| `#snoozed` | 延后处理 | 分紧急与等待两档；到期自动回到收件箱 |
| `#spam` | 垃圾邮件 | 被系统或用户判定为垃圾的邮件 |
| `#trash` | 回收站 | 已删除邮件；自收受之日起 7 日实体删除 |

写信为弹层而非独立路由，触发点有三：侧栏「写信」按钮、移动端悬浮按钮（需发信权限）与深链 `?composeTo=<地址>`（打开写信窗并预填收件人）。

![EpoCanvas Mail 写信窗口：发件人锁定当前信箱，富文本工具栏与附件、发送按钮](/images/mail/ui/ui-compose.png)

*图：写信弹层。站内信箱直投，站外经营运者配置之通道投递。*

<details>
<summary>图解：写信弹层自上而下的分区构成</summary>

写信弹层自上而下的分区：发件人锁定、收件人与主题、富文本工具栏、正文编辑区与底部动作条。

- **发件人行**：发件人锁定为当前登录信箱，写信时不可手工改写，因此本平台发出的邮件不存在 From 伪造。多信箱帐号可在此下拉切换发件身份，寄出后收件人看到的是所选信箱；发件人地址亦决定出站邮件走哪条投递通道。
- **收件人与主题行**：收件人支持联系人选择与 `?composeTo=` 深链预填；主题进入列表展示并可被 `subject:` 检索。
- **工具栏与正文区**：17 项排版工具：段落、字号、字样式、颜色、对齐、列表、引用、链接、图片、表格、表情、翻译与源码模式。
- **底部动作条**：附件按钮（能力依角色开启，单附件上限依实例设置）与发送按钮；站内直投、站外经营运者配置通道投递。

</details>

## 2. 界面骨架

主界面由四个区域构成：

| 区域 | 元素 |
| --- | --- |
| 顶栏 | 搜索框（邮件页搜邮件、设置页搜配置项，见[搜索与规则参考](/mail/search/)）、明暗切换、帮助、公告铃铛（有未读公告时显示）、账户菜单（头像、存储用量条、账户详情、设置、退出；菜单页脚附项目介绍、隐私政策与服务条款外链；多账户模式另附切换、添加与全部退出） |
| 侧栏 | 写信按钮、八个文件夹导航与未读计数、标签区（至多 7 个）与新建标签入口 |
| 状态栏 | 连接状态、最近同步时间、未读数、邮件模式徽标（加密模式下提示）与版本号 |
| 主区 | 当前视图的列表或详情 |

宽度低于 1025 像素时侧栏收合为抽屉并以遮罩唤出，路由切换自动收起。

## 3. 设置区

进入设置后主区切换为设置面板，邮件侧栏随之隐藏。五个分区路由：

| 分区路由 | 分区 | 内容 |
| --- | --- | --- |
| `#settings/profile` | 个资 | 头像、昵称、性别、生日、邮箱、电话与地址 |
| `#settings/general` | 常规 | 简介、外观色调、主题壁纸、阅读偏好、语言与数据隐私 |
| `#settings/security` | 安全 | 用户名与密码、两步验证中心、通行密钥、注销帐号 |
| `#settings/data` | 资料 | 数据导出、通知与转发、第三方应用授权、存储空间 |
| `#settings/labels` | 标签 | 标签管理与分类规则构建器 |

![EpoCanvas Mail 常规设置页：个性装扮区、主题壁纸与外观色调](/images/mail/ui/ui-settings-general.png)

*图：常规分区。五个设置分区共用同一骨架，左栏为分区导航。*

<details>
<summary>图解：设置区的外壳——左栏导航与右区内容</summary>

常规设置分区的外观样貌：左栏为五个设置分区的导航，右区为常规项（外观色调、主题壁纸等）。

- **左栏分区导航**：个资/常规/安全/资料/标签五分区切换；进入设置后邮件侧栏隐藏，由「返回邮件」回主界面。
- **个性装扮区**：外观色调三态（暗色／亮色／跟随系统）与全局主题壁纸（八种预设 + 自定义图片或 URL）。范围是全站所有视图，与仅覆盖信箱区的「个人背景」不同；顶栏另有色调快捷切换，不必回到本页。
- **其余分组**：本页剩余三组设置：阅读偏好（收件箱类型、阅读窗格位置、会话视图）、语言（界面语言六选一、AI 翻译目标语言 16 选一）与数据隐私（个人信息处理与 AI 处理偏好的集中入口）。此图仅示左栏与面貌，逐项含义见设置指南第 3 节。

</details>

## 4. 管理区

管理区路由为 `#manage/admin/<分区>`；路径中的角色组段须与帐号身份相符（站长为 `admin`、协管者为 `moderator`），不符时自动归位到可用分区。每个分区绑定独立权限键，逐分组授权于权限控制页：

| 分区路由 | 分区 | 权限键 | 职责 |
| --- | --- | --- | --- |
| `#manage/admin/analysis` | 分析页 | `analysis:query` | 收发量、拦截率、来源分布、增长曲线与 AI 用量仪表 |
| `#manage/admin/users` | 用户列表 | `user:query` | 帐号查询、重置密码、调整分组、封禁与恢复 |
| `#manage/admin/mail` | 全部邮件 | `all-email:query` | 全库邮件审查、`$` 高级检索、详情抽屉与物理删除 |
| `#manage/admin/roles` | 权限控制 | `role:query` | 身份分组、配额模板与 AI 模型授权 |
| `#manage/admin/reg-keys` | 注册密钥 | `reg-key:query` | 邀请注册码的签发与查验 |
| `#manage/admin/system` | 系统设置 | `setting:query` | 实例级配置，配置卡清单见[设置指南](/mail/settings/) |
| `#manage/admin/apps` | 应用管理 | `setting:query` | OAuth 2.0／OIDC 第三方应用凭证 |
| `#manage/admin/rules` | 分类管理 | `setting:query` | 收发开关、AI 识别、黑白名单与硬拦截 |
| `#manage/admin/audit` | 操作报告 | `setting:query` | 四类预警的研判、处置与申诉裁决 |

![EpoCanvas Mail 操作报告页：四类预警工单与处置按钮](/images/mail/ui/ui-audit-report.png)

*图：操作报告（`#manage/admin/audit`）。列表研判，处置按钮按预警类别分流。*

<details>
<summary>图解：操作报告在管理端的表格化样貌</summary>

操作报告页的管理端样貌：预警工单表格化研判，处置按钮按预警类别分流。

- **工单表格**：每行一条预警工单，列含类别（审计／风控／封禁／申诉）、优先级（P0／P1）、当前状态，以及活跃环境池的纯文本信息——IP、地理、设备与指纹。环境池按请求行为聚合，同一帐号在多 IP 并发登录时才会累积出可见的异常特征。
- **处置按钮**：按钮随工单类别分流：申诉警告把「研判放行」提到最显眼处（放行即恢复帐号），封禁警告突出「解除预警」，其余类别走标准操作菜单。按钮只提交研判结论，真正的封禁与恢复仍由用户列表页落地，两页状态同步。
- **模式联动**：同一张表在三种邮件模式下形态不同：全部邮件模式（L1）信息最全；隐私模式（L2）下本页即图中样貌；加密模式（L3）记录时间戳被剥离、时间列隐藏，管理员只能凭类别与环境池研判，无法还原事件发生次序。

</details>

## 5. 登录面

`/login/` 为独立的登录应用，与主界面分离部署。同一登录卡承载全部流程：

| 流程 | 行为 |
| --- | --- |
| 密码登录 | 帐号（邮箱）与密码提交；连续失败触发防爆破锁定 |
| 两步验证 | 验证器应用（TOTP 六位码）、备用恢复码与通行密钥三选一或多重依次验证；勾选「以后本设备登录不再验证」发放 30 天信任 |
| 第三方登录 | 管理员启用并配置密钥的提供商显示为按钮；开启而未配置密钥的灰显「即将上线」 |
| 注册 | 邮箱（可选预设域名后缀）、密码与注册码；注册码模式分为必填、关闭与选填三档，URL 可携带邀请码参数 |
| 忘记密码 | 弹窗跳转外部申诉门户，携带申诉类型、界面语言与邮箱参数 |
| 添加账户 | 多账户模式下经 `?action=addAccount&u=N` 进入，登录后落入对应会话位 |

![EpoCanvas Mail 登录页：邮箱与密码输入框、保持轨道连接勾选框与第三方快捷登录按钮](/images/mail/ui/ui-login-oauth.png)

*图：登录页。第三方按钮的三态显示规则见[运行模式](/mail/modes/)第 4 节。*

<details>
<summary>图解：登录页承载的全部流程</summary>

登录面的整体样貌：同一登录卡承载密码登录、两步验证、第三方快捷登录、注册与忘记密码全部流程。

- **输入区**：本页最常走的路径：邮箱即帐号，密码经加盐哈希存储、服务端不接触明文。连续失败会触发防爆破锁定，锁定粒度与时长由后端策略决定；勾选「保持轨道连接」后本设备 30 天内免重复验证。
- **第三方按钮区**：管理员启用并配置密钥的提供商显示为按钮；开启而未配置密钥的灰显「即将上线」，未启用的不显示。
- **其余流程**：同一张卡还承载另外三条路径：已开启两步验证的帐号提交后进入第二验证（TOTP、恢复码或通行密钥）；注册码模式下可携带 code 参数直接预填注册表单；「忘记密码」跳转外部申诉门户并带上申诉类型、界面语言与邮箱。逐条规则见运行模式第 4 节。

</details>

## 6. 独立页面与全局能力

| 界面 | 路由 | 说明 |
| --- | --- | --- |
| OAuth 授权页 | `#/oauth/authorize` | 第三方应用申请授权时显示：应用信息、官方认证徽章、访问范围清单与授权／取消 |
| 公开个人主页 | `/<用户名>` | 未登录可访问；展示头像、时区、身份分组、加入时间、个人数据看板与「邮件联系我」；是否开放由管理员「公开个人主页」开关决定 |
| 404 页 | 其余路径 | 未知路径的空状态页与回首页入口 |
| PWA | — | Web 端可安装为应用；另提供 Android 应用（epomail） |

邮件模式亦改变管理界面：加密模式（Level 3）下全库邮件审查入口隐藏、操作报告剥离时间戳，见[运行模式](/mail/modes/)第 2 节。
