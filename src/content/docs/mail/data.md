<details>
<summary>图解：资料页——个人数据自主的四个分区</summary>

资料页的四张卡片：数据带走的三个格式、一个转发区、一个存储区与一个第三方授权区，个人数据自主的完整界面。

1. **用户资料与数据导出卡**：提供 JSON 资料导出、邮件归档（MBOX／JSON／CSV）与个人资料及标签导出；三者均来自同一后端响应，时间范围参数未生效，单封 .eml 也由现有字段重新拼接。
2. **邮件与消息转发卡**：Telegram 消息推送与自动转发的逐项配置；两项功能是否对帐号开放由管理员「用户资料控制」开关决定。
3. **存储空间卡**：显示邮件与附件的计量用量及有效配额；自备 Backblaze B2／S3 可承接新附件并绕过附件保存路径的系统配额检查，其他邮件限制仍适用；解除接入不会迁移旧对象。
4. **第三方应用和服务卡**：显示 OAuth 授权并提供撤销操作。后端删除对应授权并记录撤销状态，userinfo 请求据此拒绝访问；不能保证第三方会话、已取得资料及全部现有权杖同步回收。

</details>

## 1. 三类导出

| 导出项 | 格式 | 范围 |
| --- | --- | --- |
| 汇出全量数据 | JSON | 部分帐号与个人资料、`is_del=0` 邮件的选定字段及 `customLabels`；不含附件文件、原始 MIME、完整联系人／别名资料、安全设置或审计记录 |
| 邮件历史归档 | MBOX、JSON 或 CSV | 浏览器将同一响应的邮件字段转换成所选格式；后端忽略 `type/format/range`，未按所选时间范围筛选，垃圾桶邮件被排除 |
| 通讯录与配置 | JSON | 仅后端返回的 profile 子集、customLabels 与导出时间；不是完整通讯录、别名规则或全部偏好的备份 |

单封 .eml 与批量 MBOX 均由已有字段重新拼接，不包含完整原始 MIME 或附件文件。垃圾桶按邮件创建时间超过 7 天清理，不保证移入后再保存 7 天；请在删除前另存附件并核对导出内容，范围与权利见[隐私政策](/mail/privacy-policy/)。

本轮本地实现另将完整原始 MIME 以服务器端 AES-256-GCM 加密后暂存在对象存储，用于投递恢复。应用设定 7 天清理期限，失败重试可续期，成功入库也不立即删除；计划任务分批清理，清理失败的对象保留待重试，因此不是存储层 TTL 到期即删除的保证。该暂存不纳入自助导出，单封 .eml 与 MBOX 仍由字段重建，也不证明线上实例已全部部署。

当前本地实现会在普通退出时清除当前会话、当前邮件缓存和收件人历史，保留其他账号会话与本地草稿；删除草稿列表项时，草稿与 `att` 附件在同一 IndexedDB 事务内删除。这些本机内容不在服务器导出中。

共用或转让设备前，先另存所需草稿，再在「设置 → 资料 → 隐私与本机资料」选择「清除本机全部本站资料」。确认范围包括此浏览器内本站所有账号的登录、设备信任、缓存、设置、草稿及附件，并会退出登录；阻塞或部分失败须按提示重试，或通过浏览器清除本站资料，不能视为已全部清除。此动作不撤销所有服务器凭据，也不删除其他网站资料、聊天副本、服务器静态头像、审计记录或备份。同卡的自动验证码识别默认关闭，须个人选用、服务已配置且提供资料去向说明才可开启。以上是本轮本地实现，不证明所有线上实例已部署；同源存储边界见隐私政策第 4.3 节。

## 2. 存储空间

- 附件存储用量仪表实时显示用量与配额，配额依身份分组（出厂值见[运行模式](/mail/modes/)第 3 节）；
- 可接入个人 Backblaze B2／S3 存储桶；启用后新附件按个人配置保存，附件保存路径可绕过系统配额检查，但统计与其他邮件限制仍存在。服务商费用及外部保存规则须另行确认，见[第三方处理者清单](/mail/sub-processors/)；
- 解除接入不迁移或删除原桶对象。旧附件的 BYO 来源定位保留，待对象清理队列确认后才结束相关处理，不能把解绑当成清理完成；旧附件可读性及删除限制见[数据处理与安全维护](/mail/data-security/)。

<details>
<summary>图解：导出与存储的操作步骤</summary>

![导出与存储的操作步骤](/images/mail/ui/data.png)

1. 进入「设置 → 资料」。
2. 「汇出全量数据」下载选定个人资料、未删邮件字段与 customLabels 的 JSON；附件、完整通讯录及安全设置须另行处理。
3. 「邮件历史归档」选择 MBOX／JSON／CSV 后下载；格式由浏览器转换，后端不应用时间范围。
4. 「通讯录与配置」导出返回的 profile 子集与 customLabels；请核对所需联系人和偏好是否包含。
5. 存储卡查看附件用量；点「接入存储桶」绑定自备 Backblaze B2／S3，之后附件直存个人云端。

</details>
