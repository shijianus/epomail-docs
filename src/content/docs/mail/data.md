<details>
<summary>图解：资料页——个人数据自主的四个分区</summary>

资料页的四张卡片：数据带走的三个格式、一个转发区、一个存储区与一个第三方授权区，个人数据自主的完整界面。

1. **用户资料与数据汇出卡**：三类导出并列：全量 JSON 备份、邮件历史归档（MBOX/JSON/CSV + 时间范围）与通讯录配置；单封邮件另可在阅读页下载 .eml。
2. **邮件与消息转发卡**：Telegram 消息推送与自动转发的逐项配置；两项功能是否对帐号开放由管理员「用户资料控制」开关决定。
3. **存储空间卡**：附件存储用量仪表实时对照配额；可接入自备 Backblaze B2/S3 存储桶，接入后新附件直存个人云端、不受实例配额约束，解除接入即回落。
4. **第三方应用和服务卡**：用户名下全部 OAuth 授权的应用列表：逐应用移除访问权限，或经详情弹窗一键撤销全部；撤销即时生效，应用现有令牌立即失效。

</details>

## 1. 三类导出

| 导出项 | 格式 | 范围 |
| --- | --- | --- |
| 汇出全量数据 | JSON | 完整备份：帐号个资、历史邮件、通讯录、分类与标签规则及安全设置 |
| 邮件历史归档 | MBOX（通用）、JSON 或 CSV | 仅收发邮件，可限定时间范围 |
| 通讯录与配置 | JSON | 联系人名录、自定义别名规则与系统个性化偏好 |

单封邮件可在阅读页直接下载为 .eml。回收站邮件 7 日实体删除且不可复原，需要留存请先导出（见[服务条款](/mail/terms-of-service/)第 8 节）。

## 2. 存储空间

- 附件存储用量仪表实时显示用量与配额，配额依身份分组（出厂值见[运行模式](/mail/modes/)第 3 节）；
- 可接入个人对象存储（自备 Backblaze B2 或 S3 存储桶）：接入后新附件直接保存于您的云端，不再占用实例配额；平台对 B2 的推荐基于其免费额度与 0 出站流量费；
- 接入状态随时可解除，解除后新附件回落实例存储。

<details>
<summary>图解：导出与存储的操作步骤</summary>

![导出与存储的操作步骤](/images/mail/ui/data.png)

1. 进入「设置 → 资料」。
2. 「汇出全量数据」打包下载 JSON 完整备份（含个资、历史邮件、通讯录、规则与安全设置）。
3. 「邮件历史归档」选择 MBOX／JSON／CSV 格式与时间范围后下载。
4. 「通讯录与配置」导出联系人名录与个性化偏好。
5. 存储卡查看附件用量；点「接入存储桶」绑定自备 Backblaze B2／S3，之后附件直存个人云端。

</details>
