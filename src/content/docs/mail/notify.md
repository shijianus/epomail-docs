本页逐步说明「设置 → 资料」页「邮件与消息转发」区的两项能力：Telegram 消息推送与自动转发。两项功能是否对帐号开放由管理员「用户资料控制」卡决定；关闭时对应区块不显示。数据导出与存储亦在同一页，见[设置指南](/mail/settings/)第 5 节。

## 1. Telegram 消息推送

推送使用您自备的私有 Telegram 机器人，新邮件实时直达您的会话：

1. 向 @BotFather 申请一个私有机器人，取得 Bot Token（形如 `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`）；
2. 获取您与该机器人的 Chat ID（向机器人发送任意消息后经 getUpdates 查询，群组为负数、频道形如 `-100123456789`）；
3. 在「Telegram 消息推送」项点设置，填入 Bot Token 与 Chat ID；在群组话题内接收时可另填 Topic ID；
4. 选择推送类型偏好：全部邮件，或仅重要与验证码邮件；
5. 点「发送测试消息」验证连通，成功后开启推送。

推送内容的字段显示偏好（发件人、收件人、邮件正文）由管理员在系统设置的邮件推送卡全局配置；官方机器人的全站推送与个人私有机器人互不冲突。

## 2. 自动转发

| 配置项 | 说明 |
| --- | --- |
| 启用自动转发 | 总开关；开启后出现下方配置 |
| 转发目的地邮箱 | 一个或多个目标地址，多个以英文逗号分隔 |
| 触发类型 | 全部邮件直接抄送转发；或仅当收件信箱命中指定前缀／字母别名（如 `billing`、`dev-*`）时转发 |
| 主题标头 | 可选在转发邮件主题添加 `[Fwd]` 标头，便于在目标邮箱中识别 |

:::note
界面另提供「智能规则过滤转发」与「保留邮件原件」选项；当前版本的转发引擎将智能规则档按全部邮件处理、尚未应用保留原件选项，依赖这两项行为前请先实测。
:::

## 3. 投递路径与防回环

转发优先经平台原生转发通道投递，失败时自动改经系统投递通道并按开关附加 `[Fwd]` 前缀；目的地与收件人或原发件人相同时自动跳过，避免转发回环。触发类型与高级选项的规则语义亦见[搜索与规则参考](/mail/search/)第 7 节。
