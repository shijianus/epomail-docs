## 1. 法律名词

| 名词 | 定义 |
| --- | --- |
| 个人数据 | 与已识别或可识别自然人有关的数据，包括账号、网路纪录，以及邮件内容、附件或中继数据中的个人信息；不限于注册栏位 |
| 匿名化／假名化 | 匿名化须达到不能以合理可能使用的手段识别个人；可用额外资料恢复关联的假名化、散列或遮盖仍可能是个人资料。合成邮件不使真实账号与访问日志自动匿名 |
| 高敏感个人数据 | 健康、基因、用于唯一识别的生物识别、性生活等依法受特别保护的数据；刑事定罪与犯罪资料受独立规则规范，各法域的分类与要件不完全相同 |
| 蒐集／处理／利用 | 包括取得、记录、存储、检索、传送、使用及删除等操作；台湾法律区分蒐集、处理与利用，GDPR 的处理概念涵盖较广，不宜机械套用 |
| 数据控制者 | 单独或共同决定特定处理目的与方式的主体；依事实判断，不因自建而当然唯一排他，也不将每位个人使用者一律视为控制者 |
| 受托处理者 | 代表控制者并依其合法指示处理数据的主体；同一提供者就自行决定目的的其他活动可能是独立控制者 |
| 当事人 | 数据所涉及的自然人，包括使用者、寄件人、收件人及邮件提及的人，不必已建立账号 |
| 国际传输 | 依法构成跨境提供或使境外接收者可访问数据的活动；须按实际路径评估适法机制，供应商认证不自动满足传输要求 |
| 告知义务 | 依法说明处理者身分、目的、依据、来源、接收者、保存及权利等信息；间接来源包括寄件人、身分提供者、检举人或整合服务，时点与例外依适用法律 |
| 特定目的 | 处理前明确界定的目的，数据处理应限于合法、必要且相容的范围；学习或测试不等于可任意使用真实邮件 |
| 行销拒绝权 | 当事人可依适用法律拒绝直接行销；收到拒绝后应停止相应使用，并提供易用的拒绝方式 |
| 主管机关 | 依处理活动与现行法律有管辖权的机关；不仅限运营者所在地。欧盟机关可查阅 [EDPB 成员名单](https://www.edpb.europa.eu/about-edpb/about-edpb/members_en) |
| 非自愿性性影像 | 未经同意制作或散布的性影像，包括有害合成影像；限制接取、必要保存及救济见[可接受使用政策](/mail/acceptable-use/) |
| 儿少性剥削 | 对儿童及少年进行性虐待、剥削、引诱，或制作、持有、散布相关违法内容；保护、通报与证据保存依适用法律 |
| 准据法 | 契约有效选定或依法确定的法律；不得排除强制的消费者、数据保护或司法救济权，见[服务条款](/mail/terms-of-service/)第 11 节 |
| 定型化契约 | 为多数使用者预先拟定的契约条款；不公平或依法不得排除权利的内容，不因点击接受即当然有效 |
| 数据处理协议（DPA） | 对实际受托处理的事项、指示、安全、协助与终止等作成的必要协议；组织用途须另行确认及订立，名称不能改变实际角色 |
| 数据保护长（DPO） | 符合法定条件时须指定的独立数据保护职务；一般隐私联络信箱不等于已任命 DPO |
| 欧盟代表 | 在适用 GDPR 的特定境外处理情形下依法指定的欧盟境内联络代表；不同于 DPO，不因提供欧语界面就宣称已任命 |

## 2. 技术名词

| 名词 | 定义 |
| --- | --- |
| 实例（站点） | 特定运营者管理的一份 EpoCanvas Mail 部署，如 `mail.epocanvas.com`；数据流依其基础设施与功能设置而异 |
| 运营者 | 实际决定并管理实例服务的自然人或组织；作者同时运营时，也依其行为承担义务 |
| PBKDF2 | 由密码与盐值衍生验证值的机制，用于提高猜测成本；不是保证弱密码不会被破解，实际参数见安全文件 |
| TOTP | 以共享秘密及时间产生一次性验证码的机制；伺服器须保护所持秘密，并非仅存储公开密钥 |
| Passkey（通行密钥） | WebAuthn 凭证；伺服器保存公钥、凭证识别及必要的验证中继数据，私钥由验证器或所选同步服务管理，不传给本服务验证伺服器 |
| JWT（工作阶段权杖） | 用于登录工作阶段的签章权杖；签章不等于加密，效期、撤销与工作阶段限制依部署实作 |
| localStorage | 浏览器中可跨工作阶段保存数据的机制；可能保存登录状态及偏好，并不证明所有页面或第三方元件均无 Cookie |
| 静态加密（encryption at rest） | 存储数据的加密；邮件主旨与正文依模式处理，附件及中继数据不自动受同一应用层加密保护。持有伺服器与密钥者仍可能解密 |
| 端对端加密（E2EE） | 仅通讯端点掌握解密能力的设计；本服务未提供此保证，自行使用 OpenPGP 亦不必然隐藏信封信息或其他中继数据 |
| HMAC 混淆路由 | 将资源识别与使用者信息绑定的机制，可降低列举与未授权访问风险；仍须伺服器授权检查，不能保证无越权 |
| RBAC | 按角色限制操作与数据访问的机制；有效性依权限设置、检查与维护，不构成绝对安全保证 |
| D1／KV／R2 | Cloudflare 的数据库、键值与对象存储服务；实际数据位置、复本及保存依配置与提供者安排 |
| 遥测（telemetry） | 自动回报使用或诊断数据的行为；未设上游使用分析不代表无第三方流量，字型、验证、投递及选用服务仍可能发出请求 |
| 软删除／实体删除 | 前者标记或限制数据使用，后者从指定存储移除；不表示备份、外部副本与合法保存数据同步消失，也不保证必可恢复或必不可恢复 |
| BYOS（自备存储） | 使用所配置的 S3 相容对象存储；端点、凭证与档案可能由实例为完成访问而处理，非仅留在使用者装置 |
| Workers AI | Cloudflare 推论服务；启用的自动处理与使用者触发功能可能传送邮件内容，范围及依据见[隐私政策](/mail/privacy-policy/) |
| Turnstile | Cloudflare 的人机验证服务；验证请求与必要技术数据涉及第三方处理，详见[第三方处理者清单](/mail/sub-processors/) |
| SSRF 防护 | 限制伺服器被诱导访问不适当目的地的检查；覆盖范围与效果依实际路径及部署，不代表所有外部请求均已消除风险 |
