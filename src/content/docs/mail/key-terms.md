## 1. 法律名词

| 名词 | 定义 |
| --- | --- |
| 个人资料 | 指自然人之姓名、出生年月日、联络方式、社会活动及其他得以直接或间接方式识别该个人之资料。本服务所涉者以电子邮件地址、帐号凭证、网络活动记录为主 |
| 高敏感个人资料 | 病历、医疗、基因、性生活、健康检查及犯罪前科等高敏感类别之个人资料，其处理于多数法域受严格限制 |
| 收集／处理／利用 | 收集指以任何方式取得个人资料；处理指为建立或利用个人资料档案所为资料之记录、输入、存储、编辑、更正、复制、检索、删除、输出、连接或内部传送；利用指将收集之个人资料为处理以外之使用 |
| 数据控制者 | 决定个人资料收集、处理、利用之目的与方式之主体；托管实例之运营者、自行部署实例之部署者均属之 |
| 受托处理者 | 依控制者之指示，为其处理个人资料之主体（如 Cloudflare、Resend） |
| 当事人 | 个人资料所识别之自然人，即本站文档所称之「您」 |
| 国际传输 | 指将个人资料作跨国（境）之处理或利用；遵循适用法律之要求及标准合同条款等保障机制 |
| 告知义务 | 向当事人收集个人资料时，告知收集者名称、收集目的、资料类别、利用之期间地区对象方式、当事人得行使之权利及不提供之影响等事项之义务；收集非由当事人提供之资料者，于处理或利用前告知来源 |
| 特定目的 | 收集或处理个人资料所应有之特定目的；利用并应于该特定目的之必要范围内为之 |
| 营销拒绝权 | 当事人表示拒绝接受营销时，即停止利用其个人资料营销；首次营销时并提供表示拒绝之方式 |
| 主管机关 | 依适用法律主管个人资料保护事务之机关；托管实例所在地台湾之主管机关为个人资料保护委员会 |
| 非自愿性性影像 | 未经同意而被摄录、重制、散布之他人性影像，及以电脑合成等方法制作之不实性影像；未经同意摄录、重制或散布该等影像于多数法域构成犯罪，平台接获通知应先限制浏览或移除 |
| 儿少性剥削 | 对儿童或少年之性剥削行为，包括拍摄、制造、重制、持有、散布、播送、交付、公然陈列、贩卖或支付对价观览儿童或少年之性影像 |
| 准据法 | 契约所适用之法律，依运营者所在地确定；[服务条款](/mail/terms-of-service/)第 11 节载明各实例之准据法 |
| 定式合同 | 以概括条款就多数不特定人所为之契约约定；显失公平之部分依适用法律得不受拘束 |

## 2. 技术名词

| 名词 | 定义 |
| --- | --- |
| 实例（站点） | 运行于特定个人或组织之 Cloudflare 帐号内之一份 EpoCanvas Mail 部署，如 `mail.epocanvas.com` |
| 运营者 | 部署并管理实例之个人或团队；即各文档所称之「我们」 |
| PBKDF2 | 一种密码哈希算法。本服务以 HMAC-SHA256 执行 100,000 次迭代并附加每用户独立随机盐，使原始密码无法自哈希值反推 |
| TOTP | 依 RFC 6238 之时间性一次性密码；其密钥于数据库中以 AES-256-GCM 加密存储 |
| Passkey（通行密钥） | 依 FIDO2/WebAuthn 标准之公开密钥凭证；本服务仅存储公钥，私钥留存于当事人设备 |
| JWT（会话令牌） | 登录后签发之数字签名凭证，有效期 30 日；同帐号上限 10 个并行会话；登出即由服务器端撤销 |
| localStorage | 浏览器提供之网页存储机制，资料留存于当事人设备并可跨会话；本服务之会话令牌存于此处，不使用 Cookie |
| 静态加密（encryption at rest） | 资料写入存储媒体时之加密。本服务之密钥由实例服务器环境变量衍生，属服务器端加密，非端对端加密 |
| 端对端加密（E2EE） | 仅收发双方得解密之加密形态。本服务不提供；有此需求者应自行以 GPG 等工具预先加密 |
| HMAC 混淆路由 | 以哈希消息认证码将邮件识别码与用户身份绑定编码之机制，防止越权访问（IDOR）与资源枚举 |
| RBAC | 角色访问控制。本服务采默认拒绝（fail-closed）之多级权限模型，非白名单参数于网关剥离 |
| D1／KV／R2 | Cloudflare 之边缘 SQLite 数据库、全球复制键值存储与 S3 兼容对象存储，分别承载结构化资料、会话缓存与附件 Blob |
| 遥测（telemetry） | 软件自动向开发者回传使用资料之行为。本服务之源代码零遥测，不向上游回传任何实例资料 |
| 软删除／实体删除 | 软删除指标记删除，管理员得复原；实体删除指连同附件与索引自存储体中移除，不可复原 |
| BYOS（自备存储） | Bring Your Own Storage——将附件存于运营者或当事人自有之 S3 兼容对象存储（如 Backblaze B2、Wasabi）之机制；存储凭证由配置者自行保管 |
| Workers AI | Cloudflare 边缘推论服务；用于验证码提取等 AI 处理，触发条件与资料范围见[隐私政策](/mail/privacy-policy/)第 6 节 |
| Turnstile | Cloudflare 之人机验证机制；于注册与新增信箱时评估浏览器可信度，不以广告 Cookie 或跨站追踪为之 |
| SSRF 防护 | 服务端请求伪造（Server-Side Request Forgery）之阻断机制；对外部端点之请求一律经公共地址校验，回环、私有网段与云端元数据地址一律拒绝 |
