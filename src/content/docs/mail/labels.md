**生效日期：2026 年 10 月 6 日｜版本：5.15**

标签与分类规则在「设置 → 标签」（`#settings/labels`）管理。规则条件的完整字段表见[搜索与规则参考](/mail/search/)第 7 节；本页说明标签本身的操作与统计。

## 1. 标签的创建与外观

| 操作 | 说明 |
| --- | --- |
| 新建标签 | 侧栏标签区（至多 7 个）或标签页内新建并命名 |
| 图标 | 内置图标库任选，亦支持自定义 SVG |
| 颜色 | 标签色板自定义，列表与侧栏同步呈现 |
| 删除 | 删除标签同时解除其在规则中的引用 |

## 2. 出厂四标签

| 标签 | 维护方式 |
| --- | --- |
| 社群 | 默认规则按常见公共邮箱域自动归类 |
| 订阅 | 内置启发式：无回复前缀发件人、邮件营销平台域名、退订信号 |
| 推销 | 内置启发式：折扣与限时类主题词、正文营销词密度 |
| 工作 | 手动或自建规则维护 |

四个出厂标签可编辑可删除；启发式归类仅对未手动处理的新邮件生效。

## 3. 分类规则构建器

- 规则由「条件 + 例外」两步构成：条件全部命中且例外无一命中时执行动作；
- 条件字段（发件人、收件人、主题、正文、地址包含等）与多值语法见[搜索与规则参考](/mail/search/)第 7 节；取值输入带后端联想补全；
- `priority` 数值决定执行顺序（小者优先），`stopProcessing` 命中即截断后续规则；
- 规则在收信时自动执行，亦可在标签页对存量邮件手动执行。

## 4. 统计与复核

- 侧栏标签区实时显示各标签的总数与未读数；
- 分类结果可在管理区[分析页](/mail/analysis/)复核来源分布；站点级黑白名单与硬拦截由管理员在[分类管理](/mail/category/)配置。

<details>
<summary>图解：标签与规则构建器的操作步骤</summary>

![标签与规则构建器的操作步骤](/images/mail/ui/labels.png)

1. 进入「设置 → 标签」；在侧栏标签区或标签页新建标签（侧栏至多显示 7 个）。
2. 为标签挑选内置图标或上传自定义 SVG，并拾取标签颜色。
3. 在规则区以「条件 + 例外」两步添加规则；取值输入自带联想补全。
4. 设置 priority（小者优先）与 stopProcessing（命中截断）；规则于收信时自动执行，也可手动执行。

</details>
