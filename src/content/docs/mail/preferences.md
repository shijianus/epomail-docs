## 1. 个资（`#settings/profile`）

| 卡片 | 内容 |
| --- | --- |
| 基本信息 | 头像上传、个人昵称、性别、生日 |
| 联系信息 | 登录主邮箱（带主邮箱标记）、可添加多个额外电子邮箱并随时移除、含区号的电话号码 |
| 地址 | 住家、公司与其他三组地址卡 |

个资的对外展示受管理员「公开个人主页」开关约束；开放时经 `/<用户名>` 访问，见[界面与路由总览](/mail/interface/)第 6 节。

## 2. 常规（`#settings/general`）

| 分组 | 内容 |
| --- | --- |
| 个人简介 | 一段展示于公开个人主页的简介 |
| 个性装扮 | 外观色调（暗色／亮色／跟随系统）、全局主题壁纸（八种预设＋自定义壁纸与 URL）、个人背景、界面密度 |
| 阅读偏好 | 收件箱类型、阅读窗格位置、会话视图开关 |
| 语言 | 界面语言六选一；默认翻译目标语言独立设置（16 选 1）；图片文字识别翻译可单独关闭 |
| 数据隐私 | 个人信息与 AI 处理偏好的集中入口 |

## 3. 外观的作用范围

全局主题壁纸对所有视图生效，个人背景仅覆盖信箱区；暗色／亮色亦可在顶栏快捷切换。系统邮件与欢迎邮件按收件人语言投递，与界面语言设置独立。

<details>
<summary>图解：个资与常规的操作步骤</summary>

1. 「设置 → 个资」：上传头像，填写昵称、性别与生日。
2. 联系信息卡可添加多个额外电子邮箱与带区号的电话号码；地址卡分别保存住家、公司与其他地址。
3. 「设置 → 常规」：选择外观色调（暗色／亮色／跟随系统）与全局主题壁纸（八种预设或自定义）。
4. 设置阅读偏好（收件箱类型、阅读窗格、会话视图）与界面语言；默认翻译目标语言 16 选 1。

</details>
