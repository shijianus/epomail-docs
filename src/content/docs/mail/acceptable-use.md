# 可接受使用政策

**生效日期：2026 年 10 月 1 日｜版本：5.4**

本政策是[服务条款](/mail/terms-of-service/)第 7 节「可接受使用」之具体化，规定您使用 EpoCanvas Mail 服务（下称「本服务」）时之行为边界。违反本政策者，运营者得依「执行措施」节处置；涉有犯罪嫌疑者，并依法处理。

本政策所列行为，除违反本政策外，亦可能构成您或运营者所在地法律下之违法行为；具体定性以有权限机关之认定为准，本文件不构成法律意见。

本站法律文档以繁体中文（台湾）版本为正式版本，其他语言版本仅供参考；内容如有歧异，以繁体中文版本为准。

您不得利用本服务传输、存储或散布下列内容：

| 禁止行为 | 运营者之处置 |
| --- | --- |
| 儿童及少年性剥削内容，包括拍摄、制造、重制、持有、散布、播送、交付、公然陈列、贩卖儿少性影像或与性相关之图画、语音、物品 | 零容忍：一经发现即删除内容并终止帐号，保存证据并移交有权限机关；不适用申诉缓冲程序 |
| 对儿童及少年散布或播送有害其身心健康之暴力、血腥、色情、猥亵、赌博内容 | 零容忍程序：限制接取或先行移除 |

## 2. 非自愿性性影像

利用本服务上传、传输或存储非自愿性性影像者，一经查获，运营者即予限制浏览或移除，并依下列规定处理：

1. **刑事禁止**：未经同意摄录、重制、散布他人之性影像，或以电脑合成等科技方法制作并散布不实性影像，于多数法域构成刑事犯罪。
2. **平台移除义务**：运营者知有性侵害犯罪嫌疑情事，即先行限制浏览或移除与犯罪有关之资料；该等资料与嫌疑人之个人资料及网络使用记录，至少保留 180 日，以提供司法及警察机关调查。
3. **处置方式**：运营者接获通知或举报后，先行限制浏览或移除该等内容，保存证据并配合司法警察机关之调查。本节之处置不适用第 7 节之申诉缓冲程序。

## 3. 垃圾邮件与滥用行为

您不得为下列行为：

1. 传送未经请求之大量商业邮件（UBE／UCE）、向未经同意之收件人营销，或以本服务进行信箱暖机（warm-up）与地址验证轰炸。上开行为可能违反收件地之法律（如美国 CAN-SPAM Act、欧盟 ePrivacy 指令、加拿大 CASL）；跨国传输以收件地法律为准。以个人资料营销者，当事人表示拒绝接受营销时，应即停止利用其个人资料营销。
2. 以程序化手段批量注册帐号、绕过人机验证（Turnstile）、绕过注册密钥或配额限制。
3. 将本服务用作匿名转发跳板或短期一次性滥发池，或以规避处置为目的反复注册。

## 4. 攻击与干扰

您不得：

1. 对本服务或第三方系统进行扫描、探测、暴力破解；尝试越权访问他人信箱、管理界面或其他用户之资料。前揭行为可能构成犯罪，运营者并得依民事及行政途径求偿与处置。
2. 以无正当理由之方式使用 AI 翻译、附件、API 等共用资源，致妨碍其他用户之正常使用。
3. 对 Cloudflare、上游开源社区或运营者为骚扰、诽谤或权利滥用之行为。
4. 违反第三方服务（Cloudflare、Resend、Mailjet、Telegram 等）之使用条款。

## 5. 资源使用之一般义务

1. 您应依您帐号之存储配额使用资源；配额由运营者依角色设置。
2. 帐号与 API 令牌不得出借、出租或转让予第三人使用。
3. 您以自备外部存储（BYOS）与外部数据库者，应自行确保该等服务符合其所在地法律对国际传输之要求。

运营者依违规之性质与情节轻重，采取比例相当之处置；儿少性剥削内容不适用阶梯缓冲，径依零容忍程序办理。

## 7. 申诉与举报

1. **申诉**：您认为处置有误者，得通过[服务条款](/mail/terms-of-service/)第 13 节所列管道申诉；运营者应于合理期限内复核并答复。除情事紧急外，第 4 级以上之重大处置前，应给予说明之机会。
2. **举报**：任何人发现违反本政策之行为或安全隐患（垃圾邮件来源、钓鱼邮件、越权访问尝试等），得通过前述管道举报；善意举报一律获核实处理。
3. **例外**：涉儿少性剥削内容或第 2 节之非自愿性性影像者，运营者不适用申诉缓冲程序，径行删除、终止帐号，保存证据，并移交有权限机关处理。
