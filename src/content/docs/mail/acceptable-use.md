繁体中文（台湾）版为本站正式版本，其余语言为对照译本；此安排不限制适用法律要求的清楚告知、对消费者有利的解释或不得排除的权利。更新日期记录文本修订，变更之通知与适用依服务条款办理。

## 1. 违法与危害内容

不得利用服务从事下列行为。处置应考量可靠信息、实际危害与合法使用的可能性；紧急隔离及法定通报依第 6、7 节办理。

| 禁止行为 | 运营者之处置 |
| --- | --- |
| 儿童及少年性虐待、性剥削内容的制作、持有或散布，以及引诱儿少受侵害 | 立即限制接取、阻止传播；依法保存必要证据及通报，并审查账号终止 |
| 向儿少散布依法禁止向其提供的暴力、性或赌博内容 | 先限制有害接触，依法律与危害程度移除或限制账号 |
| 未经同意制作或散布性影像，包括有害的合成性影像 | 迅速限制接取或移除；保存与申诉依第 2 节 |
| 依法禁止散布、贩售或公开展示的猥亵内容 | 核实通知与适用法律后采必要措施 |
| 诈欺、钓鱼、冒用身分或伪造寄件人以欺骗他人 | 隔离内容、限制涉事功能并依法处理 |
| 恶意软体散布、凭证窃取、未经授权入侵或破坏系统 | 立即隔离危害并复核；第 4 节的合法隔离测试另依授权范围判断 |
| 侵害着作权、商标权、隐私或违法揭露他人数据 | 核实权利及合法使用理由，按第 8 节或适用程序处理 |

## 2. 非自愿性性影像

禁止以本服务制作、传输或散布未经同意的性影像。接获足以定位内容的可信通知时，运营者应迅速限制接取或移除，降低再次散布的危害。

1. 依实际适用法律判断移除、证据保存与通报义务，不以单一法域规则推定全球相同。
2. 仅在适用法律明确要求时，按其适用对象、起算点与范围保存至少 180 日；其他情形以合法且必要的最短期间保存。证据应隔离，限获授权且有必要的人员接触，期满且无其他合法保存事由时清除。
3. 向主管或执法机关提供数据，须具法律依据、核实对象并限于必要范围。紧急移除不剥夺事后申诉；法律禁止揭露或有妨害调查风险时，理由通知得依法限制或延后。

## 3. 垃圾邮件与滥用行为

不得从事下列行为：

1. 发送未经请求的大量邮件、向未同意的收件人行销，或进行信箱暖机与位址验证轰炸。除本政策外，仍须遵守依法适用的寄件地、收件地及其他反垃圾邮件规范；行销遭拒绝时应停止。
2. 未经授权批次注册，绕过 Turnstile、注册密钥或配额限制。
3. 建立滥发转发跳板、短期滥用账号池，或反覆注册以规避处置。

## 4. 攻击与干扰

可在您控制且与真实服务隔离的部署，以合成或经评估无法合理重新识别个人的匿名数据学习、调试及安全测试，并确保第三方不受影响。仅替换姓名、遮盖地址或散列标识，不当然达到匿名标准；评估范围见[隐私政策](/mail/privacy-policy/)第 4.5 节。测试不授权取得真实邮件、个人资料或他人凭证。

1. 对公开托管实例、真实使用者系统或第三方系统进行扫描、压力测试、社交工程、暴力破解或访问测试前，须取得该系统负责人的明确授权，遵守范围、时间与停止条件；公开可访问不等于授权。
2. 不得故意耗尽 AI、附件、API 等共用资源，或干扰他人使用；获授权的容量测试应遵守事先约定的限制。
3. 善意批评、漏洞回报、隐私申诉、主管机关检举及依法维权不属滥用。禁止威胁、定向骚扰或以公开私人数据造成危害。
4. 第三方条款仅在实际选用服务及相关契约关系范围内适用，不转嫁运营者本应承担的义务。

## 5. 资源使用之一般义务

1. 请遵守实例公布的存储与发送配额；变更依服务条款通知。
2. 不得出租、转售账号或将凭证交予未授权者。合法整合应使用受限授权并妥善保管密钥。
3. 选用 BYOS 或外部数据库前，应确认访问权限及数据处理条件；使用者与运营者各依实际角色履行义务，使用者选择服务不免除运营者的数据保护与国际传输责任。

## 6. 执行措施

处置依违规性质、可信程度、危害与重复情形采比例原则。儿少侵害、非自愿性影像或进行中攻击可先隔离或停用，无须逐级等待；之后仍应复核。

![警告、限流、隔离、停用与终止的处置层级及申诉路径](/images/mail/aup-ladder.svg)

*图：处置层级依情况选择；紧急保护与事后申诉并行，删除及证据保存依适用法律与技术限制办理。*

| 级别 | 处置 | 适用情形 |
| --- | --- | --- |
| 1 | 警告 | 轻微、首次且可改善的违规 |
| 2 | 功能限流 | 限制发信量、API 频率或涉事功能 |
| 3 | 隔离 | 限制内容接取或投递，阻止危害扩散 |
| 4 | 暂停账号 | 暂停访问，依法保留必要数据待复核 |
| 5 | 终止与删除 | 重大或反覆违规；依隐私政策处理删除、取回及合法保存 |

配额、调度清理与备份限制见[数据处理与安全维护](/mail/data-security/)及[隐私政策](/mail/privacy-policy/)。账号停用不等同所有副本立即清除，删除亦不能保证所有系统中的数据均不可恢复。

法定内容通报依适用法律办理，仅提供必要数据予有权接收者，不自动向所有第三方、上游服务商或检举人提供内容。使用者仅就依法可归责的行为负责，没有概括赔偿运营者或开发者全部费用、罚款或第三方索赔的义务。

## 7. 申诉与检举

1. 认为处置有误者，可经 `admin@epocanvas.com` 或服务条款第 13 节管道申诉；无法登录仍可联络。一般情形应在重大处置前提供理由与说明机会，并于合理期间复核答复。
2. 检举请提供必要的内容位置、时间与理由，避免重新散布受害影像、密码或无关个资。运营者按可信程度及危害分流处理；隐私请求的法定期限另依隐私政策。
3. 紧急措施得先执行再通知，但不取消事后申诉或向法院、主管机关求助的权利。复核发现错误时，应在合法且技术可行范围更正限制与结果；不得承诺已删除数据必可恢复。

## 8. 着作权与智慧财产权之通知与反通知

权利人可提供权利及侵害的具体说明、足以定位内容的信息、联络方式与依法必要的声明。运营者应核实通知、授权及适用的例外或限制，再决定限制接取、移除或要求补充数据；不因单方主张即认定侵权。

受影响者可提出反通知及合法使用理由。通知、反通知或身分数据仅在适用程序要求且具法律依据的必要范围转交，并依法告知，不自动完整转送给检举人。反覆侵权或故意虚假通知依事实、比例原则及法律处理；内部程序不取代法定救济。
