*图：收件箱。列表直接呈现验证码徽标（绿框）与官方邮件认证标记（蓝底勾选），文件夹与标签计数即时同步。*

<details>
<summary>图解：收件箱全景——四个最先用到的入口</summary>

这张收件箱全景图的四个标注分区，对应日常使用频率最高的四个入口：写一封新信、翻重要邮件、查延后事项与核对已寄出。

1. **写信（侧栏顶部主按钮）**：全局唯一的新建邮件入口，点击弹出写信弹层（非独立路由）；移动端为右下悬浮按钮，亦支持 `?composeTo=<地址>` 深链预填收件人。任何视图下都可一键开始写信。
2. **星标邮件（侧栏文件夹）**：所有加星邮件跨文件夹聚合于此：在列表行点击星形图标即入此视图，用于收藏需要长期保留或快速再访的邮件；侧栏计数实时反映数量。
3. **稍后处理（侧栏文件夹）**：延后跟进的暂存区，分「紧急」与「等待」两档：在详情页选「延后」并指定时间，到期自动回到收件箱顶部，重要事项不再沉底。
4. **已发送（侧栏文件夹）**：本帐号发出的全部邮件存底，可在此核对哪些信已实际寄出；出站量受帐号角色的每日发信配额约束，站内信直投、站外经投递通道。

</details>

## 1. 收件箱与整理

| 能力 | 说明 |
| --- | --- |
| 邮件视图 | 主要邮件、星标邮件、稍后处理、已发送、草稿箱、全部邮件、垃圾邮件、回收站八个视图，计数即时刷新 |
| 阅读版式 | 三栏分屏、会话线程视图、内联回复与表情回应，邮件详情支持原始信头查看 |
| 整理动作 | 星标、延后处理（自选时间）、举报垃圾／非垃圾、移入回收站、彻底删除 |
| 验证码徽标 | 经 Workers AI 提取之验证码直接显示于列表与详情（见第 5 节） |
| 官方邮件标识 | announcement@epocanvas.com 等官方发件人之邮件带认证标记与说明横幅（见[防篡改与官方规范](/mail/tamper-proof/)） |

## 2. 撰写与发送

![EpoCanvas Mail 写信窗口：发件人锁定当前信箱，收件人支持联系人选择，主题栏下方为富文本工具栏（段落、字号、加粗、列表、引用、分隔线、链接、图片、表格、表情、翻译与源码模式），底部为附件与发送按钮](/images/mail/ui/compose-guide.png)

*图：写信。富文本编辑器提供 17 项排版工具；站内收件人直接投递，站外经投递通道发送。*

<details>
<summary>图解：写信弹层——一封信从排版到发出的四个落点</summary>

写信弹层的四个标注分区，覆盖一封信从排版到发出的完整路径：工具栏决定样式，收件人与主题决定去向，发送按钮落地投递。

1. **富文本工具栏（正文上方）**：17 项排版能力：段落与字号、加粗/斜体/下划线/删除线、颜色、对齐、有序无序列表、引用、分隔线、链接、图片、表格、表情、翻译与源码模式，即写即见。
2. **收件人输入行**：支持从联系人选择或直接输入地址；站内信箱直投（不产生外部传输），站外地址经营运者配置的通道（Resend/Mailjet 等）投递。
3. **主题行**：收件人首先看到的内容，与正文首行摘要一同显示在列表与推送通知里；写明事由便于日后用 `subject:` 算子检索。
4. **发送按钮（右下）**：点击即投递：站内直投秒达，站外经投递通道发送；发送后可在「已发送」视图核对。附件能力依角色开启，单附件上限依实例设置（出厂 25 MB）。

</details>

- **富文本编辑**：段落、字号、加粗斜体下划线删除线、颜色、对齐、有序无序列表、引用、分隔线、链接、图片、表格、表情、翻译与源码模式；
- **附件**：附件收发能力依帐号角色开启；单附件大小上限依实例设置（缺省 25 MB，仅约束使用运营者公共存储之用户，自备存储者不受限）；存储配额依角色设定；
- **发送范围**：站内信箱直投（不产生外部传输）；寄往站外之邮件经营运者配置之通道（Resend／Mailjet 等）投递，涉及之第三方见[第三方处理者清单](/mail/sub-processors/)；
- **发送管理**：已发送视图可查；出站量受帐号角色之每日发信配额约束（见第 6 节）。

## 3. 搜索语法

![EpoCanvas Mail 搜索栏输入 from:github 后的结果视图：列表仅显示命中之 GitHub 通知邮件，侧栏计数保持同步](/images/mail/ui/search-guide.png)

*图：搜索。字段算子可与自由关键词组合，命中列表即时刷新。*

<details>
<summary>图解：检索——一次搜索的两个关键位置</summary>

搜索的两个标注分区演示一次完整检索：在检索框输入算子或关键词，命中列表即时过滤并高亮关键词。

1. **顶栏检索框**：邮件页搜邮件、设置页搜配置项；支持 `from:`/`to:`/`subject:`/`body:` 等十个字段算子与 `is:`/`global:` 旗标，多条件以空格相连为「且」关系，Tab 可补全算子。
2. **命中列表**：仅显示满足全部条件的邮件，命中词以浏览器原生高亮标出（`hl:off` 可关闭）；点击行进入详情，摘录窗自动平移到命中处保留上下文。

</details>

| 算子 | 示例 | 说明 |
| --- | --- | --- |
| `from:` | `from:github` | 按发件人过滤 |
| `to:` | `to:boss` | 按收件人过滤 |
| `subject:` | `subject:验证码` | 按主题过滤 |
| `body:` / `subject_or_body:` | `body:发票` | 按正文／主题或正文过滤 |
| `larger:` / `smaller:` | `larger:10M` | 按邮件体积过滤 |
| `before:` / `after:` | `after:2026-10-01` | 按日期过滤 |
| `label:` | `label:工作` | 按标签过滤 |
| `global:` | `global:项目` | 跨信箱全站检索 |
| `is:` | `is:sent`、`is:spam`、`is:trash` | 按状态过滤 |

搜索命中基于 CSS Highlights API 高亮；全站检索与页内查找两级并存。全部字段算子、旗标与规则条件的完整参考见[搜索与规则参考](/mail/search/)。

## 4. 标签与分类规则引擎

- 默认预置四个标签：**社群**（按常见公共邮箱域自动归类）、**订阅**、**推销**、**工作**；标签颜色与图标可自定义；
- 规则条件可组合（发件人地址包含、主题关键词、系统设置等），支持例外与优先级；收件时自动打标，亦可靠手动；
- 全局治理工具：发件人黑名单、主题与内容关键词黑名单、白名单模式、空发件人名拦截、非收件人拦截、可执行附件拦截与硬拦截拒收计数；
- 标签统计（总数、未读）于侧栏即时呈现，分类结果可在分析页复核。

## 5. 验证码自动提取

![EpoCanvas Mail 邮件详情：Cloudflare 验证码邮件中的 6 位验证码以大字号呈现，列表与详情均带绿色验证码徽标](/images/mail/ui/ui-detail-verification.png)

*图：验证码提取。此为唯一非经手动触发之 AI 处理，仅将主题与正文前 6,000 字符送至 Workers AI；处理范围与退出方式见[隐私政策](/mail/privacy-policy/)第 6 节。*

<details>
<summary>图解：验证码提取在详情页的呈现</summary>

邮件详情中的验证码提取效果：6 位验证码以大字号呈现，列表与详情均带绿色徽标。

- **验证码大字区**：Workers AI 从主题与正文前 6,000 字符中提取的验证码，直接以大字号呈现便于抄写。
- **绿色徽标**：列表行与详情页同步出现的绿色标记，含义是「此邮件含已提取的验证码」，让您不必逐封打开即可从列表直接辨认。徽标只在提取成功时出现；未命中或已关闭验证码提取时不显示，因此它的缺失不代表安全，只代表没有可抄的码。
- **边界**：此为唯一非经手动触发之 AI 处理，可于常规设置关闭；处理范围与退出方式见隐私政策第 6 节。

</details>

## 6. 垃圾邮件治理

- 隔离与保存：垃圾邮件隔离保存 7 日后自动转入回收站；举报垃圾／非垃圾经用户确认后自动维护个人信任名单；
- 出站约束：每日发信配额按角色设定（普通用户 5 封、LV.0 8 封、LV.1 10 封、管理员 100 封，站长不设上限），计数每日重置；配额滥用之处置见[可接受使用政策](/mail/acceptable-use/)第 6 节；
- 收费与营销内容之传输责任归发件人；未经请求之大量商业邮件为禁止行为（见[可接受使用政策](/mail/acceptable-use/)第 3 节）。

## 7. 转发与推送

- **个人转发**：可将信箱邮件自动转发至其他地址，支持抄送；
- **全局转发**：管理员可配置系统级转发规则，受邮件模式约束（加密模式下关闭）；
- **Telegram 推送**：绑定机器人后按配置推送主题、发件人、正文与验证码，附 7 日有效之站内阅读链接；推送字段可逐项隐藏。

## 8. AI 能力

| 能力 | 触发方式 | 说明 |
| --- | --- | --- |
| 验证码提取 | 新邮件自动（可关闭） | Workers AI 边缘推论，见第 5 节 |
| 全文翻译 | 手动点击 | 保留原邮件排版的多语言翻译，多片并发；模型端点与备援通道见[隐私政策](/mail/privacy-policy/)第 6 节 |
| 图片文字识别 | 手动上传 | OCR 生成字幕，纯装饰图自动略过 |
| AI Hub | 管理员配置 | 接入 OpenAI 兼容等多模型端点，0-Token 测速，模型按角色授权 |

运营者不以邮件内容训练任何模型；经同意之 AI 处理可随时撤回（见[隐私政策](/mail/privacy-policy/)第 6 节）。

## 9. 开放平台与数据自主

- **OAuth 2.0 / OIDC 认证中心**：管理员可注册第三方应用，授权范围限 openid / profile / email，访问令牌 2 小时有效；当事人可于「第三方应用」页实时查看并随时撤销授权；
- **接入指南**：管理端注册应用、端点与集成代码详见[开放平台与 API 接入](/mail/api/)；
- **数据导出**：设置页一键导出 JSON 格式完整副本（含个人资料与未删除邮件全文），单封邮件可下载为 .eml；

## 10. 界面与移动端

- 六种界面语言（简体中文、繁体中文、English、Français、Español、Nederlands），前后端字典六语言完全对称；
- 明暗双主题、300+ 离线矢量图标（零外部请求）、响应式布局与 PWA 安装；另提供 Android 移动应用（epomail）。

![EpoCanvas Mail 英文界面收件箱：完整的多语言支持，侧栏显示 Compose、Main、Starred、Snoozed、Sent、Drafts、All Mail、Spam、Trash 与 Social、Subscriptions、Promotions、Work 标签](/images/mail/ui/ui-inbox-en.png)

*图：English 界面。界面语言可于设置中切换，词典六语言对称由静态审计脚本保障。*

<details>
<summary>图解：英文界面收件箱与中文版的同构关系</summary>

English 界面的收件箱：与中文版完全同构，词典六语言对称由静态审计脚本保障。

- **侧栏**：Compose、Starred、Snoozed、Sent 等视图与 Social/Subscriptions/Promotions/Work 标签同构对应。
- **列表**：发件人、主题、摘要与验证码徽标的位置、字号与配色与中文版逐项一致——本地化只替换词条，不改版式，因此截图与操作指引可跨语言复用。日期、数字与计数同样按界面语言格式化。
- **切换方式**：界面语言的切换点：常规设置的「语言」区六选一（简体中文、繁體中文、English、Español、Français、Nederlands），改后即刻生效、无需重登。投递与显示分开——系统通知与欢迎邮件按每位收件人自己的语言设置生成，不随发信人的界面语言走。

</details>

![EpoCanvas Mail 移动端收件箱：375 宽度下的响应式布局，侧栏收合为抽屉，列表保持完整可读](/images/mail/ui/ui-inbox-mobile.png)

*图：移动端。同一实例适配桌面与移动浏览器，亦可经 PWA 或 Android 应用安装使用。*

<details>
<summary>图解：移动端收件箱的响应式取舍</summary>

375 宽度下的移动端收件箱：侧栏收合为抽屉，列表保持完整可读。

- **抽屉式侧栏**：视窗宽度低于 1025 像素时，左栏自动收合为抽屉：点汉堡按钮以遮罩形式唤出，选中任一视图后自动收起，不遮挡阅读区。桌面端与移动端共用同一套侧栏结构，因此计数与标签在两种形态下完全一致。
- **悬浮写信按钮**：桌面端「写信」按钮在移动端的对应物，固定于右下角、随滚动常驻，点开即唤出全屏写信。它只在帐号具备发信权限时出现；参观者或已被关闭发信权限的分组看不到此按钮，也就无从进入写信流程。
- **列表**：与桌面端共用同一份虚拟滚动列表：长列表只渲染视口内的行，首屏打开速度不随邮件总量增长。触控目标按移动端可达性放大，但信息密度与列构成与桌面一致，因此移动端截图同样可用于核对字段。

</details>
