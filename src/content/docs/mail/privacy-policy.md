# 隐私政策

**生效日期：2026 年 9 月 29 日｜版本：5.0**

本政策说明 EpoCanvas Mail 服务（下称「本服务」）如何收集、处理及传输您的个人资料，以及运营者就资料保护所遵循之标准与承诺。您于注册或使用本服务前，应先阅读本政策；不同意本政策之任一内容者，请勿使用本服务。

本文件所述之技术事实，以本服务开源代码之实际实现为准。本站法律文档以繁体中文（台湾）版本为正式版本，其他语言版本仅供参考；内容如有歧异，以繁体中文版本为准。您所用实例之适用法律，依其运营者所在地确定（见第 12 节）。

## 1. 适用范围

本政策适用于您以任何方式使用本服务所生之个人资料，包括：

1. 造访本服务网站（`mail.epocanvas.com` 或自行部署实例之网域）；
2. 使用移动应用（epomail）；
3. 通过开放 API 接入本服务。

本政策不适用于本服务链接或嵌入之第三方网站与服务；该等第三方各有其隐私政策，由其自行负责。

自行部署 EpoCanvas Mail 之运营者，自部署之时点起即为其用户之数据控制者，应自行向其用户履行其所在地适用法律下之告知义务；本政策可作为其告知之基础文本。

## 3. 收集之告知事项

本服务于向您收集个人资料时，明确告知下列事项：

| 告知事项 | 本服务之告知内容 |
| --- | --- |
| 一、收集者名称 | 运营者（见第 2 节；自行部署实例为其部署者） |
| 二、收集目的 | 提供电子邮件通信服务；帐号与信息安全管理；滥用与诈欺防制；系统公告之传送；履行法定义务（详第 5 节处理活动对应表） |
| 三、个人资料之类别 | 识别类（电子邮件地址、用户名）；帐号安全类（密码哈希值、两步验证凭证）；界面偏好类（语言、明暗模式）；网络活动类（邮件记录、标签、星标、已读状态）；其他得以直接或间接方式识别个人者（登录 IP、自 User-Agent 解析之操作系统、浏览器与设备类型）——详第 4 节 |
| 四、利用之期间、地区、对象及方式 | 期间：帐号存续期间内，部分项目有固定保存期限（见[数据处理与安全维护](/mail/data-security/)之处理矩阵）；地区：本服务建置于 Cloudflare 全球边缘网络，资料可能于全球任一边缘节点处理（见第 7 节）；对象：运营者及其受托处理者、经您授权之第三方应用、依法律要求之有权机关（见第 7 节）；方式：以自动化方式为存储、传输、检索、推送与边缘推论，除法令或司法程序要求外，不为人工资核 |
| 五、当事人得行使之权利及方式 | 查询、阅览、制给复制本、补充更正、停止处理及删除等权利，行使方式见第 9 节 |
| 六、不提供个人资料所致之影响 | 电子邮件地址与密码为注册及登录之必要项目，不提供者无法建立帐号；其余字段（昵称、头像、个人简介等）均为选填，不提供不影响本服务之使用 |

您以 Linux DO 帐号登录时，本服务自该身份源取得您的用户标识符、昵称、头像等识别资料，属收集非由您直接提供之个人资料；其来源为您登录所使用之 Linux DO 帐号，利用之期间、地区、对象及方式与您得行使之权利，同前表第二款至第五款之告知。本服务无其他收集非由您提供之个人资料之情形。

## 4. 收集之个人资料

### 4.1 您主动提供者

- **电子邮件地址与密码**：注册之必要项目。密码仅以 PBKDF2-HMAC-SHA256 哈希值存储（100,000 次迭代，每用户独立随机盐），无法自哈希值还原原密码。
- **两步验证凭证（选填）**：TOTP 密钥以 AES-256-GCM 加密存储；备用恢复码仅存 SHA-256 哈希值；通行密钥（Passkey）仅存公钥，私钥留存于您之设备。
- **个人资料（选填）**：昵称、头像、个人简介；头像上传至运营者配置之图片存储服务。

### 4.2 您之通信内容

您收发之电子邮件（含发件人与收件人、主题、正文、时间戳等元数据）与附件，以及您施加的标签、星标、已读状态与延后提醒，存储于实例之数据库（Cloudflare D1）与对象存储（Cloudflare R2 或运营者配置之 S3 兼容存储）。邮件内容之所有权与责任归属您本人；运营者不出售邮件内容、不为广告目的利用之，亦不接入任何第三方统计追踪。

### 4.3 自动记录之技术资料

- **登录与安全日志**：注册与登录时之 IP 地址、浏览器 User-Agent 及解析所得之操作系统、浏览器与设备类型，用于信息安全审计与异常登录识别。
- **会话令牌**：登录后签发之 JWT（有效期 30 日）存储于您浏览器之 localStorage。本服务不使用 Cookie，无跨站追踪。
- **边缘网络日志**：Cloudflare 依其自身政策处理请求元数据。

### 4.4 本服务不收集之项目

本服务无广告追踪 SDK、无行为画像、无跨站 Cookie、无 Google Analytics 或任何第三方统计；亦不读取您设备之通讯录、相册、位置或其他应用程序之资料。

### 4.5 高敏感个人资料

病历、医疗、基因、性生活、健康检查及犯罪前科等属高敏感类别之个人资料，其收集与处理于多数法域受严格限制。本服务之帐号与系统字段不收集该等资料；您经由电子邮件自行传输之内容可能包含之，运营者仅于提供通信服务之必要范围内被动存储与传输，不为内容分析建档。您应自行审慎决定是否于邮件中传输高敏感资料。

## 5. 收集、处理与利用之处理性质

本服务各项处理活动之性质如下：

| 处理活动 | 特定目的 | 处理性质 |
| --- | --- | --- |
| 帐号注册、登录、信箱管理 | 提供电子邮件服务 | 契约之必要处理，并采适当之安全措施 |
| 登录日志、失败锁定、两步验证 | 信息安全维护 | 契约之必要处理，并遵循比例原则 |
| 验证码自动提取（运营者可选开启） | 提升服务便利性 | 经您同意；您得要求关闭，或改用未开启此功能之实例 |
| 邮件翻译、图片文字识别（您主动触发） | 内容协助 | 经您同意；未触发即不发生传输 |
| 公开个人页面（默认关闭） | 社交展示 | 您自行公开之资料 |
| 系统公告、官方欢迎邮件 | 契约履行与用户沟通 | 契约之必要处理 |

您的个人资料仅用于收集之目的及与其密切相关之范围。本服务不为自动化决策、用户画像或任何与提供服务无关之商业目的利用您的个人资料。运营者以个人资料营销时，您表示拒绝接受营销，运营者应即停止利用；首次营销时并应提供您表示拒绝之方式。

## 6. AI 处理之特别告知

本服务涉及三种 AI 处理，其触发条件与资料范围如下：

1. **验证码自动提取**（运营者可选开启）：新邮件送达时，系统将主题与正文前 6,000 字符传送至 Cloudflare Workers AI 于边缘节点推论，以提取邮件中之验证码。此为唯一非经您手动触发之 AI 处理；不欲此处理者，得要求运营者关闭该功能，或改用未开启此功能之实例。
2. **邮件翻译**（您主动触发）：您点击「翻译」后，邮件文本经分片传送至实例配置之大型模型端点（默认兼容 OpenAI 协议），并以 MyMemory、Google 翻译公共接口备援。您未触发翻译时，邮件内容不会传输至任何 AI 服务。官方系统邮件（欢迎邮件、全域公告）未被管理员修改时，其翻译直接采用预置之对应语言官方模板并于客户端本地渲染，不向任何 AI 服务传输邮件内容；已被修改者方按前述流程经 AI 翻译。
3. **图片文字识别**（您主动触发）：您上传含文字之图片时方传送至前述 AI 服务；纯装饰图、Logo 与图标自动略过。

运营者不以邮件内容训练任何模型，亦不向 AI 服务传送翻译或识别所需文本以外之身份信息。上开经同意之处理，您得随时以第 9 节所列方式撤回同意；撤回不影响撤回前已为之处理。

## 7. 与第三方之共享及国际传输

本服务依最小必要原则与第三方共享个人资料，全部情形如下（完整清单与保障机制见[第三方处理者清单](/mail/sub-processors/)）：

1. **受托处理**：Cloudflare（运算、存储、邮件路由、人机验证、边缘 AI）、Resend 或 Mailjet（外寄投递，仅寄往站外之邮件涉及完整邮件）；
2. **经您授权**：Telegram 通知（仅推送您配置之字段）、OAuth 第三方应用（范围限 openid / profile / email，得随时撤销）、Linux DO 登录；
3. **您主动触发**：AI 翻译与图片文字识别服务（见第 6 节）；
4. **法律要求**：仅于依法定程序受有权机关要求时提供，并于法律允许范围内通知您。

本服务建置于 Cloudflare 全球边缘网络，您的个人资料可能于运营者所在国境外之节点处理。运营者遵循适用法律对国际传输之要求及主管机关依法所为之限制，并依赖 Cloudflare 之资料保护措施（SOC 2 Type II、ISO/IEC 27001 认证及欧盟标准合同条款机制）保障传输安全。自行部署之运营者应自行评估并确保其国际传输行为符合其所在地之法律要求。

## 8. 资料保存期限与销毁

| 资料类别 | 保存策略 |
| --- | --- |
| 收件箱邮件 | 保存至您删除，或触发配额清理 |
| 垃圾邮件 | 隔离 7 日后转入回收站 |
| 回收站邮件 | 自收受之日起 7 日，由系统例行任务实体删除（含附件与索引） |
| 信箱用量逾 90% | 系统对已标记删除之邮件径行实体删除以释放空间 |
| 帐号注销 | 会话即时失效；邮件进入软删除状态，至管理员执行实体删除为止 |
| 实体删除 | 帐号资料、信箱、邮件、附件、OAuth 授权与会话一并移除，不可复原 |
| 实例停运 | 运营者应预先通知并提供资料导出期间；停运后资料随 Cloudflare 资源销毁 |

实体删除后资料不可复原。删除前，您得通过「设置 → 数据导出」取得 JSON 格式之完整副本（含个人资料与未删除邮件全文）。技术措施之完整说明见[数据处理与安全维护](/mail/data-security/)。

## 9. 当事人权利与行使方式

您就您的个人资料享有下列权利：

1. 查询或请求阅览；
2. 请求制给复制本（本服务以「数据导出」功能落实）；
3. 请求补充或更正；
4. 请求停止收集、处理或利用；
5. 请求删除。

行使方式：界面自助功能（导出、注销、撤销 OAuth 授权、登出）即时生效；需人工处理之请求，运营者于受理后 30 日内答复并处理。联络窗口：`privacy@epocanvas.com`。

您认为本服务之处理致您权利受损害者，得向运营者请求救济；运营者就其处理之合法性负说明与举证责任。您并得向运营者所在地之主管机关申诉或寻求法律救济（适用法律见第 12 节）。

## 10. 安全维护措施

运营者建立并持续改善下列安全维护措施，防止个人资料被窃取、窜改、毁损、灭失或泄漏，包括：全站 HTTPS/TLS 传输加密、密码 PBKDF2 加盐哈希、TOTP 密钥 AES-256-GCM 静态加密、登录失败锁定（连续 5 次失败锁定 12 小时）、会话上限 10 并可即时撤销、基于密码学哈希之邮件路由（防越权访问与资源枚举）、附件下载防御性标头与 MIME 允许清单。完整清单见[数据处理与安全维护](/mail/data-security/)。

:::caution[加密之范围与限制]
本服务「全部／隐私／加密」三种邮件模式之加密，系服务器端静态加密：密钥由实例服务器之环境变量与用户识别衍生。此机制防护数据库文件遭窃取或快照泄漏之风险，并非端对端加密；掌握服务器与密钥之运营者在技术上具备解密能力。管理员之可及范围依模式而定：全部邮件模式下管理员得读取全部邮件；隐私模式下仅限垃圾、已删除与无主邮件；加密模式下管理界面不回传用户邮件。需要运营者亦无法读取之保密强度者，应自行以 GPG 等端对端加密工具先加密邮件正文再行发送。
:::

## 11. 儿童及少年之保护

本服务不面向未满 14 岁之儿童，亦不有意收集儿童之个人资料。监护人认为儿童提供个人资料者，得联络运营者请求删除，经核实后即时处理。任何人均不得利用本服务对儿童及少年散布有害其身心健康之内容；相关使用限制见[可接受使用政策](/mail/acceptable-use/)。自行部署之运营者应依其辖区法律自行订定年龄门槛。

开源代码项目本身不提供服务，亦不对任何实例之合规负责；法律义务由营运该服务之主体承担。各实例适用之法律以其运营者所在地为准：托管实例 `mail.epocanvas.com` 由运营团队于台湾营运，其个人资料处理适用台湾现行法律（含《个人资料保护法》），运营者接受该法主管机关依法实施之检查与监督，本政策与[数据处理与安全维护](/mail/data-security/)即作为受检之基础文档。自行部署实例之适用法律为其部署者所在地之法律，告知、安全维护与受监督等义务由部署者自行履行。
