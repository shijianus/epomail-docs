## 4. 存储与访问的实际范围

### 4.1 账号与安全数据

新写入的密码验证采用加盐 PBKDF2-HMAC-SHA256，默认 210,000 次迭代且可配置；历史 SHA-256 或较低参数记录可在验证时升级，不能保证所有存量已完成迁移。TOTP 密钥加密保存；恢复码有验证用哈希，另保存以密钥加密、可于重新验证后显示的原码副本；通行密钥保存公开凭证数据。这些措施降低风险，并非保证密码永不可被猜解。TOTP 设置流程可在 KV 暂存未加密设置密钥 600 秒；历史密码升级遇到多因素验证时，可在待完成的 KV 流程暂存输入密码 300 秒并可能续期，故不能声称任何路径都不保存明文凭证。个人字段、登录来源、操作记录与权限设置亦可能存于实例数据库或 KV。

### 4.2 邮件与附件

邮件数据主要由 Cloudflare D1 与配置的对象存储处理；附件可依用户或运营者配置存于 S3 兼容存储、R2，或在未配置时使用 KV。已核对的入站路径读取并解析原始 MIME，未另持久保存完整原始邮件；下载 .eml 并不证明保留了原始文件。外部备份、数据库与自行修改的保存行为须另行确认，实际数据位置不能仅由源代码推定。

服务不提供端到端加密。「加密」与「隐私」模式依程序及设置对部分正文、主题作服务器端静态加密；附件与路由元数据不自动纳入该保护，掌握服务器及密钥者在技术上可能解密。

### 4.3 浏览器、日志与外部请求

浏览器可在 localStorage 保存登录令牌、语言与界面偏好；登出与服务器撤销、凭证有效期是不同机制。在共用设备使用后应登出并清除不需保留的本地数据。

登录安全机制亦处理 IP 衍生的国家／城市、网络 ASN 及设备信息。已知环境清单最多保留最近 15 条并使用 180 日滑动 TTL，持续使用可能使期限续延；IP 多账号关联项目使用 7,200 秒 TTL。可信设备凭证可保存 60 日，前 30 日可能用于免除部分多因素验证。这些与账号字段或审计日志的保存并非同一周期。

Cookie 规则亦可能涵盖 localStorage 等终端存储或读取。适用 ePrivacy 终端访问规范时，仅为传送通信或提供您明确要求的服务所严格必要的访问，才可依相应例外免事先同意；登录或安全标签本身不表示符合例外。其他终端访问须在启动前清楚告知并取得有效同意，同意前不得启动。拒绝不应使无关的基本功能失效，撤回须与给予同意同样容易，撤回后停止相应访问。不能以未使用 Cookie 免除上述要求。

字体、Turnstile、外部图片及其他配置的资源可能收到 IP、User-Agent、时间及请求数据；读取远程邮件图片也可能向发件方暴露打开情况。没有广告或分析 SDK 不等于没有第三方网络请求。完整数据流见[第三方处理者清单](/mail/sub-processors/)。

### 4.4 管理与调试访问

管理界面依邮件模式、角色及权限限制可见范围；这不是运营者在技术上绝对不能接触数据的保证。人工访问限处理具体支持、安全事故、滥用举报、合法请求或其他有依据且必要的事项，采用最小权限并保留适当记录。禁止以学习、测试或好奇为由随意阅读真实邮件，亦不得将其贴入公开 Issue 或调试服务。

公开个人页面默认关闭；开启后，匿名访客可取得主信箱、个人字段、角色、加入时间及邮件活动／来源统计。部分「隐藏统计」设置仅控制画面，不能当作 API 访问限制；账号软删除也未证实会关闭该公开路径。需要撤回公开时应同时关闭页面并请运营者核对匿名访问，在修正前勿用该功能公开不必要的真实数据。

### 4.5 敏感与第三人的数据

邮件可能包含健康、种族、宗教、政治意见、工会、基因、生物识别、性生活或性取向等特殊类别数据；犯罪记录另受特别限制。仅称「被动存储」或取得账号用户的一般同意，不会自动满足相关额外法律条件。测试应使用合成或已依法去标识化的内容；目前不以承接受监管的敏感数据处理为服务目的，未确认合法依据及保障前，不应上传此类真实数据。

## 5. 处理目的与法律依据

GDPR 适用时，运营者须为每一目的确定适当依据；其他适用法律的额外条件仍须遵守。

| 处理活动 | 目的 | GDPR 适用时的依据与限制 |
| --- | --- | --- |
| 账号、投递、存储与必要服务通知 | 履行您要求的信箱服务 | 对您为履行契约所必要；通信中非缔约人的数据另依经衡量的合法利益或其他适当依据处理 |
| 登录安全、限流与具体滥用防制 | 保护用户、通信及基础设施 | 必要时依经必要性及利益衡量的合法利益；仅限确属适用的法定义务时采用法定义务依据 |
| 翻译、OCR、选用通知或公开字段 | 提供您主动选用的附加功能 | 依功能及接收者另作清楚告知；须同意时取得自由、特定、知情且明确的同意，能撤回 |
| 自动验证码提取 | 协助识别验证码 | 不因方便或运营者开关自动成为契约必要；启用前须确认有效依据、必要保障与所需的个别选择 |
| 依法回应权利请求或有权机关 | 履行实际适用的法律要求 | 明确法定义务；境外命令仍须评估适用性、通信保密及国际传输规则 |
| 特定争议的最低必要记录 | 提出、行使或抗辩法律请求 | 经衡量的合法利益及适用的法定保存，限制范围与期间 |

如以合法利益为依据，利益为提供所要求的通信、维护安全或抗辩具体请求，运营者应留存必要性及利益衡量记录，并容许第 9 节所述异议。不得将所有功能包成「履行契约必要」。服务不以数据出售、广告投放或商业模型训练为处理目的。

自动分类、限流或风险信号可能影响邮件处理与账号功能；本政策不授权仅以自动处理作出对您具有法律或类似重大影响的决定。若实际部署涉及此类决定，须先确认合法条件、说明逻辑与影响并提供适当人工介入及申诉。

## 6. AI 与选用内容处理

已核对的程序包含收件时的验证码提取，以及您操作后的翻译、图片文字识别。实际数据可能包括主题、正文片段、图片及其中的身份或敏感内容，不能保证文本中没有个人资料。OpenAI 兼容协议只描述接口，不表示接收者必然为 OpenAI。

验证码提取的全站开关在本次核对版本默认关闭；启用后，新信抵达时可自动向 Workers AI 传送完整主题及最多 6,000 个 JavaScript 字符的正文文本，主题不计入此上限。这并非每次均由您按按钮触发，亦未见逐用户退出判断。全站开关不等同每位用户的有效同意。部署者在缺少有效依据、所需选择或可履行的撤回机制时，应停用相应外传；请求用户搬到另一实例，不能代替自由撤回或证明先前已取得同意。

文字翻译可能使用配置的模型或 Workers AI，部分流程会向 MyMemory 或 Google 翻译公共接口传送文本片段，包含经 URL 查询参数传送的情形；缺漏片段的备援不仅发生于整体端点失效时。OCR 可将内嵌图片字节传至 Workers AI，或将远程图片 URL 传至配置的外部视觉端点；识别出的文字再进入翻译流程。客户端 OCR 默认关闭，但省略参数的 API 调用可能采用不同默认值，不能以界面开关推论所有路径都没有图片处理。

对具有个人或机密数据的邮件，未确定接收者、受托契约、保存与跨境保障前，应停用该路径。一次按下翻译，不是对未披露接收者或后续模型训练的概括同意；某些图片可能在翻译工作流程中被提取，不仅限于您另外上传的图片。

运营者不将邮件作为自行训练模型的数据集；第三方的保存、训练与再利用限制须以实际契约及配置确认，不凭本政策代其作保。AI 结果可能有误，验证码、翻译与识别输出应由您核对；本服务不以此提供具法律效果的专业判断。在适用范围内应清楚标示 AI 功能及输出，依实际角色与用途履行必要透明告知；一般翻译或识别不因使用 AI 就当然属高风险系统，亦不因此取得合规认证。

## 7. 接收者与国际传输

依实际配置，接收者包括 Cloudflare、外寄投递服务、您或运营者指定的存储与数据库、身份源、AI／翻译服务、通知平台、经授权应用及收件人的邮件服务商。各方是否为受托处理者或独立控制者依其实际用途及契约判断，不能全数列为仅按指示处理。

Cloudflare 全球网络或非欧盟供应者的使用不保证数据仅在欧洲经济区内处理。GDPR 限制的跨境传输，须先确认实际地区与合法机制，例如对应范围的充分性决定，或已有效订立的标准合同条款、传输影响评估及必要补充措施。SOC 2、ISO 认证、TLS 或服务商宣称提供 SCC，都不单独构成该次传输已合法的证明。例外或明示同意不应用作反复、结构性传输的通常替代方案。

可向第 14 节窗口索取与您数据相关的接收者、地区及保障摘要，并在依法可提供且经必要遮蔽后取得保障文件。对有权机关的请求，运营者核实权限与法律依据、限制披露范围，并于法律允许且不损及合法目的时通知受影响者。

## 8. 保存、停用与删除

| 数据类别 | 实际机制及保存标准 |
| --- | --- |
| 账号、个人设置与正常邮件 | 为提供服务而保存至删除、账号清理或合法必要性消失；停用不等同实体清除 |
| 垃圾邮件与回收站 | 每日处理以邮件 `create_time` 起算；垃圾保存默认 7 日后转回收站，回收站门槛固定 7 日，因此可在同轮符合实体删除条件；不是移入后再保证 7 日缓冲 |
| 过期系统邮件与配额清理 | 部分官方邮件在读取列表时依过期天数（默认 7 日）标记删除，再由计划任务处理；执行删除时用量已超过配额 90% 的邮件可直接实体删除 |
| 账号注销／停用 | 自助操作限制访问并改变数据状态；未证实有注销后 90 日自动清除所有数据的机制，删除请求须另行跟踪完成 |
| 安全、登录、审计及权利请求记录 | 仅保存特定目的所必要的期间；没有通用自动到期的项目，运营者须另订并落实最短必要保存与定期复核 |
| 附件、原始邮件、备份及外部副本 | 各存储与备份的删除须分别确认；不得将界面删除当作所有副本已同时清除，具体周期由实例补充告知 |
| 法定保存或具体争议 | 有实际法律依据时仅保留所需数据、限制其他使用并记录理由及期限，期满清除 |
| 计划性停运 | 在合理可行时先通知并提供数据取回期间，再终止资源及处理残留副本；突发中断可能限制取回能力 |

没有一项固定的 90 日宽限可排除法定「不再必要即删除」或第 9 节的请求期限。若备份只能按周期覆写，应隔离不再使用、告知周期，并于恢复时重新应用删除；未确认的备份周期不能描述为即时或彻底不可恢复。发件人、收件人或独立服务商已持有的副本，通常无法由本服务单方面删除；依法应通知接收者更正、删除或限制时仍须办理。

## 9. 当事人权利与处理期限

依适用法律及其条件，您可请求知情、查阅及副本、更正、删除、限制处理、反对基于合法利益的处理、撤回同意，以及在符合条件时取得机器可读数据或请求可携。撤回不影响撤回前合法的处理；反对直接营销时应停止该用途。您亦可就具有重大影响的自动决定请求适用的保障与人工介入。

GDPR 适用时，对于您提供且与您有关、以同意或履行契约为依据并以自动化方式处理的个人资料，您可要求以结构化、常用且机器可读格式取得，并不受阻碍地转移至另一控制者；技术上可行时亦可要求直接传送。此权利不得不利影响他人的权利与自由，亦不限制查阅或删除权。

自助导出是其中一个途径，导出文件不等于所有数据的完整副本：个人字段为选定子集，不包含附件文件、回收站邮件、完整路由字段、原始 MIME、所有别名及安全／管理审计记录。取得未包含且依法可请求的数据，可联络 `privacy@epocanvas.com`；运营者亦须保护通信对象及其他人的权利，必要时遮蔽而非一概拒绝。

:::note[对合法利益处理提出异议]
GDPR 适用时，您可随时基于个别情况，反对以合法利益为依据的处理，包括画像。除非运营者证明有优先于您利益、权利与自由的重大且正当事由，或为提出、行使或抗辩法律请求所必要，否则不得继续。反对直接营销无须提出个别理由，提出后须停止该用途。请联络 `privacy@epocanvas.com`；运营者最迟须于首次联络时，清楚、单独提示此权利。
:::

GDPR 适用时，应无不当迟延并于收到请求后一个月内回复。因复杂程度或请求数量而有必要时，可依法再延长最多两个月，但须在第一个月内说明延长及理由；不采取行动时亦应告知理由、申诉与司法救济途径。其他适用法律定有较短期限者，依其规定。

一般请求免费。仅在适用法律允许且能证明请求明显无根据或过度时，才可收合理费用或拒绝并说明。身份有合理疑义时仅要求必要的补充核验，不一律索取证件，也不以未注册或无法登录排除权利。

您可直接向有管辖权的数据保护机关申诉及寻求司法救济；GDPR 适用时，包括您惯常居所、工作地或涉嫌侵害地的主管机关。无须先取得运营者同意或先用完内部申诉。欧盟机关联络资料可见 [EDPB 成员清单](https://www.edpb.europa.eu/about-edpb/about-edpb/members_en)。

## 10. 安全与事故应变

运营者应依数据性质、风险、技术现状及合理实施成本采取适当的访问控制、凭证保护、加密、更新与事故处理措施；安全功能的存在不构成零风险或特定认证的保证。个人维护模式不要求本政策以外的 24 小时支持，但不延长法定通报期限。

事故须立即评估、控制并留存记录。GDPR 适用时，除不太可能对个人权利自由造成风险外，控制者应无不当迟延且在可行情况下于知悉后 72 小时内向有管辖权的监管机关通报；迟报须说明，信息可依法分阶段提供。对当事人可能造成高度风险时，除符合法定例外，应无不当迟延直接告知，不一律以公开事故细节代替通知。受托处理者应无不当迟延通知控制者。其他适用通信法另有通报对象、门槛或较短期限者，依其规定。

## 11. 年龄与儿童数据

托管测试服务供年满 16 岁且依法具备缔约能力者使用；所在地法律要求更高年龄或监护人许可时，依其规定。此服务门槛不表示已完成年龄验证，也不取代 GDPR 对儿童同意与其他儿童及青少年保护规范的判断。得知未符合门槛者注册时，应限制不必要处理并依法核实、回应与删除。自行部署者须另行评估对象、年龄与可行的保障。

## 12. 法律适用与比例原则

托管实例的运营所在地为台湾，应遵守适用的个人资料保护及通信法律，并按官方数据库所载已生效规定与施行注记判断义务。法规修正公布不等于已施行。

运营地不是唯一判断依据。在欧盟设立机构相关活动中处理数据，或在境外向身在欧盟的人提供服务、监测其境内行为而符合法定条件时，GDPR 亦可能适用；单纯网站可从欧盟连线，不当然构成向当地提供服务。免费、公益、个人作者或「测试中」不会自动排除适用；对外开放信箱亦不能一概援用纯粹个人或家庭活动例外。

欧盟代表、数据保护官、影响评估与处理记录依各自法定条件决定，不因小型项目便一律免除，也不因可从欧盟浏览便一律必须任命。持续运营的信箱通常不属偶发处理，应审慎评估相关例外。措施可以配合规模与风险，无须仅为发表源代码取得 ISO 认证或承诺企业服务。

## 13. 更新与新增用途

重大变更应在新处理开始前，以适当方式提供清楚告知，列明变更及适用安排；需同意的新增目的或接收者，应先取得有效同意，拒绝不得被解读为同意。既有数据转作新用途前，须评估相容性及法律依据。继续使用不构成新的隐私同意，更新日期也不代表所有实例已落实变更。
