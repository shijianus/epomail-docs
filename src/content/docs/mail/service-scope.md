## 1. 服务内容

| 项目 | 说明 |
| --- | --- |
| 帐号与注册 | 依实例配置经注册码或开放注册取得帐号，六种身份分组决定配额与权限 |
| 邮件收发 | 入站经 Cloudflare Email Routing 即收即解析；站内直投；站外经营运者配置的投递通道 |
| 存储 | 依身份分组的存储配额；可接入个人对象存储，接入后附件直接落其云端 |
| 整理与自动化 | 八视图收件箱、标签与分类规则引擎、高级搜索、验证码提取 |
| AI 能力 | 全文翻译与图片文字识别（依实例的 AI 引擎配置与模型授权） |
| 通知与转发 | Telegram 推送与邮件规则转发（依管理员的用户数据管控开关） |
| 客户端 | Web（可安装 PWA）与 Android 应用（epomail） |
| 语言 | 六语言界面；系统邮件与欢迎邮件按收件人语言投递 |

功能层面的逐项说明见[功能指南](/mail/features/)；各界面与路由的导览见[界面与路由总览](/mail/interface/)。

## 2. 服务边界

| 事项 | 边界 |
| --- | --- |
| 可用性 | 不承诺服务水平协议；运行可用性依 Cloudflare 平台 |
| 保存期限 | 回收站邮件自收受之日起 7 日实体删除；垃圾邮件隔离 7 日后转入回收站 |
| 配额 | 发信、信箱数与存储依身份分组出厂值，站长可于权限控制页调整 |
| 费用 | 托管实例当前不设付费功能 |
| 功能变动 | 功能随版本演进调整；重大变更经站内公告与公告邮件通知 |
| 附件限制 | 单附件上限依实例设置，仅约束使用运营者公共存储的用户 |

保存期限的完整语义见[数据处理与安全维护](/mail/data-security/)；行为边界见[可接受使用政策](/mail/acceptable-use/)。

## 5. 申诉与恢复

- 忘记密码：登录页「忘记密码」弹窗跳转申诉门户（携带申诉类型、界面语言与邮箱参数），经核验后恢复访问；
- 封禁与预警申诉：就处置结果提交的申诉以预警工单进入操作报告，由管理员研判放行或驳回，处置阶梯见[可接受使用政策](/mail/acceptable-use/)第 6 节；
- 数据自助：全量数据导出（JSON）、邮件历史归档与单封 .eml 下载可随时经「设置 → 资料」取得，见[设置指南](/mail/settings/)第 5 节。

## 6. 自部署实例的支持边界

上游开源项目不对其代码的任何部署运行提供服务、支持或可用性承诺；部署者对其用户的支持、告知与合规义务自负。本站文档（含法律文档）可作为自部署者面向其用户的说明基础，采用时其运营者即为该等文档的责任主体。
