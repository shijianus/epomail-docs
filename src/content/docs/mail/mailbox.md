<details>
<summary>图解：收件箱全景——四个最先用到的入口</summary>

这张收件箱全景图的四个标注分区，对应日常使用频率最高的四个入口：写一封新信、翻重要邮件、查延后事项与核对已寄出。

1. **写信（侧栏顶部主按钮）**：全局唯一的新建邮件入口，点击弹出写信弹层（非独立路由）；移动端为右下悬浮按钮，亦支持 `?composeTo=<地址>` 深链预填收件人。任何视图下都可一键开始写信。
2. **星标邮件（侧栏文件夹）**：所有加星邮件跨文件夹聚合于此：在列表行点击星形图标即入此视图，用于收藏需要长期保留或快速再访的邮件；侧栏计数实时反映数量。
3. **稍后处理（侧栏文件夹）**：延后跟进的暂存区，分「紧急」与「等待」两档：在详情页选「延后」并指定时间，到期自动回到收件箱顶部，重要事项不再沉底。
4. **已发送（侧栏文件夹）**：本帐号发出的全部邮件存底，可在此核对哪些信已实际寄出；出站量受帐号角色的每日发信配额约束，站内信直投、站外经投递通道。

</details>

## 1. 八个视图

| 视图 | 行为要点 |
| --- | --- |
| 收件箱 | 默认视图；时间正／倒序切换、新邮件轮询增量插入、虚拟滚动列表、未读红点、会话聚合 |
| 全部邮件 | 跨文件夹汇总；点击侧栏标签即按该标签过滤 |
| 已发送 | 本帐号发出之邮件 |
| 草稿箱 | 本地草稿；无收件人时显示占位标记 |
| 星标邮件 | 星标集合 |
| 延后处理 | 紧急与等待两档；到期自动回入收件箱 |
| 垃圾邮件 | 隔离 7 日后转入回收站 |
| 回收站 | 自收受之日起 7 日实体删除 |

## 2. 邮件详情页动作

| 分组 | 动作 |
| --- | --- |
| 回复类 | 回复、回复全部、转发；内联回复与表情回应 |
| 整理类 | 星标、已读／未读、移动到（收件箱／垃圾／回收站）、归档、延后（预设时间或自选）、加标签、举报垃圾／非垃圾 |
| AI 类 | 全文翻译（保留原排版，可逐封选择目标语言）、验证码徽标 |
| 输出类 | 打印单封或整个会话、下载 .eml、查看原始信头 |
| 治理类 | 屏蔽发件人、由此创建过滤器（打标签／标已读／进垃圾／进回收站） |

## 3. 写信弹层

写信为弹层（非独立路由），入口：侧栏「写信」按钮、移动端悬浮按钮（需发信权限）、深链 `?composeTo=<地址>`（预填收件人）。

- 收件人支持联系人选择；站内信箱直投，站外经营运者配置的通道投递；
- 富文本工具栏 17 项：段落、字号、加粗斜体下划线删除线、颜色、对齐、有序无序列表、引用、分隔线、链接、图片、表格、表情、翻译与源码模式；
- 附件能力依帐号角色开启，单附件上限依实例设置。

## 4. 会话与排版

邮件详情支持会话线程聚合、分层排版与悬浮快捷回复；原始信头查看用于排查投递问题。官方发件人邮件带认证标记与说明横幅，见[防篡改与官方规范](/mail/tamper-proof/)。

<details>
<summary>图解：邮箱视图与详情的操作步骤</summary>

![邮箱视图与详情的操作步骤](/images/mail/ui/views.png)

1. 登录后默认进入收件箱（`/mail/u/0/#inbox`）；顶部按钮切换时间正／倒序。
2. 新邮件由轮询自动插入列表顶部，未读以红点标示；侧栏文件夹树在八视图间切换。
3. 点击侧栏标签，列表即切到「全部邮件」并按该标签过滤。
4. 点击任一邮件进入详情视图（`#message/<hash>`）：回复、星标、延后、加标签、翻译、下载 .eml 等动作见页内动作栏。

</details>
