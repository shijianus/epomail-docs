## 1. 部署拓扑

| 组件 | 实现 |
| --- | --- |
| 运算 | Cloudflare Workers（V8 Isolate 沙箱）：业务逻辑无状态，明文仅存于请求内存，请求结束即释放 |
| 入站 | Cloudflare Email Routing 接收邮件，postal-mime 解析正文、标头与附件 |
| 出站 | 三通道依序解析：Cloudflare Email Workers 绑定、Resend API、Mailjet；站内互发直接写库 |
| 结构化存储 | Cloudflare D1（双库物理隔离：用户库承载帐号、角色与设置；邮件库承载邮件、星标与附件元数据；单库部署 100% 向后兼容） |
| 键值存储 | Workers KV：会话令牌、登录风控计数、TOTP 中间态、用户资料与对象存储兜底 |
| 边缘推论 | Workers AI（验证码提取等，默认 llama-3.1-8b-instruct） |
| 定时任务 | Cron 触发器每日执行：风控计数清零、发信计数重置、回收站与垃圾邮件清理、无绑定 OAuth 帐号清除 |
| 人机验证 | Cloudflare Turnstile（HTTP API 校验，注册与新增信箱） |

## 2. 技术栈

| 层 | 技术 |
| --- | --- |
| 客户端 | Vue 3.5、Element Plus、Pinia、vue-i18n、ECharts、Dexie（本地草稿，不上服务器）、Vite 7、vite-plugin-pwa |

## 3. 数据加密体系

- **三模式静态加密**：全部模式（不加密）、隐私模式（垃圾与回收站除外均加密）、加密模式（全部加密）；模式语义与管理员可及范围见[数据处理与安全维护](/mail/data-security/)第 1.3 节；
- **邮件加密**：主题与正文以 AES-256-GCM（含认证标签）加密，每条记录随机初始化向量；密钥自实例级主密钥环境变量经 HKDF-SHA256 派生并按用户加盐，主密钥不入库、不随代码提交；
- **凭证保护**：密码经 PBKDF2-HMAC-SHA256 100,000 次迭代加盐哈希；TOTP 密钥以 AES-256-GCM 静态加密，备用恢复码仅存 SHA-256 哈希；通行密钥仅存公钥；
- **边界**：以上为服务器端静态加密，非端对端加密；附件不在加密范围内。

## 4. 附件存储链

附件二进制按序解析存储：自备 S3 兼容存储（BYOS，支持 AWS S3、Backblaze B2、MinIO 等）→ 运营者配置之 S3 兼容存储 → Cloudflare R2 绑定 → 缺省 Cloudflare KV。元数据（文件名、MIME、体积）存于 D1；下载附带防御性标头与 MIME 白名单；删除邮件时附件经引用计数级联清理。

## 5. 会话与角色权限

会话为 30 天有效期之 JWT（HS256），落于 KV 并经深度脱敏；同帐号上限 10 个活跃会话，登出与注销即时吊销。权限采用 RBAC，播种六个标准角色：

| 角色 | 每日发信 | 存储配额 | 附件 | 附加能力 |
| --- | --- | --- | --- | --- |
| 参观者 | 禁止 | 0 | 否 | 只读沙箱 |
| 普通用户 | 5 封 | 5 MB | 否 | 基础收发 |
| 普通用户 LV.0 | 8 封 | 10 MB | 否 | 博客等级联动升级 |
| 普通用户 LV.1 | 10 封 | 25 MB | 是 | 基础收发与附件 |
| 管理员 | 100 封 | 500 MB | 是 | 用户管理、全邮件管理（受邮件模式约束） |
| 站长 | 不限 | 1024 MB | 是 | 全部权限 |

全部管理与业务路由统一经鉴权网关校验；公开端点（登录、注册、OAuth、初始化）除外；账户删除即时吊销其会话。

## 6. 邮件生命周期

| 环节 | 行为 |
| --- | --- |
| 删除 | 邮件先入回收站（软删除），自收受之日起 7 日后由定时任务实体删除（含附件与索引） |
| 垃圾隔离 | 垃圾邮件保留 7 日后转入回收站；隔离期可配置 |
| 配额清理 | 信箱用量逾配额 90% 时，已标记删除之邮件径行实体删除 |
| 官方邮件 | 欢迎邮件与全域公告缺省 7 日过期（可配置） |
| 级联删除 | 实体删除按分块执行（规避 D1 单语句绑定参数上限），附件与星标随邮件级联移除 |
| 帐号注销 | 会话即时失效，资料进入软删除状态，至管理员执行实体删除为止（时限承诺见[隐私政策](/mail/privacy-policy/)第 8 节） |

## 7. 应用安全设计

- **防越权路由**：邮件 URL 一律使用 HMAC-SHA256 签名的 20 位随机 Hash，绑定用户与租户，不暴露自增 ID，杜绝枚举与 BOLA／IDOR；
- **XSS 三重防御**：DOMPurify 白名单消毒、body style 注入过滤、附件输出 MIME 白名单加严格 CSP 与 `nosniff`；
- **SSRF 阻断**：出站请求经公共地址校验，回环、RFC 1918 与云元数据地址一律拒绝；
- **登录防护**：连续 5 次失败锁定 12 小时；Turnstile 人机验证；TOTP／Passkey 两步验证；
- **官方邮件完整性**：官方发信身份锁定、不可变快照投递与文档防篡改校验，见[防篡改与官方规范](/mail/tamper-proof/)。

## 8. 可观测与质量保障

- 运行日志经 Cloudflare Workers Logs 收集（应用不落 IP 日志之外的自建日志）；数据分析页仅呈现统计聚合，无内容级数据；
- 自动化测试、审计与巡检脚本逾百个：Playwright 全真栈浏览器回归、公网端到端断言、全仓静态扫描与六语言 i18n 三件套（详见[专案介绍](/mail/project/)第 7 节）。
