## 一、个人资料保护法（I0050021，最新修正已施行版本）

> ⚠ 结构性变化：主管机关已改为**个人资料保护委员会**（第 1-1 条）；旧第 27 条（安全维护）已删除，
> 非公务机关安全维护义务由**第 20-1 条**承接。任何文档**不得**再引用旧第 27 条。

| 条号 | 内容要点（可直接引用的关键句） |
| --- | --- |
| 第 5 条 | 「個人資料之蒐集、處理或利用，應尊重當事人之權益，依誠實及信用方法為之，不得逾越特定目的之必要範圍，並應與蒐集之目的具有正當合理之關聯。」（誠實信用與比例原則——蒐集處理利用之通則性義務） |
| 第 1-1 条 | 「本法之主管機關為個人資料保護委員會。」 |
| 第 2 条 | 用词定义：个人资料（姓名、出生年月日、联络方式、社会活动及其他得以直接或间接方式识别个人之资料）、蒐集、处理、利用、国际传输（跨国（境）之处理或利用）、公务机关、非公务机关、当事人。 |
| 第 3 条 | 当事人权利（**不得预先抛弃或以特约限制**）：一、查询或请求阅览；二、请求制给复制本；三、请求补充或更正；四、请求停止蒐集、处理或利用；五、请求删除。 |
| 第 6 条 | 特种个人资料（病历、医疗、基因、性生活、健康检查、犯罪前科）原则不得蒐集处理利用；例外六款（法律明文／履行法定义务＋适当安全维护／当事人自行公开／无从识别之统计学术研究／协助法定职务＋安全维护／经当事人书面同意）。 |
| 第 8 条 | 直接向当事人蒐集之告知义务六款事项（机关名称、蒐集目的、资料类别、利用之期间地区对象方式、当事人依第 3 条得行使之权利及方式、不提供之影响）＋免告知六款情形。 |
| 第 9 条 | 蒐集非由当事人提供之个人资料，应于处理或利用前告知来源及第 8 条第一项第一款至第五款事项。 |
| 第 19 条 | 非公务机关蒐集或处理之要件（特定目的＋八款之一）：法律明文／与当事人有契约或类似契约之关系且已采取适当之安全措施／当事人自行公开／无从识别之统计学术研究／经当事人同意／增进公共利益／取自一般可得之来源（当事人禁止处理利用显有更值得保护之重大利益者除外）／对当事人权益无侵害。 |
| 第 20 条 | 利用应于蒐集之特定目的必要范围内为之；特定目的外利用七款（法律明文／增进公共利益／免除当事人生命身体自由财产上危险／防止他人权益之重大危害／无从识别之研究／经当事人同意／有利于当事人权益）。**行销拒绝权**：「當事人表示拒絕接受行銷時，應即停止利用其個人資料行銷」；首次行销应提供表示拒绝之方式并支付所需费用。 |
| 第 20-1 条 | 非公务机关保有个人资料档案者，应办理安全维护事项，防止个人资料被窃取、窜改、毁损、灭失或泄漏；安全维护事项、管理机制、应采取之措施之办法由主管机关定之。 |
| 第 21 条 | 国际传输限制四款（涉及国家重大利益／条约协定特别规定／接受国保护未有完善法规致有损当事人权益之虞／以迂回方法规避本法）——主管机关得限制之。 |
| 第 22 条 | 主管机关检查权：通知陈述意见、通知提供必要文书资料物品、自行或会同中央目的事业主管机关、直辖市县（市）政府派员携带执行职务证明文件进入检查；非公务机关及相关人员**无正当理由不得规避、妨碍或拒绝**。 |
| 第 25 条 | 违法之矫正处分：禁止蒐集处理利用／命令删除经处理之个人资料档案／没入或令销毁违法蒐集之个人资料／公布违法情形及姓名名称与负责人（采损害最少方法）。 |
| 第 28 条 | 公务机关违法之损害赔偿（每人每一事件 500 元以上 2 万元以下酌定；同一原因事实合计上限 2 亿元，所涉利益超过者以利益为限）。 |
| 第 29 条 | 非公务机关违法致个人资料遭不法蒐集、处理、利用或其他侵害当事人权利者负损害赔偿责任，**但能证明其无故意或过失者不在此限（举证责任倒置）**；准用第 28 条第二项至第六项。 |
| 第 41 条 | 意图为自己或第三人不法之利益或损害他人之利益，违反第 6 条第一项、第 15 条、第 16 条、第 19 条、第 20 条第一项或依第 21 条限制国际传输之命令处分，足生损害于他人者：**五年以下有期徒刑，得并科新台币一百万元以下罚金**。 |

**补充**：第 18 条（公务机关应置个人资料保护长）适用于公务机关，本服务非公务机关不适用，勿误引。

## 二、个人资料保护法施行细则（I0050022）

**第 12 条**：「適當安全維護措施」指为防止个人资料被窃取、窜改、毁损、灭失或泄漏，采取技术上及组织上之措施，以与所欲达成之个人资料保护目的间具有适当比例为原则。措施**得包括**十一项（→《数据安全与安全维护》文档之框架）：

1. 配置管理人员及相当资源；
2. 界定个人资料之范围；
3. 个人资料之风险评估及管理机制；
4. 事故之预防、通报及应变机制；
5. 个人资料蒐集、处理及利用之内部管理程序；
6. 资料安全管理及人员管理；
7. 认知宣导及教育训练；
8. 设备安全管理；
9. 资料安全稽核机制；
10. 使用纪录、轨迹资料及证据保存；
11. 个人资料安全维护之整体持续改善。

## 三、刑法（C0000001）——妨害电脑使用罪章及其他

| 条号 | 罪名与要点 |
| --- | --- |
| 第 235 条 | 散布播送贩卖猥亵之文字图画声音影像或其他物品，或公然陈列，或以他法供人观览听闻：二年以下有期徒刑、拘役或科或并科九万元以下罚金；意图散布播送贩卖而制造持有者亦同。 |
| 第 339 条 | 诈欺：意图为自己或第三人不法之所有，以诈术使人将本人或第三人之物交付——五年以下有期徒刑、拘役或科或并科五十万元以下罚金；得财产上不法利益者亦同；未遂犯罚之。 |
| 第 358 条 | 无故输入他人帐号密码、破解使用电脑之保护措施或利用电脑系统之漏洞而入侵：三年以下有期徒刑、拘役或科或并科三十万元以下罚金。 |
| 第 359 条 | 无故取得、删除或变更他人电脑或相关设备之电磁纪录致生损害于公众或他人：五年以下有期徒刑、拘役或科或并科六十万元以下罚金。 |
| 第 360 条 | 无故以电脑程式或其他电磁方式干扰他人电脑或相关设备，致生损害于公众或他人：三年以下有期徒刑、拘役或科或并科三十万元以下罚金。（垃圾邮件、洪水攻击之主要刑事依据） |
| 第 361 条 | 对公务机关之电脑犯前三条之罪者，加重其刑至二分之一。 |
| 第 362 条 | 制作专供犯妨害电脑使用罪章之罪之电脑程式而供犯本罪，致生损害：五年以下有期徒刑、拘役或科或并科六十万元以下罚金。 |
| 第 363 条 | 第 358 条至第 360 条之罪，**须告诉乃论**（→ AUP 中说明：受害当事人告诉后始追诉，运营者仍得依民事与行政途径处置）。 |
| 第 319-1 条 | 未经他人同意，无故摄录其性影像：三年以下有期徒刑；意图营利或散布者加重（五年以下，得并科五十万元以下罚金）。 |
| 第 319-2 条 | 以强暴、胁迫、恐吓或其他违反本人意愿之方法摄录性影像：五年以下有期徒刑，得并科五十万元以下罚金。 |
| 第 319-3 条 | **未经他人同意，无故重制、散布、播送、交付、公然陈列或以他法供人观览其性影像**：五年以下有期徒刑，得并科五十万元以下罚金；影像系 319-1 摄录者六月以上五年以下、系 319-2 摄录者一年以上七年以下；意图营利加重至二分之一。（→ AUP「非自愿性影像」条款之主要刑事依据） |
| 第 319-4 条 | 以电脑合成（深伪）或其他科技方法制作不实性影像并散布播送交付公然陈列，足以生损害于他人：五年以下有期徒刑、拘役或科或并科五十万元以下罚金；意图营利者七年以下。 |
| 第 339-4 条 | 加重诈欺：犯第 339 条诈欺罪而有冒用政府机关公务员名义／三人以上共同／**以广播电视、电子通讯、网际网路或其他媒体等传播工具对公众散布**／以深伪方法犯之者，处一年以上七年以下有期徒刑，得并科一百万元以下罚金。（→ AUP 钓鱼与假冒邮件之刑事依据） |

## 八、诈欺犯罪危害防制条例（D0080226，2024-07-31 公布）——条号已于 2026-09-28 核验定位

- 立法目的（第 1 条）：防制及打击诈骗危害，预防与遏止不当利用**金融、电信及网路**从事诈欺犯罪并保护被害人。
- 对网路广告平台业者：第 30 条（涉诈广告禁止与查证管理措施）、第 32 条（知悉涉诈广告之**暂停刊播、下架删除并保存资料**义务）、第 33 条（受通知**先行限制接取或移除**）、第 37 条（电磁纪录与用户注册资料之合理期间保存）；违法者依第 39 条由数位经济相关产业主管机关处 50 万元以上 1000 万元以下罚锾并限期改正。
- 刑事衔接：第 43 条对犯刑法 §339-4 致交付财物达 100 万元者加重为三年以上十年以下有期徒刑。
- 用法：AUP 之诈欺条款引用 刑法 §339、§339-4（加重诈欺——对公众散布、冒用公署名义、深伪）＋本条例第 30、32、33 条框架。

## 九、其他适用结论（写作时统一采用）

1. **垃圾邮件**：台湾**无**垃圾邮件专门法。AUP 中引用：刑法 §360（干扰电脑系统罪）＋刑法 §339-4（加重诈欺）＋民法 §184（侵权）＋个资法 §20 第二项（行销拒绝权）＋儿少福利法 §46（平台自律）＋《诈欺犯罪危害防制条例》第 30、32、33 条（涉诈内容处置）。可同时提及境外收件地法规（美国 CAN-SPAM Act、欧盟 ePrivacy 指令、加拿大 CASL）作为跨国传输之行为指引，但注明以收件地法律为准。
2. **非自愿性影像（NCII）**：AUP 单列条款，引用：性侵害犯罪防治法 §13（平台先行限制浏览或移除＋资料保留 180 日）＋刑法 §319-1 至 §319-4（妨害性隐私及不实性影像罪章）。与儿少性剥削条款并列但分立（法源不同）。
2. **目的事业主管机关**：现行法主管机关为**个人资料保护委员会**（§1-1）；第 22 条检查由主管机关为之，必要时会同目的事业主管机关或地方政府。文档表述：「依個資法第 1-1 條，主管機關為個人資料保護委員會」。
3. **准据法**：中华民国法律（以台湾地区施行之法律为主），争议管辖：台湾台北地方法院为第一审管辖法院（自部署实例得依部署者所在变更）。
4. **本站法律文档之正式版本**：繁体中文（台湾）版（zh-tw 目录）为正式版本；简体中文为对照版本。
5. **审计受检义务表述**：「營運者依個資法第 22 條接受主管機關之檢查，無正當理由不得規避、妨礙或拒絕；並依施行細則第 12 條所列項目建立並持續改善安全維護措施。」（自部署实例由部署者承担同一义务）
6. 部署方接受**台湾（主管机关）之检查与审计**——所有文档之「行政监督」节均须包含此句。
